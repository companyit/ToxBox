# 009 2FA 动态验证码工具（范围待确认）

日期：2026-11-02。负责人已授权开始新增 2FA 功能页面；“2FA”尚需区分验证码工具、账户绑定或密钥/二维码生成，本提案按独立本地 TOTP 工具准备，未将具体范围视为已确认。

## 目标与场景

用户输入已有 Base32 密钥，在浏览器内查看当前 6 位动态验证码、有效期倒计时，并可点击复制。拟路径 `/developer/2fa/`，进入开发者分类与相关工具，兼容 CSR/SSG。

| 需求 | 可执行验收条件 |
| --- | --- |
| OTP-01 | 支持 Base32 大小写、分隔空白及合法尾部 padding；拒绝非法字符、错误 padding、非零尾位、空解码及超过 1024 字符的原始输入；不静默截断；错误提示中文且不回显密钥 |
| OTP-02 | 使用 RFC 6238 TOTP，固定 SHA-1、6 位、30 秒、T0=0；采用设备当前时间，验证 RFC 时间向量及前导零；说明需设备时间准确，不声称能校准服务器时间 |
| OTP-03 | 用户明确点击生成后计算，显示验证码与剩余秒数，到期自动更新；修改密钥立即使旧码失效，异步旧计算不能覆盖新状态；后台恢复重新按当前时间计算 |
| OTP-04 | 密钥默认遮挡，可手动显示；仅点击复制时写入验证码，不读取剪贴板；失败提供手动复制提示；清空/离页停止定时器并释放密钥与结果引用，不声称保证内存物理擦除 |
| OTP-05 | 密钥/验证码不进入 URL、日志、分析事件、存储、SSR HTML 或网络；本工具页禁止初始化 GA 等第三方脚本，需明确跨页已加载脚本无法靠移除标签卸载的隔离方案 |
| OTP-06 | 有标签、键盘焦点、语义错误提示与窄屏布局；倒计时不每秒触发读屏播报；Web Crypto 不可用时保留输入并说明无法生成 |
| OTP-07 | 首页、分类、相关工具及路由有真实入口，预渲染页面可读；新增页纳入静态生成检查，SEO 索引白名单单独评审，未批准时新页 noindex |

## 排除与待确认

不含网站账户登录、后端验证码验证、账户绑定、恢复码、HOTP、多账户管理、密钥持久化、二维码、otpauth URI 导入及新 npm 依赖。算法参数扩展需另行修订。

待确认：负责人是否选择此 TOTP 工具范围；工具页第三方脚本隔离采用整页导航及禁止 GA 初始化的方案是否批准。完整新页规格需人工审阅，确认后编码。

依据：[RFC 6238](https://www.rfc-editor.org/rfc/rfc6238)、[RFC 4226](https://www.rfc-editor.org/rfc/rfc4226)。

## OTP-08～10：otpauth 导入扩展（2026-11-02，本轮授权）

负责人明确选择支持 otpauth 链接导入及参数识别，替代前文对此项及算法参数的排除。

- OTP-08：独立遮挡输入框接收最多 4096 字符的 `otpauth://totp/` 链接，点击导入才解析；识别 Base32 secret、label/issuer、SHA1/SHA256/SHA512、6/8 位和 1～300 秒整数周期（产品范围），缺省 SHA1/6/30。拒绝 HOTP、重复/未知参数、空值、错误百分号或 UTF-8、issuer 冲突及不支持参数；失败不覆盖已有密钥/参数，错误不回显链接。
- OTP-09：成功导入原子更新密钥与参数，停止旧计算，显示账户/发行方及参数摘要；手动改密钥回到 SHA1/6/30，提示该行为；倒计时、过期复制判断和计算均使用同一周期。链接不自动生成验证码。
- OTP-10：链接、账户、发行方与密钥同样仅在当前页面内存中，清空/离页一起清除；不从页面 query/hash 自动导入，不请求远端，不打开链接。原第三方脚本隔离保留。

不含扫码、二维码生成、持久化、多账户或新依赖。依据：[Google Key URI 格式](https://github.com/google/google-authenticator/wiki/Key-Uri-Format)、RFC 6238。自定义周期上限是本产品限制，不称标准限制。
