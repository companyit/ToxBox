## 目标与首版范围

拟新增办公工具`/office/image-crop/`。从一张本地图片选择矩形区域，按需等比缩小后下载；保留现有批量图片压缩转换工具。单张裁剪适合头像、配图和截图局部，文件默认留在浏览器。

| 编号 | 可执行验收条件 |
| --- | --- |
| CROP-01 | 一次选择一张非空静态JPG/PNG/WebP，最多10 MiB，单边最多10000、总计最多2000万像素；复用现有签名/头部检查，拒绝SVG/GIF/HEIC、动画WebP/APNG、CMYK JPEG及现有不支持的PNG类型。解码后再次核验尺寸；损坏/超限中文报错，不改原文件 |
| CROP-02 | 按EXIF显示方向建立原图像素坐标；预览与导出基于同一方向，旋转后宽高以实际解码位图为准。预览最长边1280且不放大，显示原图尺寸及当前裁剪尺寸；默认选择整张图。透明区域有棋盘背景，预览明确仅供参考，不把缩略图像素当裁剪坐标 |
| CROP-03 | 支持拖动裁剪框移动、四角调整大小；另提供X、Y、宽、高四个有标签的整数输入，纯键盘可完成所有操作。左上角原点(0,0)，右/下边界为排除端点；x/y非负、宽高至少1，矩形不越出原图。拖动到边界时限制到有效范围，不能翻转；数值非法保留输入并禁用导出，不静默截断或使用旧框导出 |
| CROP-04 | 比例提供自由、1:1、4:3、16:9。固定p:q使用宽=p×k、高=q×k的整数矩形；切换时以当前框中心取能放下的最大k，位置向下取整并限在图内，不能容纳一个单位时保留原框并报错。固定比例下编辑宽或高，以对应整数单位向下取整推导另一边并提示调整；小于一个单位拒绝。恢复整图明确重置为自由比例/整图/原尺寸输出，保留文件及输出格式 |
| CROP-05 | 输出尺寸提供按宽度或按高度两种主尺寸，默认按宽度且不缩小；另一边为round(裁剪另一边×主尺寸/裁剪主边)，最少1像素，允许不足1像素的比例舍入误差。主尺寸为1～对应裁剪边的整数，不放大、不拉伸；输出同样受单边10000/2000万像素保护。裁剪变化后重置主尺寸为当前裁剪边并撤销旧结果，不悄悄沿用上次缩放 |
| CROP-06 | 默认PNG，另选JPG/WebP；PNG禁用质量，JPG/WebP质量10～100整数、默认90。JPG铺白底，PNG/WebP保留透明；实际编码MIME不符时明确报错，不静默改格式。显示输出尺寸、格式及体积，不能承诺一定变小或色彩完全一致 |
| CROP-07 | 主动点击生成后在同源Worker从原始解码位图裁剪/缩放，不裁剪预览图；成功才提供单一结果预览和下载cropped-image.png/jpg/webp。输出最多100 MiB，检查/生成分别30秒可取消；错误/取消不发布部分或旧结果，保留文件及有效编辑便于重试。下载交给浏览器，不声称已落盘 |
| CROP-08 | 重选、修改裁剪/尺寸/格式/质量、恢复、重新生成立即撤销旧输出并终止旧任务；文件/任务版本隔离迟到消息。清空/pagehide/离页释放File、位图、画布、预览/结果Blob URL及监听；取消预览检查可重试，清空回焦文件控件 |
| CROP-09 | 不上传、写入URL/日志/存储或采集文件名、尺寸和内容；沿用无GA/广告的敏感独立文档组。重绘不复制原始EXIF/GPS，但不宣称全面隐私脱敏、色彩配置保真或原字节保留。不支持在线图片链接 |
| CROP-10 | 接入首页、办公目录、搜索、指南及隐私；相关工具通过现有分类目录发现。新页noindex，正式八页索引不变；SSG仅空界面，不解码或访问Canvas。375/768/1440px可用，焦点可见、状态可感知，拖动有数值输入替代、触控命中区域至少44px。实施时按实际基线精确增加1工具/1HTML/1指南 |

## 验收样例

自制400×300四色分区图，输入x=100、y=50、宽200、高100，按宽100输出应为100×50，位置/颜色对应原图指定区域。400×300整图切16:9，应得400×225、x=0/y=37；再按宽200输出为200×113。透明棋盘样例核对PNG透明与JPG白底；带方向标记的EXIF 1～8样例核对预览及导出位置；真实Worker与独立打开下载文件分别验证，不只检查文件名。

## 排除项与待审阅

首版不含批量/ZIP、旋转翻转、任意角度、圆形/多边形裁剪、滤镜/标注/去背景、放大、证件照规格、自动主体识别、流程保存、云处理或新依赖。

待审阅：单图范围、固定比例整数规则、只等比缩小、默认PNG、预览/像素保护值及下载交互。选定方向不自动代表这些细节已签收；本轮不增加可用入口或改变当前19工具数量。
