# 034 图片尺寸与裁剪设计

日期：2026-11-07。候选设计，尚未实现。[规格](spec.md)、[任务](tasks.md)、[架构决策](../../architecture/decisions.md)。

## 现有能力与模块边界

已核对imageConvert.ts、imageConvert.worker.ts、imagePdf.ts及029规格：已有静态JPG/PNG/WebP检查、单图10 MiB/10000边长/2000万像素保护、createImageBitmap(from-image)、OffscreenCanvas编码及MIME确认。现有fitImage只处理最长边缩小，没有裁剪坐标、交互框或精确主尺寸规则；不能把现有工具称为已支持裁剪。

建议新增纯TS imageCrop：文件/矩形/比例/输出参数校验、固定比例初始化与量化、指针坐标映射、移动/四角边界和输出尺寸推导。只复用现有检查器，不改029既有缩放规则；允许在实现时最小抽取共享解码/编码辅助函数，须回归原工具，不把Vue展示或坐标交互放入App.vue。

独立同源Worker提供inspect与export两种任务。检查任务先预检头部/尺寸，再解码方向化位图并生成最长边1280的PNG预览，返回实际方向化宽高及预览字节，finally关闭位图。导出任务重新检查文件与参数，从原始方向化位图执行drawImage的源矩形与目标尺寸，编码后核验MIME、字节与尺寸；返回结果而非原始异常/栈。检查与导出不共用已转移所有权的ArrayBuffer。

页面组件维护File、源/预览尺寸、输入草稿、有效矩形、比例、主尺寸、格式、质量、焦点、状态及URL。预览生成与导出每次独立Worker，取消/超时可terminate，原位图不在主线程长期保留。只有整任务成功才提交结果URL；创建URL失败回滚，拒绝输出空链接。

## 坐标与交互

坐标基于方向化原图的边界区间[0,W]×[0,H]。预览图片实际显示框与图像匹配，不用含留白的外容器宽高推算；按client坐标减真实图像边界、除每轴显示比例映射至原像素，不乘设备像素比，不把CSS缩放重复应用。视口变化重新测量显示边界，不改原坐标。

拖动开始保存原矩形与指针快照，使用Pointer Events/pointer capture，移动差值映射后统一round到原像素。移动时clamp(x,0,W-w)、clamp(y,0,H-h)；自由比例四角不能穿过固定对角，宽高至少1。固定p:q四角以对角为锚，将有方向的指针距离投影到(p,q)，k四舍五入后限制在1～边界可容纳的最大整数；框的宽高始终为p×k/q×k。指针取消恢复该次拖动前有效框；输入草稿若无效，不启动拖动而要求先修正，避免悄悄覆盖未完成输入。

固定比例数值编辑按对应边单位向下取整求k，推导另一边；例如16:9宽201会明确调整为192×108。若原左上角下剩余空间不足则保留草稿并报错，不平移/放大另一边来掩盖错误。切换比例使用当前框中心和最大可容纳整数k，位置floor并限在图内；恢复整图重置自由比例、全部坐标和主尺寸，格式/质量保留。

键盘不要求模拟拖动：X/Y/宽/高和主尺寸输入及明确动作按钮覆盖完整流程；布局给触控手柄至少44px命中区，四角有可见轮廓，棋盘只是背景，不叠入PNG像素。输入法组合期间不提交生成/恢复或覆盖草稿。草稿无效时保留有效框供参照，但禁用导出并明确“先修正输入”，不能拿旧框生成。

## 状态与资源

空选择→检查中→就绪→编辑/无效→生成中→成功或错误；文件版本与任务版本分别隔离检查、导出及预览回写。重选清空旧源尺寸/预览/矩形，任何编辑撤销旧输出并取消导出；移动/缩放只更新本地覆盖框，不在pointermove中反复启动Worker。取消检查保留File便于重试，取消生成保留参数；清空/离页释放所有URL、文件和监听。

Worker再次校验矩形、比例、主尺寸及限额，不能只相信UI。from-image只执行一次方向转换，不能在Canvas再叠加EXIF旋转；JPG白底，PNG/WebP透明，格式不支持时提示改选，不上传回退。源图和输出位图以原尺寸/实际裁剪尺寸为准，1280预览不会限制最终导出清晰度。30秒与像素限制为保护值，不承诺所有设备内存安全或速度。

## 接入与验证

新增敏感路径与广告排除，沿用跨组整页导航，不引入第三方脚本或新持久化。动态浏览器处理与SSG分开，精确更新工具/页面/指南与数量审计；按当前基线落地将为20工具（办公13/开发7）、28HTML、20指南，但实施前须重新核对，不把计划数量当当前事实。

纯模块验证矩形边界、越界/小数/空值、比例量化、四角拖动、显示坐标与原像素映射、舍入及不放大；使用独立小尺寸遍历核对边界不变量。真实Worker以四色图验证实际裁剪像素位置与输出尺寸，预览缩小时仍从原图导出。两引擎覆盖PNG透明/JPG白底、支持与不支持的WebP、EXIF 1～8、损坏/动画/超限、Pointer Events与数值替代、取消/超时/迟到消息、修改撤销URL、离页/存储/网络边界、三视口及现有图片工具回归。
