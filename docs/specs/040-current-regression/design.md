## 回归复现后的修复设计

搜索框沿用装饰边框色，039 后浅色/深色相对输入底色仅约 1.35:1 / 1.69:1。新增独立 `--color-control-border` 深浅主题变量，只供首页搜索输入边界使用；不加深卡片、分隔线等装饰边框。实际浏览器仍按原有 3:1 边界与焦点、4.5:1 文字门槛验收。

卡片 focus-within 使用当前 `--color-accent`，旧测试既写死旧品牌色又立即读取过渡中的颜色。本轮测试从当前主题计算实际品牌色，并用 Playwright 自动等待边框达到目标；新增深色覆盖，不移除边框或可见焦点检查。

Firefox 已启动并执行 DOCX 预览/打印样式成功，但原生 `window.print()` 点击在当前 headless 环境阻塞超时。保留真实调用测试及失败，不用 mock 冒充系统打印通过；其完整矩阵单独记录，不影响继续完成可验证的 Chromium/WebKit 回归。

Firefox 完整回归复现首页刷新 disabled 属性接管不一致，trace 显示服务端 DOM 属性未呈现而客户端预期 disabled=true。输入已有 autocomplete=off，清除按钮尚未设置。Mozilla 的 [同类问题记录](https://bugzilla.mozilla.org/show_bug.cgi?id=1847798) 说明跨刷新恢复按钮状态可产生接管问题；本轮给该按钮加 autocomplete=off，保留 ready 门禁及交互，不禁用接管检查或修改浏览器偏好。

Firefox 裁剪手柄计算样式为 44px，边界测量因浮点误差得到 43.99998474121094。测试增加计算样式严格 44px 检查，并仅对 boundingBox 使用 0.0001 CSS px 精度容差；保留拖动、下载和点击区域检查，不改变实际手柄几何。
