## 目标与模型

面向少量名单、字段和文本表格，在 CSV 与 JSON 二维字符串数组之间转换。第一行视为普通数据，不推断表头，不生成对象数组。所有单元格保持字符串，保留前导零、空格、大小写和公式样式文本，不自动解析数字、日期、布尔值或 null。首版不宣称支持所有 CSV 方言。

示例 CSV：`001,"甲,乙"`，换行后为 `002,"他说""好"""`。对应 JSON 为 `[["001","甲,乙"],["002","他说\"好\""]]`，页面以 2 空格缩进展示。JSON 转 CSV 始终为每个字段加双引号，字段内双引号写成两个双引号；记录之间使用 LF，最后一条记录不附加换行。

## 需求与可执行验收

| 编号 | 范围与验收条件 |
| --- | --- |
| TABLE-01 | 两种明确方向：CSV → JSON（默认）、JSON → CSV。用户粘贴后主动点击转换，只执行一轮，不覆盖原输入。CSV 对应 JSON 的二维字符串数组，首行不作表头；`001,true` 转为 `[["001","true"]]`，不丢前导零或推断类型 |
| TABLE-02 | CSV 只使用英文逗号分隔字段、双引号包围字段。引号字段内 `""` 表示一个双引号，可含逗号和换行；普通字段中不允许双引号。关闭引号后只允许逗号、换行或输入结束，不接受额外空格或其他字符；未关闭引号、裸引号及错误闭合均拒绝，中文错误不回显原文 |
| TABLE-03 | CSV 识别 CRLF、CR、LF；包括引号内换行均规范化为 LF。仅移除输入开头的一个 U+FEFF BOM，其他位置原样保留；不 trim 字段。`a,` 为两字段 `a` 和空字符串；`a\n` 为一条记录，`a\n\n` 为两条记录，第二条含一个空字段。空行不会静默删除；纯空输入或仅一个 BOM 提示暂无内容，不默认生成空表格 |
| TABLE-04 | 两个方向均要求矩形表格，每条记录至少一个字段，列数相同。CSV `a,b\nc` 拒绝，保留全部输入；JSON `[[]]` 和不同列数拒绝。JSON `[]` 合法，转换成功得到空结果，明确提示“结果为空”并禁用复制 |
| TABLE-05 | JSON 使用严格语法，根值必须为数组，元素必须为行数组，每个单元格必须为字符串；对象数组、数字、布尔值、null、深层数组、注释、尾随逗号及 BOM 均拒绝，不隐式 stringify 或取对象键顺序。`[["001","a\"b"]]` 输出 `"001","a""b"`；JSON 单元格中的 CRLF/CR 规范化为 LF。孤立代理项与 U+0000 两个方向均拒绝，其他合法 Unicode 保留 |
| TABLE-06 | 主输入最多 100000 UTF-16 码元，最多 1000 条记录、100 列，最终输出最多 1000000 UTF-16 码元；不截断。解析过程中逐字段/逐记录检查数量，JSON 解析前限制容器嵌套深度为 2（忽略字符串中的括号）。序列化前按转义及格式规则估算长度，超限不构造结果。边界值接受，任一超限整次失败，不发布部分结果；限额不是所有设备性能保证 |
| TABLE-07 | 展示方向规则、当前规范化策略、示例、只读结果与成功记录/列数。空输入与成功空结果区分。示例按当前方向提供，有任何输入时提示先清空，不静默覆盖。编辑输入、切换方向、转换失败立即撤销旧结果及复制提示；不提供自动连续转换 |
| TABLE-08 | 成功且非空时才允许复制，等待 Clipboard Promise 成功后反馈；失败提示手动选择并聚焦结果。版本号使编辑、换向、清空及离页后的迟到 Promise 不覆盖状态。输入法组合期间禁用转换、换向、示例、复制和清空。清空恢复默认方向并回焦主输入；pagehide、卸载释放内容及监听器 |
| TABLE-09 | 输入、单元格、结果及错误详情不进入网络、URL、日志、分析事件或持久化；只使用页面内存，不主动读取剪贴板。不执行单元格内容，页面使用文本绑定和 textarea，不把内容作为 HTML。保留既有统计边界、敏感文档隔离和广告关闭策略；不提供文件下载或自动启动表格软件 |
| TABLE-10 | 接入首页、办公分类、搜索、相关工具、独立元信息和原创指南，SSG 仅渲染空表单。新页 noindex，不扩展既有八页正式索引白名单；由 11 工具/18 站点页面加 404 精确增至 12 工具/19 站点页面加 404。更新精确路径/数量/指南审计，不放松资源校验 |
| TABLE-11 | 输入、方向和结果有可见标签，规则明确，错误/转换状态及记录列数通过 live region 播报；键盘可完成选择、转换、复制、清空。375/768/1440px 无页面级横向溢出；错误保留全部输入，不显示旧成功。双引擎验证实际流程，未运行的真实设备/读屏/剪贴板组合明确标为未验证 |

## 排除与待确认
