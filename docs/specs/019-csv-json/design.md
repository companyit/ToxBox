## 模块与数据流

新增独立纯 TypeScript 模块 `src/utils/csvJson.ts`：输入为原文本与方向，输出为区分空输入、成功（结果/记录数/列数）和失败（固定错误代码）的联合类型。模块不访问 DOM、剪贴板、存储、网络或日志；页面映射固定中文错误，不透传 JSON.parse 的异常消息。类型与限额可在同模块导出，不新增解析依赖。

数据流：原始输入长度校验 → 空输入判断 → Unicode 合法性扫描/换行规范化 → 按方向解析 → 矩形及数量校验 → 预估输出长度 → 序列化 → 结果。JSON 不去 BOM、不宽松修复语法；CSV 仅去开头一个 BOM。规范化后不 trim 单元格，不解释数据类型或公式。

### CSV 有限状态解析

使用字段开始、普通字段、引号字段、闭引号后四状态逐码元扫描，不使用按逗号或换行 split 的方案。引号内仅 `""` 解码为双引号；闭引号后拒绝逗号/换行/结束以外的字符。每次结束字段检查 100 列限制，每次结束记录检查 1000 行及列数一致性，超限立即返回，不积累多余行列。引号内规范化换行保存在单元格；引号外换行结束记录。

结尾换行只是上一条记录的结束，不额外创建记录：`a\n` 一行、`a\n\n` 两行；最后存在逗号或未结束字段时需补一个字段。空源不进入解析；单个换行解析为一行一个空字段，逗号解析为一行两个空字段。单行单个空字符串的规范输出为 `""`，以区别空表格输出空文本。

### JSON 验证与序列化

解析前用字符串/转义状态扫描括号深度，超过 2 即拒绝；JSON.parse 仍是语法判定依据。解析后仅遍历根数组与行数组，不递归展开未知结构；非数组行、空行数组、非字符串字段、超限行列及不等列拒绝。`[]` 成功得到零行零列，CSV 结果为空。

CSV → JSON 的预估长度与 JSON.stringify 的 2 空格格式一致：计入外层/行数组、逗号、缩进及换行，字符串计入引号、反斜线和控制字符转义。先扫描所有单元格计算码元长度并尽早拒绝，成功后 JSON.stringify。JSON → CSV 始终引号包围每字段，双引号翻倍，记录间加 LF，无尾 LF；预估长度包括全部引号、双引号转义、分隔符及记录换行，通过后拼接。预估算法须与实际输出长度独立对照，并覆盖恰好限额与超限拒绝；序列化后再次核对上限作为守卫。

Unicode 扫描拒绝 U+0000 及不成对 UTF-16 代理项，合法代理对不拆分；JSON 原始转义可以编码代理项，因此需在解析后对每个单元格再检查，不能只检查原文。CRLF/CR 在 JSON 语法解析后、CSV 解析前规范化为 LF，以免把 JSON 文本中的转义当作结构换行。

## 交互状态与生命周期

新增 `CsvJsonPage.vue`，复用 ToolPageLayout 及现有控件样式，独立维护输入、方向、输出、记录/列数、错误、消息、组合输入状态、复制挂起和版本号；不改动其他工具编辑器。状态包含空输入、编辑、成功非空、成功空结果和错误。每次编辑/换向/重新转换立即失效旧结果与复制反馈，不自动使用上次输出作为下次输入。

示例为空时才填入；清空恢复 CSV → JSON 并回焦主输入。输入法组合期间禁用有副作用的操作。复制使用结果快照和版本检查，错误时选择只读文本供手动复制，卸载后不更新任何状态。pagehide（包括 bfcache）和卸载均释放所有文本和结果元数据；移除监听器，不提供历史恢复或自动剪贴板读取。不宣称内容引用释放能够物理擦除内存。
