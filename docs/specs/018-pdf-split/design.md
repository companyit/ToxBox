# 018 PDF 拆分与选页导出设计

日期：2026-11-05。状态：规格准备，待负责人审阅并明确授权实现。关联：[规格](spec.md)、[任务](tasks.md)。

## 模块与复用

独立纯 TypeScript 模块解析选页表达式，返回规范化的从 0 开始索引、从 1 开始显示序列与去重后数量，或固定中文错误码。先校验原始长度、片段数和数字语法，再依据已核验的源页数限制范围；只有端点合法且不超过 500 才展开，不用大整数范围分配数组。使用 Set 保留首次出现，不能排序。纯算法不访问 DOM、文件、网络、存储或日志。

独立同源模块 Worker 处理文件检查及两种导出任务。复用 `src/utils/pdfMerge.ts` 的 `loadPdf` 严格解析与 AcroForm/加密拒绝逻辑，复用现有限额常量；不在主线程导入 pdf-lib，不把含“合并”专属错误文案的多文件校验直接用作拆分界面。若需抽取共享解析模块，先保留现有合并行为和测试，做最小调整。

组件负责 File 引用、模式、页码输入、页数、规范化页序、状态、焦点和下载链接；算法和资源处理不放入 App.vue。Worker 只返回任务结果和固定错误，不发送原异常/栈，不输出带文档片段的库日志。

## 数据流与状态

选择文件 → 立即使旧任务/页数/下载失效 → 主线程检查扩展名/非空/20 MiB → Worker 读取并检查 PDF → 返回页数 → 用户编辑表达式/选择模式 → 展示规范化页序 → 明确点击导出 → Worker 重新校验文件及表达式 → 复制并序列化 → 全部输出成功后一次性提交下载。

状态包括空选择、检查中、就绪/页码待输入、页码错误、导出中、成功和错误。读取/检查中禁用导出，但重选/清空/取消始终可中断任务；保留当前选择以便重试。页码和模式变化清除旧结果且取消导出，但文件未变时可保留已核验页数；修改输入不自动解析 PDF 或导出。

“选择全部页面”明确写入 `1-N`（单页为 `1`），随后按当前模式校验；逐页模式超过 20 页时提示，不切换模式也不静默截断。输入法组合期间禁用导出和会覆盖页码的快捷动作，compositionend 后重新校验。

## 导出与资源生命周期

单份模式创建一份新 PDF，按规范化索引 copyPages 后 save；逐页模式按所选索引顺序逐份创建/序列化，各文件仅一页。每次序列化后校验累计字节，超过 100 MiB 即失败；已有临时字节不提交 UI。整批结果就绪后主线程统一创建 Blob URL，任一 URL 创建失败需回滚此前已创建的 URL，不发布不完整下载列表。

每项结果只包含原页号或固定标签与 PDF 字节，不使用原文件名作输出名/标题。两模式输出名由程序固定生成；逐页项最多 20，无自动触发多个下载。对象 URL 全部撤销后清除引用，不承诺物理内存擦除。

主线程单任务 30 秒保护，取消/新任务/离页直接 terminate Worker；版本号与任务快照拦截旧 onmessage/onerror。Worker 重校验主线程传来的模式、页码与资源上限，不能依赖 UI 已做校验。取消导出保留文件/表达式，清空则全部清除并将焦点返回文件选择。pagehide/卸载释放 File、结果字节和 URL，移除监听。

## 路由与数据边界

沿用现有敏感文档组，扩展 `isSensitiveRoute` / `isSensitivePath`、Analytics 排除与广告准备排除路径；进入普通页面或从普通页进入拆分页维持整页导航。不得仅禁用页面事件而继承已执行的 GA。PDF 内容仍可能含动作/链接，copyPages 不提供安全清洗保证；首版不嵌入或运行内容。

拟接入页名 `pdf-split`、路径 `/office/pdf-split/`、办公分类、原创指南与相关工具。当前 9 工具/16 站点页面加 404，接入后为 10 工具/17 页加 404。精确更新 SSG/浏览器运行器/广告准备及数量测试，维持 Worker 同源 hash JS 和既有资源检查，不扩大正式索引或广告执行范围。

## 验证方案

- 算法：页码从 1 开始、片段顺序、范围递增、重叠保留首次、空白规则、单页/500 页、1000 码元/100 片段临界值；拒绝空片段、前导零、负号、小数、科学计数、中文分隔符、逆序、越界和超长端点。大范围输入在展开前拒绝。
- PDF：由合成源按 `5,1-3,2` 导出后重新解析为源 5/1/2/3 页，逐页导出 `3,1` 对应两个单页文件；覆盖不同尺寸、旋转、文字/图片、损坏、加密、表单、输出累计超限及整批失败。
- 状态：重选/页码/模式变更、超时/取消、迟到消息、导出失败保留输入、URL 原子提交/回滚/撤销、清空/离页与输入法组合。下载完成提示不推断落盘。
- 浏览器：Chromium/WebKit 三种宽度实际选文件、选页、切换、键盘、取消、两种下载及独立文档边界；正式 origin 下不初始化 GA，文件相关请求无外发；不以组件 mock 替代真实 Worker 和下载。
- 工程：类型、算法/组件、CSR/SSG、静态输出、154 历史身份及广告准备检查；新增夹具纳入运行前后摘要，不覆盖既有历史证据。对输出使用已有离线 PDFKit 辅助逐页渲染并核对页序/旋转。
- 限制：Firefox 已知启动环境问题、真实设备及更广阅读器矩阵以本轮实际执行为准，不沿用旧通过结果；保护值不是性能保证。

无新依赖或技术栈决策待定。首版产品规则和实现范围仍须明确审阅授权；新生产候选、发布和远端设置不随本规格获准。
