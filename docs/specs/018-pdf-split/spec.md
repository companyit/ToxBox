# 018 PDF 拆分与选页导出（待审阅实现范围）

日期：2026-11-05。负责人在下一模块优先级问题中选择“PDF 拆分与选页导出”。本轮先形成可审阅规格；选择方向不自动代表以下交互细节已获实现授权。关联 P1-16，沿用已安装的 pdf-lib@1.17.1，不新增依赖、上传、后端或持久化。

## 目标与首版范围

拟路径 `/office/pdf-split/`。从一份普通 PDF 中选择页面，支持两种明确模式：选页合成一份 PDF、所选页面逐页拆分。全部文件处理在同源 Worker 内完成。

| 编号 | 可执行验收条件 |
| --- | --- |
| SPLIT-01 | 一次选择一份本地 PDF，非空、最多 20 MiB、1～500 页。检查扩展名、文件头和严格解析，不只信任 MIME；复用现有加密、损坏、AcroForm 拒绝边界。不破解密码、不承诺检测所有签名类型。重选立即使旧结果和页数失效，新文件未检查通过前不能导出 |
| SPLIT-02 | 按从 1 开始的页码输入英文逗号与短横线表达式，如 `1,3-5,8`。最多 1000 个 UTF-16 码元、100 个非空片段；允许片段、数字与短横线两侧空白，不允许数字内部空白、空片段、正负号、小数、科学计数、前导零、中文逗号、逆序范围或越界。空输入不默认选择全篇。错误保留原表达式，中文提示不回显内容 |
| SPLIT-03 | 按表达式片段的输入顺序展开，每段范围递增；重复/重叠页面保留首次出现，不自动按页码排序。检查通过后展示实际页序及选中数量，并说明去重规则；`5,1-3,2` 的实际页序为 `5,1,2,3`。仅在文件就绪时提供主动“选择全部页面”操作 |
| SPLIT-04 | 默认“选页导出一份 PDF”：明确点击导出才执行，输出固定 `selected.pdf`。六页源输入 `5,1-3,2` 后输出四页，顺序对应源第 5、1、2、3 页；保留原页面尺寸、旋转和普通文字/图片，不栅格化。不承诺书签、签名、附件、标签、表单或权限完整保留 |
| SPLIT-05 | 可选“逐页拆分”：最多选择 20 个不同页面，依实际页序生成独立单页 PDF。`3,1` 显示两项下载，依次为 `page-0003.pdf`、`page-0001.pdf`。用户逐项主动点击下载，不自动连续下载，不新增 ZIP 包或“全部下载”按钮；超出 20 页时保留选择并提示减少页数或切换单份模式，不静默缩减 |
| SPLIT-06 | 单任务保护时限 30 秒，可取消；Worker 串行复制/序列化，逐页模式全部结果累计最多 100 MiB，单份模式同样最多 100 MiB。超限、超时或任一输出失败则整批失败，不出现部分下载。显示真实处理阶段，不虚构百分比；限额是保护值，不是设备性能承诺 |
| SPLIT-07 | 修改页码/模式、重选、重新导出、取消、清空、pagehide 和卸载均终止或废弃旧任务并撤销旧下载 URL。版本号阻止迟到消息回写。导出错误保留当前文件及表达式便于调整，不展示旧成功；清空清除文件、页码、页数和结果，恢复默认模式。下载由浏览器处理，不宣称已经保存到磁盘 |
| SPLIT-08 | 文件名、字节、页数、表达式和结果不进入网络、URL、存储、日志或分析。新页纳入已有 2FA/PDF/DOCX 无第三方敏感文档组，跨组整页导航，不加载或继承 GA/广告。所有 PDF 下载为本地 application/pdf Blob URL；不嵌入 PDF 预览，不把选页当作安全清洗或隐私脱敏保证 |
| SPLIT-09 | 实现后接入首页、办公分类、搜索、相关工具、导航、原创指南和隐私说明；独立元信息，SSG 只渲染空表单，不访问文件或启动 Worker。新页 noindex，不扩展八页正式索引白名单；精确更新至 10 工具、17 站点页面加 404，不放宽资源或数量断言 |
| SPLIT-10 | 文件/页码/模式有可见标签，说明实际页序、两种模式及下载限制；错误、检查和导出状态可被读屏感知。键盘可选文件、输入、切换、取消、清空和逐项下载；375/768/1440px 无页面级横向溢出。输入法组合期间不触发导出或覆盖正在编辑的页码 |

## 排除与待确认

首版不含按多个范围分组打包、按固定页数切份、ZIP、拖拽缩略图、视觉预览、OCR、正文编辑、压缩、加解密、签名校验、图片转 PDF 或云保存。

待负责人审阅：两种导出模式、保序去重规则、逐页最多 20 项且逐项下载、沿用敏感页边界及上述具体限额。该规格准备不等于工具已实现，不新增可用入口，不修改源码/配置/依赖/锁，不生成新生产候选或部署。
