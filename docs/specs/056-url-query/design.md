# 056 URL 参数解析设计

关联[规格](spec.md)。

纯 TypeScript 模块接收文本、输入类型和加号模式。完整 URL 使用浏览器 URL API 校验协议和绝对地址，从原始输入截取查询文本，以保留源码中的分隔符和转义。首个片段分隔符之前没有查询分隔符时，返回零项。查询字符串模式仅去掉一个前导问号。

对非空段先做数量检查，再按首个等号拆分。每行保存解码后的键、值和是否有等号。先在表单模式下处理字面加号，再用 decodeURIComponent 进行严格单次解码。解析失败仅返回固定错误类别及可选的参数序号。检查通过后才一次性返回完整结果。

页面保存输入、模式、解析状态和页码。在输入上限内采用同步纯函数；页面使用语义表格、状态播报和分页。使用 Vue 文本绑定，路由复用项目已有敏感工具导航隔离和静态渲染机制。

验收涵盖首个等号、空段、重复键、空键、缺等号、片段、双重编码、加号、无效 UTF-8 和边界值。组件与浏览器验证输入保留、状态撤销、移动端分页、键盘焦点及无外部请求。静态测试验证 noindex、脚本隔离与目录接入。
