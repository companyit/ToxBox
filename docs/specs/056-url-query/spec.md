# 056 URL 参数解析

日期：2026-11-19。状态：负责人回复「推进」，按 UQP-01～05 实施。

用户在排查接口请求或配置链接时，可以粘贴 URL 或查询字符串，按原顺序查看参数名和值。入口为 `/developer/url-query/`。

| 编号 | 可执行验收条件 |
| --- | --- |
| UQP-01 | 显式选择「完整 URL」或「查询字符串」，点击解析后处理。完整 URL 须为合法的绝对 HTTP/HTTPS URL，仅解析第一个 `?` 与片段分隔符 `#` 之间的文本。查询字符串可带一个前导 `?`，其中 `#` 按字面字符处理。原输入始终保留。 |
| UQP-02 | 按 `&` 分段，跳过空段，按每段第一个 `=` 分开名称和值。保留顺序、重复名称和空名称，区分无等号与有等号的空值。例如 `a=1&a=2&flag&empty=&=value` 产生五行。 |
| UQP-03 | 对名称和值分别解码一次。默认保留字面 `+`，用户可切换「表单模式」将原始 `+` 解释为空格，`%2B` 仍解码成加号。`%2526` 只解码成 `%26`。非法百分号转义或无效 UTF-8 整次失败，只用中文提示参数序号。 |
| UQP-04 | 输入最多 20,000 个 UTF-16 码元，最多 500 条非空参数，超限时无部分结果。输入或模式变化撤销旧结果。按页显示结果，每页 50 行，键盘可操作，空结果有明确提示。 |
| UQP-05 | 浏览器本地解析，名称和值按纯文本展示。解析过程不导航、请求地址或持久化内容，错误不回显输入。复用现有敏感页面隔离，页面 noindex，无统计或广告。 |

范围限只读解析。参数编辑、URL 重建、批量处理和导出暂不纳入。
