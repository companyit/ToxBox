# 041 设计

先使用已安装 Playwright/Firefox 启动新临时 profile，在本轮独立证据目录指向 Mozilla 虚拟 PDF 打印目标并指定文件输出；仅对这个浏览器实例传入偏好，退出后销毁 profile。原生打印方法不替换，浏览器上下文阻断外部请求。Mozilla [原生静默打印问题记录](https://bugzilla.mozilla.org/show_bug.cgi?id=1741698) 和 [打印到文件记录](https://bugzilla.mozilla.org/show_bug.cgi?id=2029753) 用作偏好核对依据，不据文档推断本地已通过。

只有探测产生完整可解析 PDF 才接入现有文档工具用例。使用当前 WORKDEV_E2E_RUN_DIR 下独立文件路径，文档工具用例串行执行；每次打印前要求目标不存在，等待真实文件完整可解析后移入该测试独立 artifacts 目录，避免旧文件冒充结果。Firefox 独立 launchOptions 限定在文档工具 spec，其他浏览器保留现有原生调用和 Chromium page.pdf 证据。

首轮文件独立读取发现临时 profile 默认纸张为 Letter（612×792pt），与既有 DOC-04 的 A4 目标不同。参照 [Mozilla 纸张设置记录](https://bugzilla.mozilla.org/show_bug.cgi?id=1673012) 明确测试虚拟打印机选用毫米单位、210×297mm、iso_a4；隔离探测实测得到约 595.28×841.89pt。为原生输出增加逐页 A4 竖向尺寸断言，保留首轮独立检查失败；应用 CSS 不控制用户系统纸张，产品指南仍需人工核对打印设置。

同时在 WordToPdfPage 既有打印说明中补充选择 A4、纵向及保存前核对沿用纸张的提醒，服务于真实用户的打印设置选择；不更改应用算法、按钮行为、数据边界或用户浏览器偏好。此项只调整现有 DOC-04/06/08 说明。

沿用合成 DOCX（标题、列表、表格、PNG/JPEG、70 段中文正文），调用网站真实打印按钮，检查请求提示、不宣称保存成功、PDF 页数及打印事件。独立阅读器复核文件正文和隔离范围。应用算法不因测试环境限制而改写；发现新业务缺陷时先记录再最小修复。

运行现有类型/preview 构建及完整三引擎回归，验证测试源、应用源、配置、锁和产物摘要；不修改旧 040 证据。系统对话框人工保存、真实手机/读屏和负责人验收单列，不由原生自动文件输出代签。
