# 033 PDF 页面整理

日期：2026-11-07。状态：本地实现与自动化验证完成，人工验收待完成（见文末）。初始阶段负责人选择“先评估浏览器本地渲染方案并编写规格”；本轮不授权安装依赖、编码或发布。关联P1-21、ADR-033；[设计](design.md)、[任务](tasks.md)。

目标：从一份本地PDF查看缩略图，排序、旋转、删除后导出一份PDF。拟路径 `/office/pdf-organizer/`，保留已有合并及拆分工具。

| 编号 | 可执行验收条件 |
| --- | --- |
| ORG-01 | 一次选择一份非空PDF，最多20 MiB、1～100页；检查扩展名/文件头，复用严格解析及加密、损坏、AcroForm拒绝边界。超限拒绝，不截断；现有拆分500页限制不变 |
| ORG-02 | 按源页序显示本地缩略图、原页码、输出位置及旋转增量；仅渲染可见及邻近页。失败显示“缩略图不可用”及重试，不能用空白冒充正确预览；可继续按页码编辑，但提示预览未完成 |
| ORG-03 | 单页拖动排序，并提供前移/后移按钮供键盘和触屏使用；移动后焦点保留该页并播报位置，边界按钮禁用。六页文件将第5页移至首位，结果为5/1/2/3/4/6 |
| ORG-04 | 逐页顺/逆时针90°旋转，以原旋转加增量显示及导出；删除至少保留一页。明确确认后“恢复原始排列”恢复全部页、原序及零增量，不改源文件 |
| ORG-05 | 主动导出organized.pdf，按当前顺序复制原页及设置旋转，不把缩略图栅格化为PDF；保留普通文字、图片及尺寸。不承诺书签、链接目标、签名、附件、标签或表单保真，不声称安全脱敏 |
| ORG-06 | 检查/导出分别30秒可取消，输出最多100 MiB，失败不发布部分结果。缩略图单页10秒、最多2任务并发、最长边320像素（不乘设备像素比）、最多缓存24页；均为待审保护值，不是性能/内存保证 |
| ORG-07 | 重选、编辑、恢复、重新导出撤销旧下载并取消旧导出；取消/错误保留当前文件及编辑。版本隔离迟到消息，清空/pagehide/离页销毁任务、文件引用、画布及Blob URL；下载不宣称已落盘 |
| ORG-08 | 文件名/字节/页数/缩略图/计划不进网络、URL、日志、存储或统计；纳入无GA/广告的敏感独立文档组。仅Canvas图像和安全文字，不执行PDF脚本、动作、附件或可点击注释；Worker/字体/CMap/WASM资源均同源 |
| ORG-09 | 接入目录、搜索、相关工具、原创指南及隐私，SSG只输出空选择界面，不运行渲染器。noindex，正式八页索引不变；按实施基线精确增加1工具/1HTML/1指南，不沿用历史总数 |
| ORG-10 | 375/768/1440px无页面横向溢出；纯键盘完成所有核心操作，标签/焦点可见、错误和状态可感知。真实手机/读屏/系统保存另验，不用桌面模拟替代 |

验收样例：六页合成PDF，第3页原旋转90°且含不同页面尺寸；第5页移至首位、删除第2页、第3页顺时针90°，输出5/1/3/4/6，第3源页最终旋转180°，其余内容和尺寸对应原页。用独立阅读器逐页检查。

首版排除多文件合并、复制页、批量选择、逐步撤销/重做、裁剪、正文编辑、OCR、压缩、加解密、签名校验、云保存和安全清洗。

待确认：PDF.js新增依赖/资源许可、具体版本核验与适配原型授权、100页及渲染保护值、单页操作和整篇恢复规则。文档完成不代表功能完成。
