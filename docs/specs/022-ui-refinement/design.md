- `CategoryPage.vue`：取消office单列/developer两列差异，采用统一1/2/3列响应式规则，不修改过滤逻辑。
- `ToolCard.vue`：统一卡片内部排版、边界、状态、入口；保留标题ID及唯一 RouterLink 可访问名称，不做整卡点击或截字。
- `ToolPageLayout.vue`：共享标题/指南/相关工具间距、边界与链接网格；完整正文可见，fieldset hydration禁用逻辑不变。仅用局部 :deep(input[type=file]) / ::file-selector-button 处理原生文件控件外观，不给全部输入或按钮追加可能破坏内部工具工作台的宽度/布局覆盖。
- `base.css/main.css`：仅必要语义间距/目录规则，优先在组件内更新已有规则而不是不断叠加冲突覆盖。App、14个工具算法与处理脚本、Worker及路由/SEO/敏感组不改。

既有源码含未提交成果，实施前保存只读差异基线，最小范围修改，不用 checkout/reset 覆盖其他改动。当前界面不是 Sites 生成站点，不引入托管或外部站点构建流程。

## 信息与响应式

首页 DOM 顺序保持介绍→搜索→办公→开发→旧入口→隐私。介绍区使用居中单栏，不设右侧概览，避免首屏高度由工具总数线性增长；手机收紧标题/介绍/摘要间距，验收375×812搜索完整可见。不要通过 overflow:hidden、固定首屏高度、删内容或缩小正文规避几何要求。若正常内容无法达到首屏目标，先精简重复介绍而不是压缩交互到44px以下。

目录 640/1024 断点明确从1列到2列到3列；两类堆叠展示，不采用过去办公窄列/开发宽区。保留1280px目录上限和16/24/32px边距。卡片用flex纵排和底部入口，网格stretch形成同行等高；长文案撑高整行，避免固定height或多行省略。

工具内部继续各自现有布局。共享指南保持52rem阅读宽度、清楚标题间距；相关工具用auto-fit/minmax或明确断点网格，不把13个入口塞入小字号横排。文件控件保留原生语义并以CSS伪元素改善按钮外观，禁用与focus必须同时可辨。
