# 021 图片转 PDF

日期：2026-11-07。状态：具体规格已获负责人本轮“继续开发”授权，按 IMG-01～10 实施；历史提案记录见文末。关联 P1-19、ADR-028。

## 目标与范围

拟路径 `/office/images-to-pdf/`。用户选择本地 JPG/JPEG/PNG，每图一页，按列表顺序生成一份可下载 PDF。全程本地处理，复用已安装 pdf-lib@1.17.1，不新增 npm 依赖、上传、后端或持久化。

首版默认 A4 纵向、12 mm 边距；可选 A4 横向、边距 0/12/20 mm。图片等比完整放入可用区域并居中，不裁剪；允许放大并说明低分辨率图片可能模糊。透明区域铺白底。JPEG 按 EXIF 方向呈现，不把手机方向标签忽略为正确结果。图片重新栅格化，不承诺原字节、色彩配置、打印色彩、矢量或无损保真。不在网页预览生成的 PDF。

## 需求与可执行验收

| 编号 | 需求及验收 |
| --- | --- |
| IMG-01 | 明确选择或追加本地图片；列表显示安全文本文件名、大小及检查后的像素尺寸；取消文件选择不改变现有列表。重复文件允许，按列表重复输出。不读取文件路径或自动排序 |
| IMG-02 | 使用可聚焦的上移/下移/删除按钮调整顺序，首尾对应按钮禁用；删除或排序立即撤销旧结果。三张标记为 A/B/C 的图，移 C 到最前后输出顺序 C/A/B |
| IMG-03 | 严格限定 JPG/JPEG/PNG，扩展名与文件签名一致，实际解码通过才接受；不只相信 MIME。损坏、空文件、SVG/GIF/WebP/HEIC、动画 PNG、不支持的颜色/编码明确拒绝，不展示原解析异常或图片内容。整批检查失败保留原已通过列表，不提交部分新增项 |
| IMG-04 | 最多 20 张，每张最多 10 MiB，总计最多 50 MiB；单边最多 10000 像素，每张最多 2000 万像素、全批最多 8000 万像素。原始字节和格式头尺寸在解码前预检，解码后核对尺寸。边界包含等值及相邻超限；不截断、不静默跳过。检查和生成均 30 秒超时可取消；输出最多 100 MiB。限额为保护规则，不是低内存设备性能保证 |
| IMG-05 | 至少一张检查通过才允许主动生成。默认 A4 纵向 210×297 mm，可切横向；边距可选 0/12/20 mm。每图一页，完整等比缩放居中，不裁剪。两种页面方向及三个边距都以独立几何预期验证，不把 px 当 mm；透明区域白色，低分辨率允许放大并有明确说明 |
| IMG-06 | JPEG 的 EXIF 方向由明确的浏览器解码方向策略处理，覆盖 1～8（含镜像与宽高交换）；不支持该本地 Worker 解码能力的环境提示无法处理，不调用远端服务或悄悄生成错误朝向。PNG/JPEG 重绘为普通栅格后嵌入 PDF，不保留 EXIF/GPS 字段；不把此规则称为全面隐私脱敏或色彩保真保证 |
| IMG-07 | 仅完成全部页及输出限额校验后生成 `images.pdf` 下载链接。生成失败、取消、超时、重选/追加、排序、删除、参数改变、清空及离页使旧链接失效并释放 URL；任务版本阻止迟到消息回写。取消保留已通过列表；清空删除列表、恢复默认参数并回焦选择控件；不声称点击下载即已保存 |
| IMG-08 | 文件、文件名、像素及结果只在内存与同源可终止 Worker 内处理，不写 URL、网络、日志、分析或存储。加入现有 PDF/DOCX/TOTP 敏感文档组，整页导航隔离 GA/广告。逐图处理，关闭 ImageBitmap 并释放 canvas/中间字节引用；pagehide/卸载终止 Worker 并清理监听和结果 |
| IMG-09 | 接入首页、办公目录、搜索、相关工具、面包屑、办公高亮、独立元信息、指南及隐私说明。SSG 空列表/无下载；由 13 工具/20 站点页面加 404/13 指南，精确变为 14 工具/21 站点页面加 404/14 指南。新页 noindex，八页正式索引不扩容，不改广告或部署范围 |
| IMG-10 | 中文标签、状态播报、可见焦点，键盘可完成选图后排序/参数/生成/取消/下载。375/768/1440px 无页面横向溢出。双引擎用真实 Worker、合成标记图片检查顺序、尺寸、方向、透明白底、失败/取消和第三方隔离；结果用独立 PDF 阅读器或现有 PDFKit 渲染对照。真实手机、系统保存/读屏未执行时明确未验证 |

## 排除与待确认

不含 HEIC/WebP/SVG/GIF、相机拍摄入口、拖拽排序、缩略图编辑、裁剪/手动旋转、压缩质量选择、OCR、多图拼一页、加密、云存储、批量多个 PDF 或 ZIP。不要将身份证等真实敏感图片用于反馈和验收样例。

待确认：以上格式、20 张/体积/像素限制、A4 两方向及三个边距、完整放大居中、白底重绘与色彩局限、敏感页隔离和可取消 Worker 路线。负责人审阅并明确授权后执行实现；不含新依赖、生产打包或部署。

实现细化：首版接受非隔行的普通 8 位 PNG（灰度、RGB、索引色及带透明通道类型），拒绝动画或隔行 PNG，允许经严格 TIFF/方向验证的 eXIf 块；JPEG 限 8 位灰度/RGB 基线或渐进编码。页面和指南明确显示这些兼容边界；JPEG EXIF 1～8 仍按原规格验证。

兼容核验修正：WebKit 自身生成的普通 PNG 含合法 eXIf 块，因此沿用同一严格 TIFF 方向解析及浏览器解码处理，不一概拒绝合法 PNG 元数据。重复/畸形方向块仍拒绝，输入元数据不复制到 PDF。合成 JPEG 方向样例先移除生成器已有 EXIF，再插入单份测试方向，避免构造互相冲突的元数据。
