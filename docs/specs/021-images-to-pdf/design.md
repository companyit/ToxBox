# 021 图片转 PDF 设计

日期：2026-11-07。状态：已获负责人本轮实现授权。关联：[规格](spec.md)、[任务](tasks.md)、[ADR-028](../../architecture/decisions.md)。

## 模块与流程

`imagePdfLimits.ts` 定义文件/字节/像素限额，严格校验数量、扩展名及总量；`imagePdf.ts` 处理格式头、几何计算、逐图重绘与 PDF 生成。组件 `ImagesToPdfPage.vue` 负责列表/参数/可访问交互、版本、Worker、超时和对象 URL，不把算法放入 App。无新依赖，使用现有 pdf-lib 精确版本。

同源 `imagesToPdf.worker.ts` 提供检查和生成两种任务。检查先做整个批次的数量/字节检查，再逐图读取字节、验证签名/尺寸/PNG 动画标记，超像素在解码前拒绝。JPEG 有限遍历 marker/段长和尺寸，PNG 有限遍历 chunk/长度/IHDR/IEND，拒绝畸形或不支持结构；实际解码与头部尺寸交叉核对，EXIF 方向导致宽高交换须按已解析方向核对，不能误报不一致。所有循环受文件字节及段边界限制。

拟使用 Worker 内 createImageBitmap（imageOrientation: from-image）与 OffscreenCanvas：按方向解码后用白底画布绘制，convertToBlob PNG，再 embedPng。逐图释放 ImageBitmap、画布及中间引用，检查不保留像素缓存。PNG/JPEG 只输出重新绘制的像素，原 EXIF/GPS 不作为 PDF 元信息或附件复制。首版不宣称完整色彩配置或全面隐私清洗。若当前浏览器能力不支持或方向验收失败，返回固定错误，不引入主线程/远端隐式降级；是否需要替代方案另行更新设计。

PDF 几何为纯函数：mm×72/25.4 得 pt；A4 方向确定页宽高，扣两边 margin 后，scale=min(可用宽/图宽,可用高/图高)，x/y 居中。为每图创建独立页面，不读取图片 DPI，不做裁剪。结果重开检查页数/尺寸，独立渲染视觉对照标记及边距，不能仅依靠同库往返宣称正确。

## 状态与生命周期

主线程保存已检查的 File 引用、尺寸及顺序；选择/追加通过整批检查才原子提交，失败保留旧列表并撤销旧下载。检查/生成期间禁用选择、排序、删除、参数和生成；取消、清空可用。取消保留已通过列表，清空恢复默认配置并回焦。

每次失效递增版本、终止 Worker、清除计时器及撤销下载 URL。成功消息核对版本与类型，原子创建下载；错误映射固定中文码，不回显原异常、文件名或内容；文件名仅 Vue 文本插值展示。30 秒超时直接终止，pagehide/卸载清除文件/参数、bitmap/worker 和下载引用。Worker 不输出解析日志。

## 全站接入与验证

新增敏感路由/路径，审计所有客户端/静态/预览路径判断，防止沿用普通页面已加载 GA。现有分类、指南、索引及精确路径审计更新到 14 工具、22 HTML、14 指南；正式八页索引不扩容。不执行生产候选、打包或部署。

算法测试覆盖限额等值/超限、格式伪造/截断、PNG/JPEG 像素及几何；实际浏览器覆盖 createImageBitmap/OffscreenCanvas/EXIF 1～8 和透明 PNG，不能用 Worker mock 当解码证据。组件 mock 只验证事务列表、重排、版本、取消/超时/参数失效及 URL 生命周期。E2E 使用合成 A/B/C 图，下载结果核对页序/尺寸，再用现有独立 PDFKit 辅助工具渲染检查颜色/方向/白底/边距。禁止用真实私密图片充当样例。

执行类型、单元/组件、CSR/SSG、静态清单、历史身份、广告准备和 Chromium/WebKit 回归；保存源码/产物摘要、截图、失败与修正。Firefox/真实手机/读屏/系统保存仍分别记录，不预填通过。

## 2026-11-07 实现授权

负责人在上述具体规格、限制及路线提交后明确要求“继续开发”，本轮据此批准 IMG-01～10 与 ADR-028 的本地实现和验证。历史待审阅状态保留为提案记录；不包含新依赖、生产打包、Git 写操作或部署。

实现细化：首版接受非隔行的普通 8 位 PNG（灰度、RGB、索引色及带透明通道类型），拒绝动画或隔行 PNG，允许经严格 TIFF/方向验证的 eXIf 块；JPEG 限 8 位灰度/RGB 基线或渐进编码。页面和指南明确显示这些兼容边界；JPEG EXIF 1～8 仍按原规格验证。

兼容核验修正：WebKit 自身生成的普通 PNG 含合法 eXIf 块，因此沿用同一严格 TIFF 方向解析及浏览器解码处理，不一概拒绝合法 PNG 元数据。重复/畸形方向块仍拒绝，输入元数据不复制到 PDF。合成 JPEG 方向样例先移除生成器已有 EXIF，再插入单份测试方向，避免构造互相冲突的元数据。
