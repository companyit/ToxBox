# 042 JSON 转 CSV 兼容扩展

日期：2026-11-13。负责人明确要求 JSON 转 CSV 支持完整 JSON 内容并做好非标准输入兼容，授权扩展既有019模块。保留040/041工作区改动；不新增依赖、上传、持久化或部署。

| 编号 | 可执行验收条件 |
| --- | --- |
| JCSV-01 | 默认兼容模式接受严格JSON及开头一个BOM、字符串外的行/块注释和末尾逗号；每项兼容处理明确提示，原输入不变。可切换严格JSON语法模式；不使用eval，不猜测单引号、裸键、缺值或缺引号，无法可靠解析时给固定中文说明及行列位置 |
| JCSV-02 | 对象数组按各记录字段首次出现顺序合并表头，缺失字段补空；单个对象作为一条含表头记录。空对象无字段时明确报错，不静默丢弃。含表头输出的记录统计不含表头；最多1000条数据记录、100列 |
| JCSV-03 | 二维数组允许字符串、数值、布尔、null及嵌套值；短行补空，最长行决定列数，保留记录并提示补齐。普通数组/混合数组按value单列含表头输出，基本根值作为一条value记录。空数组[]沿用空结果；全无列的数组明确报错 |
| JCSV-04 | 字符串、前导零和公式样式文本保留；数字按原始JSON数值词元输出，包括大整数/高精小数/负零/指数，不经过Number舍入。布尔输出true/false，null输出null文本；嵌套对象/数组保留为紧凑JSON文本，不自动展开或丢字段，说明CSV不保存JSON类型 |
| JCSV-05 | 可选记录路径使用JSON Pointer（如/data/items，~0/~1转义），留空转换根数据，不猜测接口包装字段。路径无效/不存在明确报错。拒绝同一对象重复键（含转义后重复）、非法Unicode/空字符；安全处理__proto__/constructor等普通字段，禁止原型污染。字段名换行规范化后冲突须报错，不合并或覆盖 |
| JCSV-06 | 原始输入100000码元、输出1000000码元、1000条记录/100列限制保留；JSON容器深度扩至30层，节点最多50000，路径最多1000码元。解析及输出有界，超限无部分结果。CSV→JSON仍按019严格CSV方言输出二维字符串数组，不推断表头或类型 |
| JCSV-07 | 页面增加清楚的JSON规则、完整对象/数组/嵌套/接口示例、语法方式与记录路径；示例不覆盖现有输入。编辑/切换选项/失败立即撤销旧结果和兼容提示，保留IME、复制版本保护、清空焦点和离页清理。所有提示不回显输入、键名或解析异常片段 |
| JCSV-08 | 同步指南/目录摘要/元信息及019当前范围，保持20工具/28HTML/20指南与既有SEO、统计、广告策略；验证算法、组件、SSG及三引擎真实流程、键盘/窄屏/错误/隐私。真实设备和系统剪贴板不由自动化代签 |

此次范围覆盖通用JSON到文本表格的映射，不宣称CSV能无损往返JSON类型。不增加文件导入下载、Excel、分隔符方言、自动展开深层字段、任意JS对象语法或自动选择接口数据。
