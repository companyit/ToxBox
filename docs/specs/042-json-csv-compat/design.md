# 042 设计

扩展019而不新增工具或路由。新增纯TypeScript jsonTable模块处理JSON兼容词法、有限深度递归读取和表格映射；csvJson保留原CSV状态机与有预算的字符串表格序列化，JSON分支将映射后的字符串表格交给同一序列化器。类型共享使用静态导入，不引入循环依赖或新包。

兼容扫描只在字符串外将BOM/注释/合法末尾逗号替换为空白，保留原始偏移及换行用于错误定位；不删除空数组逗号、缺失值或连续逗号。解析器只接受JSON文法，字符串词元用JSON.parse解码，数值保存原始词元，映射使用Map保留字段出现顺序并拒绝解码后重复键，避免Number精度丢失和__proto__赋值。严格模式不做词法修复。

对象记录生成字段并集表头；矩阵按最大宽度补空；其他根数组/基本值生成value列。嵌套容器作为合法JSON文本放入单元格，数值词元及字段顺序保留。实际CSV字段CRLF/CR仍归一LF，嵌套JSON文本保留内部字符串转义。null使用null文本，缺失列用空字符串。表头换行归一后的同名冲突报错，不能静默合并。生成的表头不计入1000条数据记录；旧serializeTable公开函数的1000行/矩形/字符串契约保留。

JSON Pointer仅显式选择用户指定记录位置，逐段遍历Map/数组，拒绝无效转义、不存在的字段和越界索引；空路径为根值。不会自动从data/list等字段提取或丢弃其他内容。

页面状态新增JSON语法方式、记录路径、示例类型与固定兼容提示；所有影响结果的选项参与原有同步失效和复制版本保护。JSON示例涵盖对象数组、单对象、二维混合类型、混合数组和接口包装；填示例仅在输入为空时生效，接口示例同时设置记录路径。CSV方向保持原控件和键盘流程；清空/离页恢复所有本轮状态，不把输入放入URL/存储/日志。

测试重点是实际映射、数字词元精度、缺列/嵌套/空值、语法修复边界、重复键/原型键、资源限制及错误不泄漏。更新旧的“对象/数字必须拒绝”等断言为明确的新行为，保留CSV、序列化预算、隐私和生命周期检查。先运行单元/组件和类型，再重新preview构建、SSG及三引擎浏览器回归；保留首次失败和被测摘要。无正式打包或部署。
