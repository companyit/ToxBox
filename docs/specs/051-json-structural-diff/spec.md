## 目标与场景

候选开发者工具 `/developer/json-diff/`。输入原JSON和新JSON，按字段路径查看新增、删除和修改，区分类型与缺失字段；忽略排版和对象键的排列顺序。例如 `{"data":{"name":"甲","score":95}}` 与 `{"data":{"score":96,"name":"甲"}}` 只报告 `/data/score` 从95改为96。031/045/050文本与文件对比继续保持逐行语义。

## 排除项

不含JSON Patch生成/应用、自动合并、文件导入下载、忽略指定字段、按数组主键配对、数组集合/移动识别、正则过滤、兼容JavaScript语法、上传/存储、新依赖或服务。数字规则只用于结构比较，不改变003格式化、030 YAML或042/044 CSV数值语义。正式打包/部署独立授权。

## 验收示例

- 仅缩进/对象键顺序变化：0项差异；数组 `[1,2]` 到 `[2,1]`：索引0和1各一项修改。
- `{"a":null}` 到 `{}`：删除 `/a`，不能视为相同。
- `{"id":9007199254740993}` 到 `{"id":9007199254740994}`：修改 `/id`，展示两份原词元。
- `{"a/b":{"~key":true}}` 到 `{"a/b":{"~key":false}}`：路径 `/a~1b/~0key`。
- 一侧非法JSON或重复字段：保留两侧输入，无旧结果/报告/复制成功提示。
