> 2026-11-15：负责人批准 [050](../050-file-diff-capacity/spec.md) 后，文件对比扩为2 MiB、500000码元、5000行，使用独立位回溯算法、200行分页和按需完整报告，中文文件选择状态保持一致。此追加替代首版容量和立即展示完整报告的约定；UTF-8、本地处理、取消及10秒保护保持，031/032不扩容。实际结果见 [050验证](../../verification/050-file-diff-capacity.md)。

## 目标与场景

新增办公工具候选路径 `/office/file-diff/`，用户选择原文件和新文件，本地解码、预览文本，再主动逐行对比，定位新增/删除。与031粘贴文本入口独立，共用纯TypeScript差异算法和展示组件。

| 编号 | 可执行验收条件 |
| --- | --- |
| FD-01 | 每侧单文件，允许扩展名.txt/.md/.markdown/.csv/.json，大小写不敏感；accept仅辅助选择，处理时再校验。每份最多1 MiB，实际读取字节超限拒绝；MIME为空不单独拒绝，不只依赖MIME判断内容 |
| FD-02 | 仅严格UTF-8，允许开头一个UTF-8 BOM；拒绝非法编码、UTF-16 BOM、空字符及空白名单外二进制控制字符（U+0001～0008、000B、000C、000E～001F、007F）。不自动猜测GBK/UTF-16、不静默替换坏字节。文件扩展名只表示候选，不承诺检测所有二进制格式 |
| FD-03 | 解码后每侧最多100000个UTF-16码元、1000行，沿用031换行规则：CRLF/CR统一LF、空字符串0行、末尾换行保留空行。空文件合法；CSV引号内换行也按文本行对比，JSON/Markdown不解析或渲染 |
| FD-04 | 两侧均读取成功才可开始；预览只读，显示本地文件名、字节数及文本行数。结果逐行显示双方行号、增删/保留统计，支持仅看变化、交换两侧、复制纯文本报告和清空。替换按删除加新增，不宣称字符级/语义/二进制/版式差异 |
| FD-05 | 更换任一文件立即清除旧差异/报告及该侧旧内容，其他侧成功输入保留；读取失败不显示旧成功。使用每侧读取代次和全局对比版本，快速重选、交换、清空、取消或离页后迟到读取/Worker/复制反馈不得恢复内容。读取中禁止交换和开始；允许取消并保留其他侧已加载内容 |
| FD-06 | 文件读取及对比采用同源Worker，在读取前做size检查、读取后再次校验byteLength；每侧读取10秒、对比10秒保护，可终止。错误固定中文，不附文件名/正文/原始异常；失败保留文件选择或提示重新选择，允许同一文件重试；不返回部分结果 |
| FD-07 | 独立无第三方脚本敏感文档页；文件名/内容只在当前内存，不进请求、URL、日志、统计或存储。pagehide/卸载释放文件引用、文本/结果、Worker和计时器；不宣称物理擦除内存。仅用文本绑定，无HTML/Markdown执行 |
| FD-08 | 两侧文件控件标签明确、可键盘操作、可见焦点、polite状态播报；375/768/1440px无页面横向溢出，200%字号可操作；长文件名可换行。复制仅在Promise成功后反馈，失败可手动选中报告，不读取剪贴板 |
| FD-09 | 实现后才接入办公目录、搜索、相关工具、指南、类型/路由和SSG空页面。新增页默认noindex，不自动扩正式24页索引；成功接入后数量预计21工具/29HTML/21指南，必须按实际核对，不提前宣称完成 |

## 排除与验收

不新增依赖/后端/上传/存储；不支持DOCX/PDF/Office/图片、压缩包、文件夹、多文件批量、拖放、编码选择、忽略空白、CSV表格/JSON结构化比较或报告下载。文件翻译单独见046，互不自动授权。

算法与浏览器覆盖合法UTF-8/BOM/中文/emoji/空文件/换行、非法字节/UTF-16/控制字符、各资源边界、同文件重选、并发读取/取消/过期结果、增删统计及复制失败；既有031测试保持。类型/单元组件/SSG/身份核对及三引擎按实际结果记录，Firefox当前环境失败不能引用历史通过。人工设备/读屏/系统剪贴板及生产部署独立验收。
