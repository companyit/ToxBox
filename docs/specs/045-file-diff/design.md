# 045 设计

日期：2026-11-14。方案待审阅，未编码。依据[规格](spec.md)。

## 模块和数据流

新增纯模块fileText.ts负责扩展名/字节/BOM/UTF-8及解码后资源检查；TextDecoder('utf-8', {fatal:true})解码，不猜测编码。输入大小先查File.size，Worker读取后再查实际字节；扫描指定控制字符，diffLines统一限额/换行。不以扩展名或MIME保证文件可信。

新增fileText.worker.ts接收File和任务代次，读取/解码输出文本与行数或固定错误代码，不返回异常对象。FileDiffPage.vue各侧维护empty/reading/ready/error、文件引用、代次及Worker；主线程10秒到时终止任务，取消/重选释放旧Worker。对比复用textDiff.worker.ts与DiffTable.vue，保持031算法和页面不变；输入加载完成后才允许对比。

侧状态变化先使整个对比结果失效；交换只在两侧不读取时原子交换文件与文本，再失效报告。清空/pagehide/unmount递增代次、终止Worker、清除计时器/文件input.value和所有内容。读取失败仍可重选相同文件，事件处理捕获File后重置原生input值，页面状态保存选择和固定错误。状态播报不包含文件名/正文，文件名仅本地独立文本显示。

## 集成与验证

新增路由/页元信息/办公目录及指南，同时纳入既有敏感文档整页导航和无GA/广告策略。SSG只输出空态，不读取文件；不改正式索引白名单。按实际新页面清单更新SSG断言与runner页面集合，不降低原有检查。

算法测试独立构造坏UTF-8/UTF-16、BOM、控制字节、大小/码元/行数边界；对比用既有算法并验证完整流程。组件测试双侧读取竞态、过期消息、失败后重试、交换/清空/复制；真实浏览器用合成文件设置input，覆盖三宽度/刷新/独立脚本隔离及网络/存储/URL内容边界。测试文件不含真实隐私材料。
