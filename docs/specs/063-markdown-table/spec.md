# 063 表格转 Markdown（候选）

日期：2026-11-24。待负责人确认首版范围。建议入口为 `/office/markdown-table/`。

| 编号 | 验收条件 |
| --- | --- |
| MDT-01 | 可粘贴制表符分隔文本（默认，适合从表格软件复制）或显式选择逗号分隔 CSV。支持引号字段、字段内分隔符和双引号转义。首行默认作表头，可切换为自动列名并保留首行数据。 |
| MDT-02 | 生成 Markdown 管道表格，保留记录顺序、前导零和空字段。短行以空单元格补齐。单元格中的竖线、反斜杠等 Markdown 语法字符作字面转义，字段内换行转为 `<br>`；用户原有的 HTML 片段按文字输出。 |
| MDT-03 | 转换后并列提供表格预览与可复制 Markdown。预览用语义化表格和文本绑定，最多展示前 20 条；复制包含全部结果。编辑输入和选项时撤销旧结果。 |
| MDT-04 | 输入最多 100,000 UTF-16 码元，最多 1,000 条数据及 100 列，输出最多 1,000,000 码元。无效引号或超限时保留输入，不给出部分结果。页面本地处理，支持键盘与移动布局。 |

首版提供粘贴、转换、预览、复制。文件导入、反向转换、渲染富文本和新增依赖暂不纳入。
