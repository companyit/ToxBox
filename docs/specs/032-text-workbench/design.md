# 设计

纯TS textWorkbench 复用 cleanupText、analyzeText 的码点统计与 compareText/diffLines。先检验全部步骤和参数，再规范化输入；每步结果立即检验100k/1000行，统计只返回数量及是否变化，不保留中间文本。结果原子提交：output、original/final统计、stages与diff。步骤顺序与限额可审阅，不把资源限制称为所有设备性能承诺。

新增同源Worker返回白名单错误码/步骤号，10秒可终止。Vue管理动态步骤表单、两个预设、输入、结果和复制版本；配置变化deep watch立即废弃旧Worker。流程报告不插入用户参数，复制最终文本和复制报告分别处理。结果不回灌原输入。

从TextDiffPage提取只负责展示的DiffTable共享组件，保留同样table/行号/类型/主题/安全插值与CSS类，工作台在details内显示变化行，既有文本差异工具继续原有筛选与报告。新页面加入既有独立敏感文档组，不新增路由架构/依赖。

目标18工具（办公11/开发7）、26HTML含404、18指南。验证纯模块组合/顺序/原子失败、共享组件对应既有浏览器回归、工作台真实Worker、可控Worker超时/迟到消息、复制和存储边界；最终生产dist与包一致，未执行部署。
