# 032 文本处理工作台（复合功能）

负责人提出增加复合功能，本轮批准在现有工具能力上串联文本清理、统计和差异预览。复用现有依赖、纯TS模块和敏感Worker方案，不增加依赖或远端部署。

TW-032-01：独立办公工具 /office/text-workbench/，首页/办公目录可检索，noindex、无第三方脚本；原工具仍独立可用，正式八页索引不变。
TW-032-02：两套可见预设：“名单去重排序”=清理首尾空白→删空白行→按行去重→升序；“文案整理替换”=清理首尾空白→删空白行→普通替换，默认查找“旧称”替换为“新称”，执行前可见可改。应用预设仅修改步骤，保留输入并清除旧结果。示例不覆盖非空输入。
TW-032-03：支持1～8步，六种现有文本整理操作可重复添加、移除、上移/下移；替换使用普通文本字面匹配，不支持正则；每个查找/替换参数最多1,000码元，查找非空。按实际顺序执行，不智能猜测顺序，去重保留首次、排序遵循UTF-16而非拼音或自然数字。
TW-032-04：输入和每步结果均限100,000 UTF-16码元/1,000 LF分行（含结尾空行），超限不截断；CRLF/CR先统一LF；允许空结果继续后续步骤。某步失败则整批不发布部分文本，提示步骤号和固定中文原因，原输入及配置保留。
TW-032-05：成功显示规范化输入/最终结果的字符数（Unicode码点）与LF行数，每步操作及字符/行数变化；只读最终文本支持复制。原文/最终文本的逐行变化可展开，复用最短增删算法，修改为删除+新增。流程报告仅含步骤名称、数量和增删摘要，不含原文本或查找/替换参数，可主动复制及手动选择。
TW-032-06：Worker顺序执行并计算统计/差异，10秒超时、可取消；输入或步骤修改立即终止并撤销结果，迟到消息不覆盖。复制失败聚焦选中对应结果；中文组合输入期间禁用主动处理操作。清空/pagehide/离页清空输入、结果、报告与替换参数，终止Worker；不上传、持久化、日志或URL转传内容。

验收：两种预设和自定义顺序输出正确；修改顺序/重复步骤有可解释结果；空结果可串联、替换参数全局预检；中间超限/任意步失败无部分结果；统计与原最终差异一致，复制/清理/取消/超时有效；375/768/1440可用，已有文本差异页提取共享展示后行为不变。排除跨页隐式传递、流程保存、任意脚本、正则、上传文件和图片/PDF混合流水线。
