# 053 JSON结构对比文件导入

日期：2026-11-16。负责人明确要求实现JSON结构对比支持导入文件，按下列有界本地读取规则实施；扩展051排除文件导入的旧范围，不改变比较算法。

| 编号 | 可执行验收条件 |
| --- | --- |
| JFI-01 | 原/新JSON各有中文选择按钮，仅单个.json（大小写不敏感），可混合文件和手动输入；成功导入仅替换对应侧，仍可编辑，不自动比较，另一侧保持。文件名仅文本显示，不写入报告 |
| JFI-02 | 每份最多400000字节、解码后100000个UTF-16码元，须同时满足；严格UTF-8，保留原文、CR/CRLF、数值词元及开头BOM，不自动修复。读取阶段不解析JSON；BOM/坏JSON/重复键及结构预算仍在主动比较时报错，不用原生JSON.parse转换数值 |
| JFI-03 | 读取在同源Worker中执行，10秒超时，可分别取消。选文件后立即废弃旧比较/报告；加载中禁用比较、交换和示例。失败/取消/超时不清空已有编辑内容，可重新选择同一个文件，固定中文错误不回显输入、文件名或原始异常 |
| JFI-04 | 每侧独立读取版本，重新选择或编辑该侧终止旧读取，迟到结果不得覆盖；另一侧可独立导入/编辑。清空、pagehide、卸载终止全部读取并清除输入、文件状态、比较/报告，交换时文件来源随对应内容交换；手动编辑清除旧来源标记 |
| JFI-05 | IME期间禁止新导入及比较，组合开始停止当前侧读取；键盘按钮/可见焦点/44px目标、文件读取polite状态，375/768/1440无页面横向溢出。非法输入保留供修改 |
| JFI-06 | 浏览器本地处理，不上传/存储/记录用户文件与内容，无新依赖/路由/工具，22工具/30HTML/22指南及GA/广告/索引边界不变。052已有结果下载保留，不追加JSON报告下载或真实部署 |

400000字节上限用于解码前资源保护；100000码元JSON的UTF-8通常更小，最终码元限额仍独立检查。空文件可导入为空输入，比较时提示缺少输入。系统文件选择取消不改变原状态。明确选择文件表示替换该侧内容，只有读取成功才提交替换。
