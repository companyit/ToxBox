# 043 CSV 转 JSON 对象数组

日期：2026-11-14；2026-11-15获准实现，当前验证见[报告](../../verification/043-csv-object-output.md)。负责人要求继续更新模块、检查改进空间；本轮核对019/042及当前源码后提出此扩展，不将方向性要求追认为以下数据规则已批准。

## 目标与场景

CSV 转 JSON 当前仅输出二维字符串数组，不能直接生成常见接口使用的对象数组。为包含字段名的表格增加显式模式，例如输入 `id,name\n001,甲`，选择对象数组后得到 `[{"id":"001","name":"甲"}]`（页面以两空格格式化展示）。保留默认二维数组行为及042的JSON转CSV规则。

| 编号 | 可执行验收条件 |
| --- | --- |
| COBJ-01 | CSV方向提供“二维字符串数组（保留首行）”与“对象数组（首行作字段名）”；默认前者，禁止自动推断表头。默认模式输出及错误行为与019一致 |
| COBJ-02 | 对象模式首行只作为字段名，每条后续记录对应一个对象；字段值一律字符串，不推断数字、布尔、null、日期或嵌套JSON。001、大整数及公式样式文本原样保留，不执行公式 |
| COBJ-03 | 字段名不trim；空字段名或完全由空白组成的字段名拒绝，其他前后空白保留并解释规则。换行沿用019规范化；规范化后同名字段拒绝。固定中文错误可指出列号，不回显字段名或输入。__proto__/constructor/prototype作为普通自有字段安全输出，不修改原型 |
| COBJ-04 | 空源维持无内容状态；仅有合法表头时输出[]、统计0条记录和表头列数；空字段值保留。列数不齐、非法引号、非法Unicode仍按019拒绝，不自动补齐或丢列 |
| COBJ-05 | 保留100000输入码元、100列、1000000输出码元。对象模式允许1条表头加1000条数据记录，默认二维模式仍最多1000条总记录；引号内换行不计新记录。输出预算必须计入每条对象重复的字段名、转义及格式化，不返回部分结果 |
| COBJ-06 | 切换输出模式立即清除旧结果、错误和复制反馈，保留输入；只在CSV方向展示控件。清空/离页恢复默认，组合输入和异步复制版本保护沿用既有行为。示例按模式提供，禁止覆盖已有输入 |
| COBJ-07 | 更新页面说明、指南、元信息及019当前范围；22工具/30HTML/22指南和索引政策不变。完成算法/组件/静态及三引擎流程验证，保留375/768/1440px与键盘验收证据；人工设备/读屏/系统剪贴板不代签 |
