日期：2026-11-14。状态：2026-11-15获准实施，当前验证见[报告](../../verification/043-csv-object-output.md)。关联[规格](spec.md)、[任务](tasks.md)。

## 模块与数据流

复用src/utils/csvJson.ts四状态CSV解析器，向转换选项增加独立csvOutput模式；缺省保持原行为。JSON输入选项及jsonTable.ts不改语义。parseCsv接收显式记录预算，默认1000，对象模式1001；不放宽serializeTable公开契约。

流程：输入限额→BOM/Unicode/换行处理→严格CSV解析与矩形检查→按模式分支。对象模式先校验表头非空白及Set精确去重，再将后续行转换为安全记录。使用Object.create(null)和自有字段写入，避免__proto__赋值副作用；JSON.stringify负责字符串转义，不拼接未经转义的原文。JSON对象的整数样式字段枚举顺序可能按运行时规则变化，说明不承诺JSON字段文本顺序；值与字段对应关系必须保持。

重复字段先经过既有换行规范化，不做trim或大小写折叠。空白字段判定采用JavaScript trim后为空，但有效字段仍原样保存。所有错误使用固定代码与中文消息，不传递字段名或解析异常。

## 资源与界面

对象序列化前逐项估算两空格JSON输出长度，计入每条记录的键名重复、字符串转义、冒号、逗号、换行及缩进；超限及时拒绝，完成后核对实际长度。保留原二维序列化路径以限制回归范围。

CsvJsonPage增加有标签的CSV输出选择和对应说明/示例。模式纳入同步invalidate监听、清空、pagehide和卸载恢复；复制继续依赖版本和结果快照。结果统计不含表头；仅表头的[]可复制。无自动转换、无自动拿结果覆盖原输入。

## 验证与待确认

算法覆盖模式缺省兼容、表头/空源/仅表头、空值、带引号的逗号和换行、重复/空白字段、原型字段、前导零/精度/公式样式、1000/1001数据记录、100/101列以及重复长字段导致输出超限。与JSON.parse后的期望对象比较并断言自有字段及原型未变；预算与实际输出独立对照。

组件覆盖换向/模式变化失效、输入保留、示例保护、清空焦点、IME及复制迟到反馈。浏览器覆盖从目录进入、两模式实际转换及错误恢复、三宽度键盘/布局、刷新清理与既有隐私断言。执行现有类型、Vitest、SSG、身份核对及三引擎runner，记录首轮失败和源/产物绑定；不以模拟DOM替代浏览器。
