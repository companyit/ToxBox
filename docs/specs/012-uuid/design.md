# 012 UUID 生成设计

关联：[规格](spec.md)、[任务](tasks.md)。状态：2026-11-03 获授权实现，实际验证见文末报告。

## 模块、数据流与异常

独立 `src/utils/uuid.ts` 通过显式注入的安全随机字节提供者生成 v4：生产适配使用 crypto.getRandomValues，纯格式化逻辑设置版本和 variant 位。组件只在客户端用户操作时检查能力、生成并显示，SSR 不访问随机源。

数量校验独立于生成；生成整个批次成功才更新结果，异常显示固定中文错误。复制快照加版本检查，编辑、清空和卸载使旧反馈失效；使用只读多行结果框。测试用固定随机字节验证位掩码，不以随机重复概率作为测试依据。
