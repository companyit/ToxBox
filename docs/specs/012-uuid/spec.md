# 012 UUID 生成

日期：2026-11-03。状态：2026-11-03 负责人明确授权实现，已完成本地功能；跨浏览器完整矩阵及负责人最终验收尚未全部完成。按 Base64 → 时间戳 → UUID → 工具搜索顺序推进。关联产品需求 P1-11。

## 目标、范围与验收

用户生成 UUID v4，单次或批量复制，拟路径 `/developer/uuid/`。

| 编号 | 可执行验收条件 |
| --- | --- |
| UUID-01 | 默认生成数量为 1，明确点击后才生成；数量只接受十进制整数 1～100，原始数量输入最多 3 字符；拒绝空值、小数、指数、零及超限 |
| UUID-02 | 输出小写 UUID v4，格式为 8-4-4-4-12，版本位为 4，variant 位为 8/9/a/b；使用 Web Crypto 安全随机源，能力缺失则中文提示，不降级到 Math.random |
| UUID-03 | 批量结果每行一个，提供全部复制和清空；复制失败支持手动复制；修改数量立即清除旧结果，失败不展示旧结果；不承诺绝对唯一性或将 UUID 当作密码 |
| UUID-04 | 结果仅在页面内存，清空和离页释放引用，不进入 URL、日志、分析事件或存储；预渲染只显示空工具界面，不提前生成 UUID |
| UUID-05 | 首页、开发者分类及相关工具有入口，独立标题、说明和预渲染正文，新页 noindex |

排除：UUID v1/v3/v5/v7、自定义格式、文件导出、历史记录、后端与新依赖。

## 共同质量要求

键盘完成核心操作，标签、可见焦点、错误及结果状态可被辅助技术感知；375、768、1440 CSS 像素无页面级横向溢出。输入使用文本绑定，不用 innerHTML。复用现有 Vue 3 + TypeScript + Vite、路由及 SSG，不新增依赖、持久化、内容埋点或部署。现有 2FA 文档隔离必须保留。
