# 057 正则表达式测试设计

关联[规格](spec.md)。

- 页面负责输入、选项、执行状态与分页。纯 TypeScript 模块构造原生 RegExp，内部加入全局匹配标志。结果逐项包含起止位置和捕获值。按 UTF-16 下标记录位置，零长度匹配后根据 Unicode 模式推进，并在越过末尾后结束。具名捕获用有序条目传递。
- 每次执行启动独立同源 Worker。页面管理两秒计时器和执行版本。超时、取消、重新执行、编辑或离页时终止 Worker，丢弃迟到消息。错误消息使用固定中文，不展示原始异常或输入。
- Worker 最多保留 500 条并探测第 501 条。结果限制为 200,000 个返回文本码元及 20,000 个匹配和组条目，总预算在构造每项结果时检查；超限后整次失败。浏览器以保持等待的测试 Worker 验证主页面仍可操作，真实 Worker 用于匹配语义测试。
- 验收覆盖语法错误、大小写、多行、跨行和 Unicode 标志、零长度结果、未参与与空捕获、匹配与输出上限、取消与离页清理。浏览器另测 375 像素布局、键盘、无数据外发及静态索引和脚本边界。
