# 057 正则表达式测试

日期为 2026-11-20。状态为负责人回复「确认」，授权按 RXT-01～04 实现。

开发者可在浏览器里核对 JavaScript 正则表达式对样本文本的匹配位置和捕获组。入口为 `/developer/regex-tester/`。

| 编号 | 可执行验收条件 |
| --- | --- |
| RXT-01 | 输入原始模式文本，通过独立控件选择 `i`、`m`、`s`、`u`，主动点击测试后执行。默认按原顺序查找非重叠匹配。模式为空时提示填写，样本文本允许为空。语法错误用固定中文提示并保留输入。 |
| RXT-02 | 显示匹配序号、文本及 UTF-16 起止位置（结束位置不含）。展示编号和具名捕获组，区分空字符串与未参与匹配的组。无匹配时明确提示。零长度匹配能前进，Unicode 模式下按码点前进。 |
| RXT-03 | 模式最多 1,000 码元，样本最多 50,000 码元。每页 50 项，最多展示前 500 项；检测到第 501 项时提示预览上限。匹配及捕获组返回数据有独立大小上限，超限显示固定中文提示。执行由同源 Worker 完成，最多两秒，可取消。输入或选项变化、取消、清空或离页撤销旧结果。 |
| RXT-04 | 结果按纯文本展示，键盘可执行、取消及翻页，状态可播报。复用敏感页面隔离，浏览器本地处理，页面 noindex、无统计或广告。接入目录、搜索、指南和静态页面。 |

范围限只读测试，不含替换、跨文件搜索、外部请求、其他正则引擎、共享链接或新依赖。现有文本整理与文本工作台继续使用其字面匹配规则。
