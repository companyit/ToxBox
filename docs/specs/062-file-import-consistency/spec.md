# 062 三个工具的文件读取交互

2026-11-23。负责人选择文件操作一致性。范围为 NDJSON、JSON 结构对比、文件对比。

- FIC-01：文件按钮旁显示支持类型、编码以及每份文件的字节和解码上限。三个工具沿用各自的容量。
- FIC-02：统一读取中、取消及超时提示。每份文件最多读取 10 秒，读取中可取消并回焦文件按钮，重选、编辑或离页使旧读取失效。
- FIC-03：失败、取消或超时保留上一份有效输入。文件对比仅在新文件读完后替换该侧文本，选入新文件时撤销旧对比结果。读取失败使用固定提示，不包含文件名或内容。

FIC-02 回归验收：NDJSON 读取过程中，用户执行转换或逐行校验，操作使用编辑区当前内容，读取提示与取消入口保留。新文件成功填入后撤销原结果，等待用户处理新内容；读取失败或取消时保留当前输入和结果。

FIC-02 键盘回归验收：文件对比和 JSON 结构对比的读取成功、失败或超时后，若同侧取消按钮持有焦点，文件选择按钮接续焦点。用户已把焦点移至其他控件时，读取结束后焦点留在该控件。按 FIC-03 检查异常结束后旧输入仍可使用。
