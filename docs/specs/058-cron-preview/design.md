# 058 Cron 执行时间预览设计

关联[规格](spec.md)。用独立 TypeScript 模块将五字段解析为有序值集及日字段通配标记，先校验整条表达式再查找。起算时间复用严格的 UTC 分钟校验。按公历日期检查月份和日条件，只在匹配日期上组合已排序的小时与分钟，达到十次或八年边界即停止。输出按时间正序去重。

页面复用日期选择、文本互填与响应式操作区的现有交互，结果独占一行。验证包含起点排除、周末跨越、闰日、月末、星期 0/7、日期与星期组合、非法输入及无结果上限。

配置文本可能涉及任务运行规律，页面复用现有敏感文档隔离，无统计和广告。八年终止日在目标年月缺少同日时取该月末，结果可包含终止分钟。

CRN-06 将表单配置映射为原有五字段语法，继续使用现有触发计算，不增加调度功能。缺少起算时间时先保留表达式，再引导填写。
