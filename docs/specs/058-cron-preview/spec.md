# 058 Cron 执行时间预览

2026-11-21。负责人要求继续开发，按 CRN-01～05 实施。入口为 `/developer/cron-preview/`。

| 编号 | 可执行验收条件 |
| --- | --- |
| CRN-01 | 输入五字段数字表达式，依次为分钟（0～59）、小时（0～23）、日期（1～31）、月份（1～12）和星期（0～7，0 与 7 为周日）。支持通配符、列表、递增范围和通配符或范围上的正整数步长。拒绝字段缺失、多余字段、倒序范围及越界值，指出出错字段。 |
| CRN-02 | 日期和星期同时受限时满足任一即可；其中一个为通配形式时，两项都须满足。日字段仅接受单独的 `*`、`*/步长` 或无星号列表，避免混合星号的兼容歧义。 |
| CRN-03 | 起算时间为 UTC，可选择或手输 `YYYY-MM-DD HH:mm`，并显示接下来最多 10 次触发时间，严格晚于起算分钟。示例 `0 9 * * 1-5` 从周五 09:00 起算时，下一次是周一 09:00。 |
| CRN-04 | 表达式上限 256 码元，最多查找之后八个公历年且结果年份不超过 9999。上限内无匹配或不足 10 次时明确显示；编辑后清除旧结果。 |
| CRN-05 | 浏览器本地预览，支持键盘操作、移动布局，接入工具目录、搜索、指南和静态页面，预览页 noindex。 |

首版范围是计算触发时间。秒字段、任务命令、宏、月份和星期缩写、Quartz 专用语法、设备时区、夏令时与任务调度均不纳入。

日字段语义参考 [Cronie crontab 手册](https://github.com/cronie-crond/cronie/blob/master/man/crontab.5)，兼容范围以上表为准。

CRN-06（配置与验证整合）：现有工具提供每天、工作日、每周选日、分钟步长四种可视化配置。生成五字段表达式并填入原输入；已有 UTC 起算时间则立即计算。生成后的表达式仍可手输调整。分钟步长从每小时第 0 分钟重新计算，界面明确说明。
