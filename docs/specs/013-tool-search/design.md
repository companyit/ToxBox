# 013 工具搜索设计

关联：[规格](spec.md)、[任务](tasks.md)。状态：2026-11-03 获授权实现，实际验证见文末报告。

## 模块、数据流与异常

独立 `src/utils/toolSearch.ts` 接收只读工具列表和查询，返回保持原始顺序的 preview 工具；名称和简介统一大小写后使用 includes 匹配。分类分组由首页对过滤结果派生，不改写数据源。

首页管理查询、错误及焦点，搜索只影响目录区域，hero、旧书签迁移入口和隐私区保留。无匹配时保留可理解的目录区域标题及一个全局空态，隐藏空分组。结果数量使用 aria-live=polite，避免逐卡重复播报。搜索框不使用可被自动表单采集识别的提交行为，实际网络验收确认查询未发送。

## 接入及验证

仅修改首页目录展示及独立过滤模块，不新增路由或静态文件。前三项验收后再实现本项，过滤结果应包含届时已有的全部 preview 工具。

新增纯函数边界测试、组件交互测试和浏览器关键流程验证；运行现有类型检查、CSR/SSG 构建及相关回归，记录实际命令、结果、浏览器版本和限制。复制成功/失败、编辑失效、清空及离页均需验证；检查请求、URL 与存储无输入和结果泄露。新增页面还需验证直接访问、导航、尾斜杠和静态输出。
