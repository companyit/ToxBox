# 013 工具搜索

日期：2026-11-03。状态：2026-11-03 负责人明确授权实现，已完成本地功能；跨浏览器完整矩阵及负责人最终验收尚未全部完成。按 Base64 → 时间戳 → UUID → 工具搜索顺序推进。关联产品需求 P1-02。

## 目标、范围与验收

在首页按工具名称或简介搜索，保留现有分类浏览，不新增搜索页面或 URL 参数。

| 编号 | 可执行验收条件 |
| --- | --- |
| SEARCH-01 | 首页提供有可见标签的搜索框，输入即按名称或简介子串过滤；查询去首尾空白、忽略大小写，不做拼音、分词或模糊匹配；空白查询显示完整目录 |
| SEARCH-02 | 保留办公/开发者分组及原目录顺序，只显示匹配工具；无匹配分组不显示卡片；全局零结果显示中文提示和清除条件按钮，清除恢复全部并将焦点返回搜索框 |
| SEARCH-03 | 提供结果数量，通过温和 live region 通知；键盘可输入、清除和打开结果；查询上限 100 UTF-16 码元，超限显示错误并暂停结果展示，不截断输入 |
| SEARCH-04 | 只提供实际 preview 工具的可点击入口，planned 工具不作为可用结果；查询不改变原始目录、相关工具或分类页面内容 |
| SEARCH-05 | 查询仅存在首页组件内存，不写 URL、日志、分析事件或存储；清空、离页或刷新后恢复初始状态；不把查询发给远端；SSG 默认输出完整目录 |

排除：搜索历史、联想、拼音、远端检索、查询分享、分类页搜索及新依赖。

## 共同质量要求

键盘完成核心操作，标签、可见焦点、错误及结果状态可被辅助技术感知；375、768、1440 CSS 像素无页面级横向溢出。输入使用文本绑定，不用 innerHTML。复用现有 Vue 3 + TypeScript + Vite、路由及 SSG，不新增依赖、持久化、内容埋点或部署。现有 2FA 文档隔离必须保留。
