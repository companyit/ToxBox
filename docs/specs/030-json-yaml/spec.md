# 030 JSON ↔ YAML 转换

负责人选择该功能，并在依赖确认请求后要求“推动”，本轮授权yaml@2.9.1及相应锁文件/许可证更新，并实施下述范围。

JY-030-01：独立开发者工具页 /developer/json-yaml/，首页/分类可检索，默认 noindex，保持正式八页索引清单。
JY-030-02：支持 JSON → YAML 与 YAML → JSON，输入和结果分别展示，明确转换按钮、清空、主动示例及复制；错误不破坏原输入，输入/方向改变即撤销旧结果；已有输入不被示例静默覆盖。
JY-030-03：处理 JSON 可表达的数据：字符串、布尔值、null、有限数值、数组及字符串键映射。YAML 采用1.2 core 单文档，支持常用块/流式结构、注释、带引号及多行字符串；注释、原始排版与锚点不保留，不承诺文本往返一致。不自动识别日期对象；yes/no按字符串处理。
JY-030-04：拒绝重复键（JSON及YAML）、锚点/别名、合并键、自定义/显式类型标签、多文档、复杂/非字符串键、非有限数值及超出安全整数范围的整数；说明小数遵循JS浮点精度，不承诺十进制任意精度。严禁悄然覆盖键或将不支持类型转成字符串。
JY-030-05：输入100,000、输出1,000,000 UTF-16码元，嵌套最多30层、节点最多20,000；不截断。Worker可取消，10秒超时终止，过期消息不覆盖新输入。错误仅中文白名单信息及行列位置，不输出原始输入片段至错误/日志/URL。
JY-030-06：仅浏览器内存处理，不上传、不持久化、不加载第三方脚本；与敏感工具独立文档策略一致。离页/pagehide清空并终止Worker，复制失败允许手动选中复制。

验收：典型对象/数组/顶层值双向结构一致；多行字符串、空字符串、中文及类型有明确测试；重复键、别名循环/膨胀、深度/体积/超时与迟到消息拒绝；375/768/1440、键盘、复制失败、静态空页面与隐私边界通过。排除文件上传、远程链接读取、YAML格式化器、编辑器依赖和服务端功能。
