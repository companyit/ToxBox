# 025 一键生产打包

负责人于本轮明确授权整合正式打包命令。

REL-025-01：`npm run build:release` 从仓库根执行类型检查、production 候选构建、正式包导出与独立校验，读取已批准正式域名。无需手填版本号或 SHA。

REL-025-02：每次使用唯一 ID，保留历史包；输出仅含 site 文件的 tar.gz、SHA256 与包外来源记录。失败退出非零，不宣称成功，不部署、不修改服务器或安装依赖。

验收：实际执行命令成功；解压归档后文件集合与摘要和正式包一致；说明可直接定位包、域名及上传方法。现有 CSR 和 preview 命令保持含义。

## 本轮追加：直接使用 dist

负责人明确授权生产命令直接输出根目录 dist/。REL-025-03：完成生产校验后，将完整 site 文件输出至 dist/，不存在旧版本残留；只包含可公开文件。已有 dist 先保留至本次移交目录，输出失败恢复原目录。拒绝符号链接目录。不改动 build:csr 含义；其后执行仍会将 dist 改为 CSR 产物。
