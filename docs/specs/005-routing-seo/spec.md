# 005 路由与 SEO 需求规格

日期：2026-10-10。阶段：M1-05B / Implement + Verify，已获安装Router4与客户端迁移授权；不授权发布。M1-02～04 已达到 Dev Done（依据负责人本轮确认），Release Ready 遗留保留。

依据：[产品需求](../../product/requirements.md) P1-01、02、07、08，[前端架构](../../architecture/frontend.md)、[决策](../../architecture/decisions.md) ADR-004、005、009、014 及草案 ADR-016、017、[门禁](../../quality/gates.md)。既有工具语义以 [002](../002-text-statistics/spec.md)、[003](../003-json-formatter/spec.md)、[004](../004-url-encoder/spec.md) 为准。

## 目标、范围与审批边界

让用户从首页或分类页进入具有稳定地址的独立工具页面，共享网站布局，建立一致的导航、元数据与发布准备约束。以下客户端迁移方案已获批准；实际实现与验证证据见任务和验收归档。M1-05B 建议只实现路由迁移与客户端元数据；静态预渲染、托管配置及站点地图产物另行授权，不自动归入 M1-05B。

不开发新工具算法、搜索功能、账户、存储、后端、分析或广告；不引入 Pinia，不更改三个工具的计算、输入上限、数值安全和复制语义，不保证收录或排名。

## 页面与静态元数据建议

统一站点根路径部署、尾斜杠规范，路径区分大小写；具体域名未知。标题均追加 `｜WorkDev Tools`，首页标题除外。关于页只陈述产品定位，不编造作者履历或联系方式；隐私页说明本地处理、无自动持久化、剪贴板权限与静态资源正常网络请求，不能宣称整个网站完全无请求。

## 需求与可验证验收标准

| 编号 | 行为 | 验收标准 |
| --- | --- | --- |
| RSEO-01 | 路由和共享布局 | 使用明确批准的 Vue Router 4 HTML5 History；8 个已知页面及 catch-all 可访问；每页仅一个 main 和一个 h1，页头页脚共享、导航有当前页语义；不使用 hash 路由替代独立路径 |
| RSEO-02 | 工具发现与首页迁移 | 首页和分类卡片链接到对应独立页面，办公仅文本统计、开发者仅 JSON/URL；未完成工具无虚假链接；首页移除三个交互实例，旧 3 个工具锚点保留迁移说明与真实工具链接；原分类、隐私锚点仍有目标；全站链接不再称“本页试用” |
| RSEO-03 | 工具复用和内存生命周期 | 独立页面无需再点展开即可操作；复用现有纯函数和工具交互组件；离开路由卸载实例、重入及刷新为空，输入/结果不进入路由参数、URL、日志、存储；待完成复制回调不污染新页面 |
| RSEO-04 | 历史与直接访问 | 8 页分别测试直达、刷新、新标签打开、前进后退；已知无尾斜杠路径在提交前规范化，保留导航push/replace意图且不增加多余历史；原查询/片段可保留导航但不充当工具输入；不自动打开外部结果 URL |
| RSEO-05 | 托管回退与资源边界 | 发布前在经授权的 Cloudflare 等效环境验证全部已知页 HTTP 200；缺失资源、未知页面及未来 /api/ 路径不能被无差别改成首页 HTML 200；记录本地 Vite 预览与托管的差异 |
| RSEO-06 | 404 双层行为 | 客户端未知路径展示中文 404、返回首页链接、noindex 且无 canonical；明确客户端导航无法修改已收到的文档 HTTP 状态；发布前直达未知路径返回真实 HTTP 404 并验证 body，不能以客户端文案代替 |
| RSEO-07 | 页级元数据 | 8 页切换、直达和返回均符合上表，唯一 title/description、lang=zh-CN、页面说明和单一 h1；元数据只来自静态目录；移除首页“首批正在规划中”的过期描述；404 不继承上一工具元数据 |
| RSEO-08 | canonical 和规范 URL | 域名未批准、本地/预览不生成生产 canonical；正式模式必须校验批准的 HTTPS origin，缺失或非法则阻止正式 SEO 产物生成；每个已知页最多一个绝对 canonical，路径与表一致，去 query/hash；404 无 canonical；不从 window.location.origin 猜正式域名 |
| RSEO-09 | sitemap 与 robots | 仅在正式域名、收录策略及产物生成获批后按同一静态目录生成；sitemap 仅含获批可索引的已知规范页，不含未知、片段、查询、API、预览域名；不编造 lastmod；预览 noindex；robots 不当作访问控制，也不靠禁止抓取来保证读取到 noindex |
| RSEO-10 | 静态渲染评估 | 按设计比较 A/B/C 七个维度并记录审批结果；若 B 获批，禁 JS 的 HTML 含各页 h1、说明、导航、独立 head，启 JS 后无 hydration mismatch、重复挂载或用户输入泄漏；未经实现只标待验证 |
| RSEO-11 | 焦点、滚动与通知 | 新页导航完成后焦点落主标题/主内容且可见；返回/前进恢复保存滚动，不被 focus 滚动覆盖；首次加载不抢焦点；有效 hash 滚动并聚焦目标，缺失目标安全回页首；页面变更 polite 通知一次，不逐键播报标题 |
| RSEO-12 | 响应式与可访问性 | 375×812、768×1024、1440×900 无页面级横向溢出；Tab/Shift+Tab/Enter、跳过导航、200% 缩放、实际读屏可用；移动设备和目标浏览器记录具体环境，桌面视口不替代真实手机 |
| RSEO-13 | 既有工具回归和质量 | 原 62 文本、33 JSON、39 URL 自动化用例保留预期并通过；首页展开测试按批准迁移变更，不能删除算法/复制竞态测试掩盖失败；三工具真实浏览器验证输入、异常、清空、复制及切页卸载；类型、构建通过 |
| RSEO-14 | 后续 API 演进 | 文档预留 /api/v1/ 服务命名空间，用户页面 URL 保持不变；API 不纳入前端 fallback/sitemap；本阶段无请求、接口占位实现或后端，未来上传等须另行 ADR 和授权 |

## 质量门禁与证据

M1-05A 完成指文档可审查，不等于 Dev Done。M1-05B Dev Done：获批范围实现（RSEO-01～04、07、08 的客户端部分、11～14）、对应自动化/类型/构建通过、真实浏览器核心路由与三工具回归通过、无已知核心或隐私阻塞缺陷，托管/域名/预渲染等遗留逐项归档；RSEO-05、06、08～10 的发布部分不能据此勾选通过。

Release Ready：在 Dev Done 上完成 RR-01～07，尤其 RSEO-05 托管深链、RSEO-06 HTTP404、RSEO-08 正式 canonical、RSEO-09 正式 SEO 产物及 RSEO-10 渲染评估后的批准方案验收；完整兼容性、设备、无障碍、隐私和性能验证不得沿用迁移前结果冒充迁移后通过。预渲染建议若被暂缓，必须由负责人批准理由和 SEO 风险，而非默认仅 CSR 即发布就绪。搜索实际收录只能记录后续观测，不能作为已保证的结果。

M1-05A起草时测试未执行；M1-05B实际结果见任务文末，不将发布项改成通过。测试计划与追溯见 [tasks](tasks.md)，实现方案与待批准事项见 [design](design.md)。生产发布独立授权。
