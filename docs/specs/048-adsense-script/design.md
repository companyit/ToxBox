# 048 设计

配置增加明确的4条allowedPaths，adScriptEnabled=true。独立纯工具从配置判断广告页面和生产文档边界；SEO head模型增加可选adsenseScript。生产SSG将精确URL加载器写入白名单静态head，客户端保留既有相同脚本、避免重复；preview模型无加载器。

生产路由守卫按原始文档路径是否属于广告白名单，与目标路径比较，跨边界使用location.assign并等待新文档，不把已执行脚本从DOM移除当作隔离。原敏感页面守卫独立保留，避免与GA隔离分组混淆。白名单仅内容/目录页，工具页无广告脚本，未新增输入上传。

首页摘要沿用隐私政策已说明的正式版本范围，就近提供完整说明链接。

候选静态资源验证只允许精确AdSense加载器例外，其余资源规则保持。validateAdSenseDocument在mode/path明确时核对唯一正确head脚本和meta，额外脚本/手工广告位拒绝；广告准备资源审计允许批准加载器URL字面量，但拒绝手工push和未知发布商ID。

生产测试拦截所有外部请求，对精确加载器返回本地哨兵脚本，不从Google取代码；全页head/接管一致、4页白名单、普通工具与文件工具双向导航隔离、开关/重复/错页负向均有验证。preview测试继续无广告执行。正式本地构建遵循现有门禁，不部署。
