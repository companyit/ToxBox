### 人工验收步骤

1. `npm run dev` 后进入首页，点击卡片试用链接，确认到达真实文本统计分区；展开工具，检查唯一 h1、分区 h2 和页头三个锚点。收起并重开确认清空，刷新确认空输入，不尝试把预留路径当作已实现页面。
2. 输入 spec 的各样本，实际粘贴 CRLF、中英文和 Emoji，记录输入框实际值；使用中文输入法验证组合期间“输入中”和结束后统计；非空（含纯空格）时示例禁用且不覆盖。
3. 分别输入 100000/100001 码元、50000 个 Emoji，检查保留完整文本、超限结果为破折号、错误与手动复制提示同时可见，删除回上限后恢复；清空后检查五项为零与焦点。
4. 实际点击复制并粘贴到其他本地编辑器核对空白；在安全上下文、无 API、权限拒绝场景检查手动回退、选区和中文提示。延迟复制 Promise 后编辑/清空/收起，验证旧操作不污染新状态。
5. 在 375×812、768×1024、1440×900、200% 缩放及系统明暗模式下检查布局，使用 Tab/Enter/Space 验证操作；检查读屏标签、通知频率和对比度，四种浏览器各两个主版本记录真实环境。
6. 用唯一标记输入，检查 Network/Application/Console/地址栏无内容泄漏。测试不依赖远端服务，工具不使用 v-html。记录收起重开、刷新后的数据状态。
7. 按 spec 在 Mac mini M4 和真实手机生产预览各样本测 10 次，记录纯函数及 input 到绘制的全部耗时。未执行前不声称满足 50ms/200ms 或 Lighthouse 目标。
