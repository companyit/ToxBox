# 002 文本统计需求规格

状态：M1-02 / Implement + Verify，2026-10-10 用户已批准统计语义及本轮实现；禁止安装依赖和生产发布。

## 目标与范围

免登录输入或粘贴文本，本地实时显示字符总数、去空白字符数、词段数、总行数和非空行数，提供示例、清空与复制原文本。手机和桌面端均可使用。非空行数保留产品 P1-03 约束，总行数满足本次补充需求，两者分别标注。

不包含准确中文分词、字素簇计数、文件导入、字节统计、历史保存、云同步、后端、数据库、广告或外部统计服务。不上传输入，不将输入写入 URL、日志、存储或分析事件。

## 统计语义（已确认）

### 字符与 Unicode

统计函数接收原始 JavaScript 字符串，不裁剪、不进行 NFC/NFKC 规范化。字符总数按 Unicode 码点遍历：有效代理对算 1，孤立代理项防御性计为 1；不是 UTF-16 length，也不是屏幕上的可见字形数量。换行符和空白同样计入总数。

CRLF 的 CR 和 LF 在字符总数中分别计数（共 2），但在行数中是一次换行。文本框/操作系统可能把粘贴的 CRLF 转成 LF；页面统计实际输入框值，不声称恢复剪贴板原始换行字节。

例如 😀 为 1；👍🏽 为 2；👨‍👩‍👧‍👦 为 7；🇨🇳 为 2；e + U+0301 为 2，而预组合 é 为 1；变体选择符、ZWJ、组合附加符均分别计数。界面显示“字符按 Unicode 码点计数，Emoji 组合可能包含多个字符”。

### 空白集合与去空白字符数

统一空白集合 W 为以下码点，空白检测、词段边界和非空行判定共用此集合：U+0009～000D（Tab、LF、VT、FF、CR）、U+0020、U+00A0、U+1680、U+2000～200A、U+2028、U+2029、U+202F、U+205F、U+3000、U+FEFF。

去空白字符数只排除 W，保留其他码点。明确不排除 U+0085、U+180E、U+200B、U+200D；零宽空格/连接符不自动当作空白。使用固定集合避免依赖模糊的“所有不可见字符”。所有 W 成员须分别纳入测试。

### 词段数

词段数为按 W 分隔的连续非空白片段数量；连续空白只作为一个边界。中文连续文本算一个片段，中英文相邻且无空白仍是一个片段；英文标点不拆分，纯标点和 Emoji 片段也计数。使用标签“词段数（按空白分隔）”，说明“不是准确中文分词，也不是自然语言词数”。不使用 Intl.Segmenter 或外部词库，避免浏览器间语义漂移。

例：“你好世界”=1，“你好 world”=2，“你好world”=1，“hello, world!”=2，“... 😀”=2。

### 行数

逻辑换行包括 CRLF、单独 CR、LF、U+2028、U+2029；CRLF 优先匹配为一次。Tab、VT、FF、U+0085 不作换行。自动折行不增加行数。

空字符串的所有结果均为 0；非空字符串总行数等于换行次数 + 1，末尾换行保留一个空行。“\n”总行数为 2，非空行数为 0；“a\n”总行数为 2，非空行数为 1。非空行指至少含一个不属于 W 的码点，纯空白行不计入非空行数。

## 输入规模与实时更新

支持最多 100,000 个 UTF-16 码元，以原输入 string.length 检查，界面明确该上限与字符统计口径不同；这是资源保护限制，不是字符统计结果。有效输入不截断。超过上限保留当前输入并显示超限错误，所有统计显示“—/超出限制”，不得显示陈旧结果；不运行完整统计，允许删除、清空和复制。回到上限以内自动恢复。

初始显示 0；普通 input 事件后不需点击统计，在 200ms 内刷新结果。中文输入法组合期间保留输入，显示“输入中”，允许暂停统计；compositionend 后 200ms 内更新。性能验收用生产构建：Mac mini M4 及一台记录型号的真实手机，在 10k/100k 码元中英文混合、含换行/Emoji 样本各连续测 10 次；从 input/组合结束到结果绘制的最大耗时应不超过 200ms，纯函数每次不超过 50ms。记录浏览器、设备、样本与各次耗时；未测不得承诺达标。若目标不达成，先评审调整策略，不擅自引入 Worker 或更改限制。
