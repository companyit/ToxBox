# 011 时间戳转换设计

关联：[规格](spec.md)、[任务](tasks.md)。状态：2026-11-03 获授权实现，实际验证见文末报告。

## 模块、数据流与异常

独立 `src/utils/timestamp.ts` 使用数值时间与显式年月日拆分，不调用 Date.parse。UTC+08:00 通过固定偏移换算；校验日期分量往返一致，处理 Date 对 0～99 年的特殊行为，并验证偏移后的 UTC 输出范围。秒转换先核验安全整数和乘法范围。

组件管理方向、单位、固定时区、输入及结果；时间计算不读设备当前时区。复制与编辑状态遵循 010 的版本失效规则。错误使用固定中文说明，不回显原始值。
