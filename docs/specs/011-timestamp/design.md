# 011 时间戳转换设计

关联：[规格](spec.md)、[任务](tasks.md)。状态：2026-11-03 获授权实现，实际验证见文末报告。

## 模块、数据流与异常

独立 `src/utils/timestamp.ts` 使用数值时间与显式年月日拆分，不调用 Date.parse。UTC+08:00 通过固定偏移换算；校验日期分量往返一致，处理 Date 对 0～99 年的特殊行为，并验证偏移后的 UTC 输出范围。秒转换先核验安全整数和乘法范围。

组件管理方向、单位、固定时区、输入及结果；时间计算不读设备当前时区。复制与编辑状态遵循 010 的版本失效规则。错误使用固定中文说明，不回显原始值。

## TIME-06 分钟输入设计

日期转时间戳提供日期、小时、分钟表单，以及可粘贴已有日期文本的入口。秒和毫秒在高级输入中提供。两种输入由时间戳页面整理为统一格式，再调用现有纯 TypeScript 换算模块。模块在比较日期往返值前，将缺省的秒和毫秒补齐，继续严格核验日期、时间和 UTC 偏移边界。表单以日期分量传值，避免引入设备时区。修改任一输入或选项时撤销旧结果。

TIME-07 以文本草稿作为共同输入；选择器提供分钟值，手输可附加秒和毫秒，统一由原换算模块校验。

TIME-08 由时间戳页面启用紧凑工作区样式，复用共享编辑器状态。表单选项分组，结果在输入下方独占一行，选择器及手输字段按可用宽度布局。

TIME-09 通过共享编辑器的可选属性提供输入提示和结果上下文。结果上下文与转换选项使用同一状态，手输和选择控件在宽屏顶对齐。
