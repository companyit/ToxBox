# 011 时间戳转换

日期：2026-11-03。状态：2026-11-03 负责人明确授权实现，已完成本地功能；跨浏览器完整矩阵及负责人最终验收尚未全部完成。按 Base64 → 时间戳 → UUID → 工具搜索顺序推进。关联产品需求 P1-10。

## 目标、范围与验收

用户明确选择秒或毫秒，在 Unix 时间戳与日期间双向转换，拟路径 `/developer/timestamp/`。

| 编号 | 可执行验收条件 |
| --- | --- |
| TIME-01 | 默认秒、UTC；支持秒和毫秒整数及负数，不根据位数猜测；时间戳 `0` 对应 UTC `1970-01-01 00:00:00.000`，秒 `1` 与毫秒 `1000` 结果一致 |
| TIME-02 | 日期输入采用显式 `YYYY-MM-DD HH:mm:ss.SSS`（年份 0001～9999），严格核验闰年、天数及时间；仅支持 UTC 和固定 UTC+08:00，界面明确标注，不依赖设备时区或宽松 Date 字符串解析 |
| TIME-03 | 时间戳仅接受可安全表示的十进制整数、可选负号，拒绝指数、小数和超范围值；输出日期须处于上述年份范围；毫秒转秒向负无穷取整，`-1` 毫秒对应 `-1` 秒，说明精度损失 |
| TIME-04 | 单字段最多 64 UTF-16 码元；空输入无结果，超限或非法值中文提示并保留输入；修改输入、单位、时区或方向立即清除旧结果 |
| TIME-05 | 示例、清空、复制及失败手动复制可用；全部本地处理，不存储或采集内容；独立入口、预渲染正文及 noindex |

排除：自动识别单位、设备本地时区、IANA 时区与夏令时、自然语言日期、实时时钟和新增依赖。

## 共同质量要求

键盘完成核心操作，标签、可见焦点、错误及结果状态可被辅助技术感知；375、768、1440 CSS 像素无页面级横向溢出。输入使用文本绑定，不用 innerHTML。复用现有 Vue 3 + TypeScript + Vite、路由及 SSG，不新增依赖、持久化、内容埋点或部署。现有 2FA 文档隔离必须保留。
