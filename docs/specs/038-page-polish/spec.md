# 038 页面布局与展示文案优化

日期：2026-11-12。负责人明确要求优化页面、移除“试用”字样并调优整体布局，本轮按该授权实施以下展示调整。

| 编号 | 验收条件 |
| --- | --- |
| UI-01 | 实际可用工具卡片不显示“试用”标签，入口统一“打开工具”；About/Terms 移除试用阶段措辞，保留实际功能限制与责任说明，不额外宣称通过任何审核 |
| UI-02 | 首页增加办公/开发者分类快捷锚点及动态数量，保留搜索、旧书签迁移和完整目录；搜索零结果仍可清除，分组和快捷入口随匹配结果一致 |
| UI-03 | 首页与分类目录统一 1/2/3/4 列（手机、640、1024、1280px 断点），卡片等高、文字完整、入口易识别，320/375/768/1440px 无横向溢出 |
| UI-04 | 首页留白、搜索框和分区层级更清晰；工具页标题与描述留白收紧，维持工作区宽度、输入高度及已有操作行为 |
| UI-05 | 链接保持语义化、44px 可操作区域、可见焦点、深浅模式和减少动态效果偏好；类型、构建与对应浏览器验证实际记录 |

内部 preview 工具状态与 SEO preview 模式继续承担既有技术用途，不因移除展示文案更改；不改工具算法、依赖、分析、广告、索引或发布配置。本轮不覆盖现有构建入口/工作流等用户改动，不部署。
