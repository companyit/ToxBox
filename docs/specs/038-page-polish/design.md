# 038 设计

ToolCard 仅对 planned 保留“规划中”，可用卡片统一操作入口；样式使用现有 CSS 变量，不加图标包。首页基于现有搜索匹配列表生成分类快捷入口与数量，不新增持久化状态或请求。两类目录共享同样断点，宽屏四列利用现有 1280px 容器，卡片说明完整保留，入口对齐底部。hover 位移仅在无减少动态偏好时启用。

ToolPageLayout 只调整标题尺寸、描述行宽与上下间距，不碰各工具表单与算法；分类页增加实际数量展示。About/Terms 只去除阶段措辞。新增局部展示规格，依据负责人本轮明确要求执行，无新架构决定。

验证：类型检查、现有单元/组件、SSG/构建；浏览器覆盖首页/两分类/典型工具的 320/375/768/1440px、搜索、分类锚点、全站无试用文案、深浅模式与焦点，并保存截图。现有未提交构建变更按实际脚本运行，所有结果区分本轮新验证与历史证据。
