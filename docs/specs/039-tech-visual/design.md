# 039 设计

在 base.css 定义背景、表面、主辅色、淡网格、光晕和阴影的深浅主题变量，以现有 CSS 变量驱动所有工具控件。背景细节限制于首页发现面板，正文及工作区保持平稳底色。

HomeView 将现有 hero/search 组合成发现面板，使用 CSS 渐变及网格，不增加网络资源；分类锚点继续由搜索匹配列表派生。ToolCard 通过工具 ID 判断文件/图片/文本/时间/安全/代码图标，使用 aria-hidden SVG 和静态 path 数据，不加图标库。入口、说明、焦点和规划状态保留。SiteHeader 用半透明背景（无滤镜环境退化为实色）和明确当前项背景加强层次。

主标题以品牌强调色点缀、深色模式采用低亮度底与高对比正文；不将整段文字设为低对比渐变。卡片 hover 仅在无减少动态偏好时平移，图标无循环动画。正文/指南/隐私保持原有内容和数据边界。

验证现有类型、组件、静态及生产构建；复用 038 浏览器测试覆盖首页/分类/工具、搜索/焦点、浅色/深色截图，人工查看桌面与手机样图，计算主文本/次文本/按钮对比；Firefox/真实设备矩阵未验证的如实记录。
