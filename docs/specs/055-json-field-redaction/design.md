# 055设计

关联[规格](spec.md)。状态：负责人选择后按JRD-01～07实施，当前证据见[055验证](../../verification/055-json-field-redaction.md)。

复用jsonReader的严格语法、Map对象、精度数值词元及Unicode/深度/节点保护，避免使用原生JSON.parse解析源数字。路径配置同样用严格读取器读取为字符串数组，不执行代码；JSON Pointer验证/解码和逐段定位为纯TS，先完整校验全部路径及重叠，再替换，不返回部分成功。

读取树不通过普通对象属性赋值映射字段，保留Map原型安全。路径采用解码段数组检查重复及前缀重叠；根空指针是任何其他路径的祖先。数组数字下标执行规范形式与现有长度检查，对象数字样式键仍按字段精确处理。对合法目标使用固定字符串替换，新的精度保留序列化器输出两空格JSON，逐段累计输出预算后再拼接；不修改现有CSV/结构对比编码器语义。

同源Worker只接收源文本、路径配置和替换字符串，返回结果/替换计数或固定错误代码/配置序号/语法行列；不发送原异常。页面负责编辑、示例、取消/10秒超时、版本、复制与按需下载，复用既有敏感页边界和URL回收机制，无新架构服务或依赖。

验证原型字段、精确大整数/指数、根与容器替换、特殊字符/换行键/空字符串、~0/~1、数组下标、缺失/重复/重叠、所有资源边界与输出预算；组件验证失败保持输入、迟到任务/复制、清空/IME/下载回收；浏览器三宽度、两引擎真实UTF-8下载、来源隔离和无数据外发，静态页面及数量检查同步。Firefox与人工设备/读屏缺口单独记录。

如负责人选择URL参数解析或正则模块，本候选保持待选，不据此实现或扩充其他模块。
