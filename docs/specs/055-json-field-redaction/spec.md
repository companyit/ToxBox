## 目标

将接口或配置JSON中的指定字段替换为固定字符串后，再复制或保存用于分享的样例。仅处理明确指定路径，不自动识别或保证清除所有敏感信息，用户须核对结果。拟页面/developer/json-redact/。

| 编号 | 可执行验收条件 |
| --- | --- |
| JRD-01 | 粘贴严格JSON，支持全部根类型；指定目标使用JSON字符串数组形式的JSON Pointer，例如["/data/email","/users/0/phone"]，避免换行字段和空指针歧义。明确点击后处理，保留原输入，不自动扫描敏感字段 |
| JRD-02 | 对象字段按原名称、数组按索引定位，~0/~1解码，根用空字符串指针。数组下标只接受0或无前导零的非负整数，不追加数组项；路径不存在、重复或祖先/后代重叠时整次失败，不返回部分结果，不猜测通配符或点分路径 |
| JRD-03 | 默认替换文本***，可改为最多200码元的普通字符串，空字符串允许；任意选中类型或容器整体替换成JSON字符串，未选字段和数组次序保持。数字保留原始词元，不经过浮点舍入；拒绝重复键、BOM、注释、尾逗号、非法Unicode及空字符 |
| JRD-04 | 源JSON最多100000码元、30层容器、50000节点；路径配置最多10000码元、100条路径、每条1000码元；结果最多1000000码元，超限不截断。同源Worker10秒保护、可取消，编辑/选项变更/重新处理/清空/离页废弃旧任务与结果 |
| JRD-05 | 输出两空格JSON、替换项数，结果仅文本绑定；支持复制与UTF-8无额外BOM的redacted.json下载。成功反馈不先于复制完成，失败可手动复制，迟到反馈不得覆盖新状态；下载按点击生成，输入变化或离页释放对象URL |
| JRD-06 | 固定中文错误可指出配置项序号及语法行列，不回显字段名、路径、输入片段或原始异常；示例不覆盖已有输入，IME期间不执行，清空回焦。375/768/1440与键盘/可见焦点/状态播报可操作 |
| JRD-07 | 独立本地敏感文档页，不上传/记录/持久化输入或结果，不加载统计/广告，与现有整页隔离一致。接入目录/搜索/指南/SSG，新增页noindex；实施后预计23工具（办公14/开发9）、31HTML、23指南，正式24页索引及四页广告白名单不扩大 |

排除：自动识别手机号/邮箱、正则匹配、通配符路径、保留前后若干字符、加密/可逆处理、文件导入、嵌套分享链接、持久化模板、上传/后端/模型/新依赖。正式打包与部署另行授权。
