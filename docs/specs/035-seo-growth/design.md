# 035 设计

[规格](spec.md)、[任务](tasks.md)。

使用独立静态索引清单集中记录24个路由名和路径，页面模型、SEO环境批准集合、JSON配置及SSG共同交叉校验。新增工具不能自动获索引；遗漏/重复/未批准项目失败。原8页约束由本轮显式政策替代，默认preview保护保留。

页面元数据维护唯一用途标题及准确摘要；工具h1保持原产品名，页面说明/指南支持元信息，不堆叠关键词。首页短说明和两分类摘要更新实际能力，保留原布局和入口数量。

纯TS orderTools仅按静态用途优先级返回新数组；工具目录唯一导出排序结果，首页/分类/搜索共用，不依赖用户数据或网络。未列出的工具置末且同优先级保持原顺序。

createPageHead扩展structuredData，只在具备正式canonical时创建：主页WebSite，分类/工具BreadcrumbList；其名称与实际导航一致。共享序列化将小于号及U+2028/U+2029转义，防止script结束标签注入；SSR head与applyPageHead共用，使用专属data属性管理单一节点、去重与清除，无执行脚本或远端上下文请求。生产候选语义检查逐页对比JSON-LD模型，拒绝多余/错误标记；preview禁止残留。

沿用显式production候选测试，不使用build:release或覆盖根dist；校验24canonical、sitemap全等与4noindex HTML，敏感工具仍不加载GA。测试覆盖排序稳定/不改输入、配置负向、SSR/DOM清理与结构化数据转义、无JS首页/分类说明及链接，并执行原有双引擎工具回归。实际上线后的HTTP头、robots获取、提交站点地图和自然搜索曝光另行记录。
