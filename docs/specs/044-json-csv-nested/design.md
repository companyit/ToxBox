# 044 设计

先使用042读取器保留数字词元及Map，再按root/each作用域选择记录，最后按既有文本或展开模式构造表格。each在选根之前执行，对每个对象调用既有JSON Pointer选择器，拒绝缺路径/非对象；先检查行数，避免超量映射。

展开遍历只进入非空Map，数组和空Map作为叶节点。字段段名先转义反斜杠再转义点；Map及全表字段并集保持首次出现顺序，换行冲突沿用已有检查。每条记录展开中检查列限制，不生成无界字段数组。现有读取器深度/节点和输出序列化预算继续适用。

页面新增两个select，纳入同步invalidate与releaseContent；示例只在输入为空时设置路径/模式。指南解释转义、数组和逐条提取限制。验证针对用户两记录样例、默认兼容、精度、空对象、异构字段、转义碰撞、路径错误与资源限制，组件覆盖失效/清理；浏览器使用既有runner和三宽度模块流程。
