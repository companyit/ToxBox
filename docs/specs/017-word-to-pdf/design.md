日期：2026-11-03。负责人已选择浏览器本地路线；具体导出流程与依赖仍待确认。关联：[规格](spec.md)、[任务](tasks.md)。

## 模块和数据流

组件管理单个 File、任务、状态、受限预览和主动打印。独立 TypeScript 模块负责规格常量、错误码、ZIP/文件校验、转换结果模型和打印状态；同源 Worker 顺序完成 ZIP 预检和 Mammoth 转换，不在主线程解析 DOCX，不写日志，不发请求。

File/ArrayBuffer → Worker 预检 → 转换器 → 受控 HTML 和已验证图片数据 → 主线程安全内容模型 → Vue 文本/白名单节点预览 → 用户明确点击打印。模板标题、错误与下载说明固定，不把文件名带入 document.title 或打印页标题。SSR 仅输出说明/空选择表单，不访问 File、Worker 或打印 API。

ZIP 预检使用明确声明的 JSZip 直接依赖，并在逐条解压流消费时统计实际字节、条目、单 XML 和合计上限，超过立即暂停/拒绝并终止 Worker。先核对原始条目名/规范路径及重复项，拒绝加密、宏及路径穿越；必要主文档和内容类型必须匹配。XML 外部实体和外部关系不能导致任何远程/本机文件读取。压缩输入限制不等于实际内存安全，Worker 终止不保证设备永不耗尽内存，因此必须用畸形和高膨胀样例验证保护。

Mammoth 显式 `externalFileAccess: false`、`includeEmbeddedStyleMap: false`，只采用应用内固定映射；自定义图片处理器只接收有实际字节校验的 PNG/JPEG，输出内部占位 ID，不将原文档 URI 或原 HTML 直接挂载。库原始 warning/error 可能带输入，不直接显示或记录，映射为固定中文状态。

## 预览与图片边界

把转换 HTML 放在不挂载的 template 中解析，仅遍历允许的段落/标题/列表/表格及文本格式节点，重新构造有数量限制的内容模型；从不挂载原始节点，不复制 style、URL、事件或任意属性。不使用 v-html，不把字符串中的标签/图片路径拼接成活跃文档。受支持的表格跨度只接受有界正整数；链接保留文字，主动内容丢弃并提示。

图片只以受控占位 ID 与经过校验的内部 PNG/JPEG 数据匹配；主线程再核验类型、签名和像素限制，创建有限生命周期 Blob URL。外部 URI、SVG、HTML 和无法匹配的图片均不渲染；图片不作为网络资源加载。图片失败或不支持时明确提示，不能宣称完整保留。

## 打印与生命周期

首版建议使用浏览器打印，不再添加 PDF 生成引擎。采用专用打印节点（Teleport 到固定打印根）及受控 @media print 样式，打印时隐藏整个网站其他区域，仅显示同一安全内容模型。A4 竖向、基本页边距、表格/图片最大宽度由应用设置；实际纸张、缩放和浏览器页眉页脚由系统对话框决定，不承诺可强制关闭。

点击时先确认任务/预览版本有效并等待图片/字体就绪，再调用 window.print。afterprint 只表示对话框结束，不代表成功保存，不存储打印历史。清空/pagehide/卸载/重新选文件终止 Worker、撤销 Blob URL、释放预览和打印模型；版本号阻断旧任务。沿用 016 的独立敏感文档组，进入或离开不得继承 GA/广告，既有 TOTP 行为不变。

## 依赖和实际验收

拟新增 mammoth@1.13.0、jszip@3.10.1 及必要锁定传递依赖；上游 Mammoth 声明浏览器入口、BSD-2-Clause 和 JSZip 依赖，安装前须核验实际发布与完整依赖图，不擅自将主仓库最新源码当成已发布稳定包。只把解析库放入懒加载 Worker，审查同源 worker 产物、包大小、许可通知及严格资源白名单。未执行安装、audit 或样例，不能宣称已安全/兼容。

合成 DOCX 样例覆盖中文、列表、表格、PNG/JPEG、分页、外链、宏类型拒绝、缺失主文档、畸形 ZIP、实际解压超限、嵌入样式映射、危险链接和内容节点上限。记录错误保留、取消/重选竞态、离页清理及双向文档隔离。验证所有请求无文件内容，第三方脚本不执行。浏览器 print 测试不能只 mock API；预览之外，Chromium 可生成打印 PDF 作结构检查，并需人工核验支持浏览器的实际另存为 PDF、中文和跨页结果，不能假称自动化检查证明系统保存成功。

执行现有类型、单元/组件、CSR/SSG、静态/历史身份/广告准备审计及 Chromium/WebKit 核心流程。更新准确工具、页面、指南数量，不放宽现有检查，不扩大索引/广告策略。生产包及部署另行授权。
