# 017 Word 转 PDF（浏览器本地 DOCX 简版）

日期：2026-11-03。负责人明确选择“文件始终留在浏览器，先支持 DOCX 简版转换，接受字体、表格和分页差异”。据此确认本地路线，不新增服务、上传或持久化。以下首版范围、打印导出方式和新依赖待审阅及明确实现授权。关联 P1-15。

## 目标与范围

拟路径 `/office/word-to-pdf/`。选择 DOCX → 本地转换 → 阅读简版预览与限制 → 主动点击“打印 / 另存为 PDF”，在浏览器系统对话框中选择保存为 PDF。此为重新排版，不是原 Word 版式复刻，也不提供静默直接生成 PDF 字节或自动下载。取消打印不提示“保存成功”，应用无法确认是否最终落盘。

| 编号 | 可执行验收条件 |
| --- | --- |
| DOC-01 | 仅单份 `.docx`，最多 10 MiB；拒绝旧 `.doc`、`.docm`、加密、损坏、无 Word 主文档或类型不符文件，不只信任扩展名/MIME。选择新文件立即使旧预览不可导出，错误保留选择以便重试，不展示旧成功 |
| DOC-02 | 解析在可取消的同源 Worker 中执行，任务保护时限 30 秒；ZIP 最多 1000 条目、实际总解压最多 50 MiB、单 XML 最多 10 MiB，拒绝重复/路径穿越/加密条目、宏内容和异常压缩包；不能仅信任 ZIP 声明的未压缩大小 |
| DOC-03 | 支持普通中文/英文段落、语义标题、列表、加粗/斜体、简单表格和内嵌 PNG/JPEG。图片最多 100 张、累计字节最多 20 MiB，每张最多 2000 万像素；输出文字最多 50 万字符、最多 5 万内容节点，超限拒绝。上述是产品保护值，不是已测性能承诺 |
| DOC-04 | 简版统一使用本机可用字体与 A4 竖向打印样式，表格/图片限制在页宽内；不保留原字体、表格宽度/边框样式、页眉页脚、文本框位置、原始分页、修订/批注和复杂公式。未支持的结构以固定提醒说明，不声称完全转换；基本内容缺失应按失败处理而不是空成功 |
| DOC-05 | 外链不作为可点击链接，保留可读文本；不加载外部图片、字体、关系引用或模板，不运行宏/脚本、不接受嵌入样式映射。预览由白名单内容模型构造，不直接插入转换器原始 HTML；javascript 链接、事件属性、表单、iframe、SVG/HTML 图片不得执行或进入打印内容 |
| DOC-06 | 转换成功后允许用户查看并主动打印；打印只含安全转换正文，不含网站导航、工具表单、真实文件名、页脚或广告。明确浏览器打印设置可能额外加网址/时间页眉页脚，需用户自行关闭；使用浏览器另存为 PDF，不把唤起对话框称为保存成功 |
| DOC-07 | 清空、取消、重新选择、pagehide、卸载终止 Worker、废弃迟到结果，清除文档模型及 Blob URL/打印节点，文件名和内容不进网络、URL、日志、分析或存储。文件页采用与 016/2FA 共用的无 GA/广告独立文档边界，不读取剪贴板 |
| DOC-08 | 原创指南、格式/排版限制、错误和进度状态完整；入口仅在功能实际实现后加入首页、办公分类、搜索及相关工具；SSG 输出空界面、不解析文件，新页 noindex，不扩大八页正式索引白名单 |
| DOC-09 | 键盘可选择/转换/取消/打印/清空，有标签、可见焦点和状态播报，375/768/1440px 无页面级横向溢出；中文、图片、简单表格、长段落跨页实测预览与另存 PDF，不以编译成功代替结果验收 |

## 依赖提案与待确认

拟新增 `mammoth@1.13.0`（上游声明 BSD-2-Clause）及 `jszip@3.10.1`（作为直接依赖用于 ZIP 预检，避免依赖未声明的传递包），与必要锁定传递依赖；不是此时已安装版本。安装前实际核验注册表、兼容性、依赖图、许可与安全记录；如版本不可用或存在不能接受的问题，停止确认，不默默换包或降低保护。

不新增字体下载包、CDN、PDF 生成库、后端、上传接口、DOC 支持、OCR、文档编辑器或持久化。待负责人审阅：DOC-01～09 限制、打印另存流程、两项依赖及必要 package/lock 更新、敏感文档隔离和实现授权。
