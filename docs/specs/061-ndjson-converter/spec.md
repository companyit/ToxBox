# 061 NDJSON 与 JSON 数组互转

2026-11-21。负责人回复「确认」，授权按 NDJ-01～05 实施。入口为 `/developer/ndjson/`。

| 编号 | 可执行验收条件 |
| --- | --- |
| NDJ-01 | 用户显式选择转换方向。NDJSON 方向按 LF 或 CRLF 分行，每个非空行必须恰好包含一个严格 JSON 值，支持对象、数组、字符串、数字、布尔值和 null。忽略空白行，报错使用原始行号，不返回部分结果。空白文本按零条记录处理。 |
| NDJ-02 | JSON 方向要求顶层为数组，每个元素输出为一行紧凑 JSON，保留顺序。空数组输出空文本。结果使用 LF，末尾不添加额外换行。 |
| NDJ-03 | 两个方向保留数字原始词元和对象字段顺序。拒绝重复键、BOM 和已有严格读取器判为无效的内容。错误不回显输入片段。 |
| NDJ-04 | 输入与输出各最多 200,000 个 UTF-16 码元，最多 2,000 条记录。NDJSON 单行最多 50,000 码元，整次转换最多 50,000 节点、单条记录最多 30 层容器。JSON 数组外层不计入单条深度，两个方向对等限制记录。 |
| NDJ-05 | 本地转换结果独占一行，显示记录数并可复制。修改输入或方向后撤销旧结果，离页清理。接入目录、搜索、指南、静态页及现有敏感隔离，页面 noindex、无统计和广告。 |

首版提供粘贴、转换和复制。文件导入、下载、流式转换和新增依赖不纳入。

## 2026-11-22 文件导入与下载

负责人确认继续推进文件工作流。新增 NDJ-06：按当前方向导入一份 UTF-8 文件，NDJSON 方向接受 `.ndjson` 和 `.jsonl`，JSON 方向接受 `.json`。最多 600,000 字节、解码后最多 200,000 码元。读取成功填入编辑区，用户主动执行转换。失败、取消或过期读取保留原输入及原结果。转换成功可按目标格式下载 UTF-8 文件，空结果可下载，内容与结果完全一致。

NDJ-07（逐行校验报告）：在同一工具内增加「逐行校验 NDJSON」模式，沿用 NDJSON 文件导入。一次统计通过和无效记录，最多列出前 50 条错误的物理行号与固定原因。不打印原文。到达总节点或记录上限时明确标出中止行和报告范围。未超出单行上限的空白行不计为记录。报告可复制，输入或模式变化后撤销。

NDJ-08（负责人选择整合方向 1）：完整校验通过后，结果区显示「转为 JSON 数组」。单次点击沿用当前输入与原有转换预算，切换至数组方向并执行。成功后可复制或下载；含错误、校验中止或输入变化时入口撤销。

## NDJ-09 数组结果排版

负责人回复「确认」，授权实现。

NDJSON 转 JSON 数组时提供「紧凑」和「易读（2 空格）」两种排版，默认紧凑，逐行校验后的直接转换沿用所选排版。易读排版不改变对象字段顺序和数字词元；空数组仍为 `[]`。输出上限包含缩进和换行，超限提示可改用紧凑格式，并保留原输入。复制和下载使用实际展示文本。
