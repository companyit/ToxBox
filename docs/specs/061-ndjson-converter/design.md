# 061 NDJSON 与 JSON 数组互转设计

关联[规格](spec.md)。

复用严格 JsonReader、Map 对象和值的数值词元。NDJSON 以物理行解析，记录已消耗节点数并逐行扣减总预算。JSON 数组读取后按记录深度约束校验，数组包装层单独核算。记录用现有严格 JSON 编码器输出。拼接时累计码元和记录数，检查单行限制和总输出后一次返回完整结果。

界面沿用工具页工作区模式，处理状态和错误用中文播报，区分成功的空结果与尚未转换。至少验证混合根类型、重复键、CRLF、空白行对错误行号的影响、空输入和空数组、精度词元以及全部资源上限。浏览器覆盖输入失效、键盘、响应式、复制行为和敏感页面隔离。

NDJ-06 使用可终止的浏览器 FileReader 和严格 UTF-8 解码，编辑、重新选择、切换方向、清空和离页使旧读取失效。下载在用户操作时创建 Blob URL，编辑、清空或离页回收。文件名和内容不写入日志、URL 或存储。

NDJ-07 复用 NDJSON 行扫描和资源预算。转换遇到首个错误即退出；校验收集固定诊断，遇到全局预算即停止，报告只汇总已检查记录。

NDJ-08 由校验返回明确的通过状态。模式切换后调用共享编辑器现有提交入口，用同一输入执行转换，并复用失效管理与下载。

NDJ-09 实现复用严格 JSON 读取器的数值词元与有序对象表示。缩进编码逐段累计输出码元，达到上限即退出，不对紧凑结果使用原生 JSON.parse 再格式化。在数组转换与校验直转中使用同一种排版设置。
