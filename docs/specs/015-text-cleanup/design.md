# 015 文本整理设计提案

关联：[规格](spec.md)、[任务](tasks.md)。日期：2026-11-03。状态：待审阅及明确实现授权。

## 模块与数据流

独立 `src/utils/textCleanup.ts` 负责换行规范化、输入上限、按行处理和普通文本替换，使用带操作类型的判别联合与类型化成功/空结果/错误返回；纯计算不访问 DOM、存储、日志或网络。组件负责操作选择、查找替换、说明、中文提示及剪贴板，复用已有视觉控件和 ToolPageLayout，避免把算法放进 App。

主输入 → 参数校验 → 换行规范化 → 单次计算 → 输出上限校验 → 结果。去重使用 Set 与原始顺序；排序使用显式比较器和索引相等时保序，不调用 localeCompare。去重前不 trim，用户需要组合整理时应主动将输出复制到输入执行下一步，工具不自动链式加工。

替换先校验原始查找文本非空，再按同样规则规范化换行；通过 indexOf 统计非重叠匹配，依据匹配数和长度差预估输出规模，超限即返回错误，不创建巨量字符串。替换文本以字面值拼接，不使用可解释 $ 替换语法的写法；查找长度受限，不运行正则。结果上限同时覆盖所有操作。

## 视图状态与隐私

状态分为空输入、编辑、成功非空、成功空结果及错误；成功空结果清晰播报并禁用复制。输入、查找、替换、操作变化均增加版本号并清空旧结果/反馈；复制使用快照及版本校验，过期 Promise 不覆盖新状态。输入法组合期间避免执行、清空或示例操作干扰输入。pagehide 和卸载清除数据与事件监听，离页不保存历史。

查找与替换仅在替换操作显示，但切换操作仍使结果失效。清空恢复默认操作并清除所有内容，焦点返回主输入。示例按当前操作提供，不静默覆盖非空输入。说明区解释去重保留空白及排序非拼音、字面替换、输入/输出限制。

## 接入与验证

拟增加页面定义、办公分类目录、路由、指南和首页实际工具概览；办公分类从 1 工具增为 2，站点从 14 页 +404 增为 15 页 +404。更新精确路径集合和数量断言、接入前审计的指南数量，不放松严格验证。不修改正式八页 SEO 索引清单、广告策略、Analytics 或 2FA 隔离。

算法验收覆盖所有操作示例、混合换行、末尾空行、Unicode/大小写、精确去重、固定顺序、重叠匹配、空替换、$ 字面值、各输入边界及结果膨胀拒绝。组件覆盖输入保留、空成功、修改失效、复制挂起/失败、输入法及离页清理。运行类型检查、Vitest、CSR/SSG 构建、静态清单、历史测试身份与接入前审计；Chromium/WebKit 实测核心流程、键盘及三个目标宽度，Firefox 已知环境限制如实记录。

新生产候选、打包及公网发布不随本规格自动执行；需要发布时重新生成绑定当前源的包，不沿用前一版本 SHA。无新增架构方案，若实现出现新依赖或数据边界变更则先登记决策并取得确认。
