## 范围与验收

拟路径 `/office/pdf-merge/`，将多份普通 PDF 的全部页面按用户列表顺序合并为一个下载文件。

| 编号 | 可执行验收条件 |
| --- | --- |
| PDF-01 | 本地选择或追加 2～10 份 PDF；每份最多 20 MiB，总计最多 50 MiB，总页数最多 500 页。上述为产品保护值，不是已测性能。检查扩展名、头部及实际解析，不仅信任 MIME；拒绝空文件、非 PDF、损坏和加密 PDF，不尝试破解密码 |
| PDF-02 | 显示本地文件名、大小、页数，可用键盘上移/下移和删除；不自动按文件名排序。相同文件重复选择视为独立项，明确保留列表顺序；一次追加批次任一文件失败则整批不加入，已有列表保持 |
| PDF-03 | 用户明确点击合并后处理，A 两页+B 一页输出三页；调换为 B+A 后顺序正确；保留页面尺寸及旋转，普通文字/图片内容不栅格化；不承诺文档级书签、表单、签名、附件、标签结构或权限完整保留 |
| PDF-04 | 首版拒绝存在 AcroForm 的文档（含常见表单/签名字段），不宣称完整检测所有签名类型；不提供签名有效性校验或修复。提示输出为新文档、不是安全清洗器，打开未知来源文件应谨慎；不在网页嵌入预览或执行 PDF 内容 |
| PDF-05 | Worker 负责解析和合并，串行读取/复制，不在主线程进行重处理。单任务保护时限 30 秒，可取消；超限、解析/序列化失败、输出超过 100 MiB 时不提供部分结果；中文错误不含文档内容或内部栈，保留原列表便于调整重试 |
| PDF-06 | 任意文件增删/排序使旧结果失效；取消或离页终止 Worker，迟到消息不覆盖新任务。输出使用 `application/pdf` Blob，本地点击下载为固定 `merged.pdf`，无远端链接；新任务、清空、pagehide、卸载撤销对象 URL、清除内存引用，不承诺物理擦除 |
| PDF-07 | 文件名、内容、页数、输出不进 URL、日志、存储、分析或网络；文件工具采用独立无第三方脚本文档边界，进入/离开不得继承 GA/广告，沿用并扩展已有 2FA 隔离。只选本地文件不等于上传，不新增文件服务器 |
| PDF-08 | 首页、办公分类、搜索、相关工具有入口；独立标题、说明及原创指南，SSG 渲染空选择界面，不读取文件或启动 Worker，新页 noindex、不扩大既有索引白名单 |
| PDF-09 | 列表重排不依赖拖拽；可见焦点、文件标签、错误播报和进度状态，进度不虚构百分比；375/768/1440px 无横向溢出。下载是否落盘由浏览器/系统处理，不把触发下载称为已保存到磁盘 |

## 排除

不含拆分、选页、OCR、压缩、签名、批注、编辑正文、加解密、页缩略图、图片转 PDF 或云存储。Word 转 PDF 单独决策，不复用 PDF 合并依赖冒充 Office 排版引擎。不使用 CDN 运行依赖。

依赖提案：`pdf-lib@1.17.1`（上游 package 声明为 MIT），以及其必要锁定传递依赖；安装前核验 npm 实际发布、兼容性和供应链，发现风险先停止确认，不擅自换包。尚未安装、未运行样例，不宣称已通过安全或性能验收。
