# 016 PDF 合并设计提案

关联：[规格](spec.md)、[任务](tasks.md)。状态：依赖、隔离和实现待批准。

## 边界与流程

Vue 组件负责 file input、显示、安全文本文件名、列表/键盘重排、任务状态和下载。独立 TypeScript 模块负责可测试的文件/总量限制及合并逻辑；pdf-lib 适配只在同源模块 Worker 中执行，使用 PDFDocument.load / copyPages / save，不在 App 集中业务。

选择新批次先在主线程核验数量/原始字节限制，再交给 Worker 串行解析检查页数、加密与 AcroForm。Worker 禁止把原异常、文件名或内容写入 console，返回项 ID 和类型化错误。解析通过后才原子更新列表。主线程保留原 File 引用，Worker 每次任务读取 ArrayBuffer，以可转移缓冲区发送，不提前并行读入全部文件。

合并按当前列表快照逐份加载、复制全部页到新文档，再序列化、校验输出长度。生命周期版本号与任务 ID 共同阻断旧消息。取消/时限/离页直接终止 Worker 并释放对象 URL；重新操作创建新 Worker。文件原始字节小不代表解析内存小，Worker 只能隔离主线程，不能保证浏览器不发生内存不足；先用保护规模和畸形样例验证，必要时降低限制再确认。

PDF 文档可能含动作/链接，copyPages 不是清洗器。首版不嵌入 iframe/object 预览、不承诺输出移除了所有主动内容；拒绝常见 AcroForm 对象，不把该检查等同完整签名识别或安全检测。文档级书签等不承诺保留，页面视觉需用已知非敏感样例实测。

## 第三方隔离

抽取并复用已有敏感文档路径/路由判断，使 TOTP 与 PDF 页均不加载 Analytics/广告，跨敏感边界使用整页导航。两种敏感工具可处于同一无第三方组，但组件卸载/整页 pagehide 均清除各自状态。SSR 不用 window/File/Worker；构建 worker 为同源 hash 资源，严格 SSG/候选/包校验若需支持新资源类型，明确更新白名单与负向测试，不关闭保护。

## 验证与批准门槛

批准 pdf-lib 精确版本、必要传递依赖及 package/lock 更新后才能安装。安装前后记录版本、锁变化、许可和真实 audit 结果；不以 audit 零告警等同无风险，不擅自升级其他依赖。补充第三方许可通知。

生成或使用公开无敏感内容的测试 PDF，覆盖页数/顺序/尺寸/旋转、边界、损坏、加密、表单、超时、取消、重排失效、撤销 URL、文件名转义与双向文档隔离。下载后重新解析结果并在实际阅读器做视觉对照，不能仅以编译或同库能解析判定版式正确。

执行类型、单元/组件、CSR/SSG、静态清单、历史身份、接入前审计与 Chromium/WebKit 核心验收，记录无法执行的阅读器/Firefox/真实设备组合。维护准确页面及工具/指南数量；新页 noindex，正式八页清单不变。只新增 PDF 合并，未完成 Word 工具不展示可用入口。发布另行授权。
