# 060 工具页布局设计

关联[规格](spec.md)。ToolPageLayout 承载统一的面包屑、标题、操作区和指南，保持交互就绪 fieldset 边界。为已有独立操作面板的页面设置外层无重复装饰；其余页使用统一操作容器。使用原生同页锚点和可聚焦目标，避免引入客户端导航状态。指南使用可折行的 CSS 网格，文档预渲染仍包含全部内容。打印时隐藏工具页导航和说明并去除新增操作区装饰。

TPL-05 将工具页指南捷径与面包屑放在同一可折行导航行，沿用原生锚点、已有聚焦目标及主题变量。页末隐私说明与链接分为说明及操作。

指南网格按工具容器宽度分成一列或两列，单节的分栏阈值沿用 26rem。适用场景放在使用步骤节的开头，短视口跳转后先看到节标题。输入或选择和结果采用描述列表，示例解释沿用现有工具指南数据。
