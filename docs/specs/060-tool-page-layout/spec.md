# 060 全站工具页布局优化

2026-11-21。负责人要求完成其余工具页优化。范围覆盖当前目录的 25 个独立工具，统一外层结构并纳入已完成布局优化的工具。

- TPL-01：工具页按标题、操作区、使用指南及隐私说明排列。已有独立操作区的页面沿用现有面板，其余工具使用统一的操作区边框、间距和焦点样式。
- TPL-02：指南保留案例、步骤、注意事项及问答。宽屏按内容分栏，窄屏保持阅读顺序。提供可用键盘操作的指南跳转和返回操作区入口。
- TPL-03：文本编辑器保留适合内容的初始高度。PDF 和图片仍使用现有原生文件控件及预览；不影响本地数据处理、结果、打印或下载。
- TPL-04：在两种浏览器遍历全部工具，校验宽窄布局、焦点和初始编辑器，回归文本工作台与代表性的转换及文件流程。

- TPL-05：工具页指南捷径与面包屑共享顶部区域，窄屏可折行。指南、返回操作及隐私链接提供无下划线的可点击外观和可见焦点；打印隐藏新增导航控件。

TPL-02／TPL-05 本轮验收覆盖 27 个工具。指南宽屏每行两节，窄屏单列按阅读顺序排列。示例的输入或选择、结果使用语义化的标签和值，保留解释正文。三个宽度验证列数、示例结构与指南往返键盘操作。
