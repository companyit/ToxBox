# 014 AdSense 接入前页面与内容准备

日期：2026-11-03。负责人要求按四个信任页面、独立域名、HTTPS、原创实用内容及清晰导航进行开发配置，随后明确确认“先完成页面、内容和接入前配置，暂不加载广告”，提供公开邮箱 `huangjemdev@gmail.com`。本轮按该确认范围实施；广告运行、远端账号、域名购买、DNS、证书签发及部署不在本轮内。

## 需求与验收

| 编号 | 需求及可执行验收 |
| --- | --- |
| ADS-01 | 更新 `/about/`：说明产品用途、七个实际工具、当前试用状态及维护反馈方式；不虚构公司、团队、资质、用户数量或广告已启用 |
| ADS-02 | 新增 `/contact/`：公开真实邮箱、可操作 mailto 链接、问题反馈建议和不要发送密钥/个人信息的提醒；无假表单、后端或收件承诺；说明邮件由用户自行发送并通过邮件服务处理 |
| ADS-03 | 更新 `/privacy/`：分开说明本地工具内容、静态请求、托管可能产生的访问记录、剪贴板、Google Analytics、外部联系、拟接入广告及隐私联系；广告未启用不能写成正在投放；保留 2FA 第三方脚本隔离；含更新时间、Google 隐私/广告设置链接 |
| ADS-04 | 新增 `/terms/`：服务范围、免费试用、合理使用、输出局限、知识产权、第三方链接、服务变化及联系；不虚构运营法人、适用法律或绝对免责；保留依法享有的权利 |
| ADS-05 | 全站页脚提供关于我们/联系我们/隐私政策/服务条款四入口；新页有独立标题、描述、单一 h1、路由、SSG 正文、尾斜杠与 404 验证；375/768/1440px 无横向溢出，键盘可用 |
| ADS-06 | 为现有七个工具分别提供原创使用场景、步骤、示例解读、边界提醒及常见问题；以实际算法行为为准，无虚构功能、复制文章或无意义凑字数；工具本地行为不变 |

| ADS-09 | 新页面保持 noindex，不扩大已批准八页正式索引清单；维持 preview SEO 合同。文档列出后续发布商 ID、审核、ads.txt、CMP、索引白名单及托管验证的具体步骤，不能称准备完成即保证获批或收入 |

## 排除与依据

不申请 AdSense、不启用自动广告、不调整已有 GA 统计行为、不增加 Cookie/同意存储、不修改 DNS/证书/云平台、不部署、不新增依赖。后续实际广告必须另审策略，并确保 2FA 独立文档不继承广告脚本。

Google 官方要求强调有用原创内容与可用导航，不将四页组合、固定字数、固定页数或 HTTPS 配置当作获批保证。广告隐私披露及适用地区的同意管理须在实际接入前落实。
