# 054 JSON结构对比定位与跳转

日期：2026-11-16。负责人在053文件导入完成后明确要求新增“对比结果定位与跳转”，本轮沿当前JSON结构对比实现，不扩展逐行文件/文本对比。

| 编号 | 可执行验收条件 |
| --- | --- |
| JDN-01 | 结果区增加有标签的字段路径查找框，最长1000码元。按JSON Pointer原文进行区分大小写的普通子串匹配，不trim、不解码、不使用正则；~0/~1按原文查找，空查找匹配当前类型筛选全部差异（包括根空指针） |
| JDN-02 | 提供定位首处、上一处差异、下一处差异，按现有稳定结果顺序导航，显示匹配数量和当前匹配序号；初始尚未定位，下一处定位第一处；边界不循环，首处禁用上一处、末处禁用下一处，零匹配全部禁用且明确说明 |
| JDN-03 | 定位匹配时自动翻到每页100项的对应页，唯一当前项高亮、aria-current及可编程焦点，滚动到视口可见；不把字段内容拼入DOM选择器或URL，目标只按内部数值索引识别。键盘Enter可定位首处，无动画依赖 |
| JDN-04 | 查询变化、类型筛选变化、手动翻页清除当前定位；新比较/输入变更/文件选择/交换/清空/离页清除查找及定位。路径查找不改变分页列表、全局统计或报告范围，报告仍包含当前类型筛选全部结果，需明确说明 |
| JDN-05 | 查找框输入法组合期间不提交新查询或跳转，不撤销JSON比较结果；结束后提交。等待DOM翻页的迟到定位不得在编辑/新查找/筛选/手动翻页/离页后抢焦点。现有JSON输入IME、文件读取版本、复制晚到保护保持 |
| JDN-06 | 键盘可操作、可见焦点/44px目标/状态播报，375/768/1440与200%字号无页面横向溢出。查找只在内存中，无外发/记录/存储、新依赖或路由；22工具/30HTML/22指南和索引/广告范围不变 |

排除：原文编辑器行列定位、字段值搜索、正则、自动展开/合并、JSON Patch、持久化查找、全局快捷键、其他工具的导航、正式打包与部署。根差异在空查找时正常参与导航；不引入额外的根路径别名语法。
