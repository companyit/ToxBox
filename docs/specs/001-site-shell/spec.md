# 001 网站基础布局需求规格

状态：M0-03 第一轮人工审阅决策已同步（2026-10-10）；基础布局规范已具备实施准备条件，尚未获得 M1-01 编码授权；不代表功能实现。关联：[第一阶段需求](../../product/requirements.md) P1-01、P1-07、P1-08 的首页部分。

## 目标与边界

提供 WorkDev Tools 首页骨架，让用户理解定位、浏览办公与开发者分类，并了解本地处理原则。此规格不实现工具计算、搜索、独立工具路由、账号、广告、统计、后端或部署。

首批工具尚未上线时显示“规划中”，卡片不伪装为可用按钮；只有在后续工具规格完成并验收后才能提供真实入口。首页对外发布应等待至少一个真实工具可用并通过发布审查。

## 用户场景

用户在桌面或手机进入首页，看到产品名称与说明；通过导航到达办公工具、开发者工具或隐私说明；浏览卡片了解计划提供的能力。键盘用户通过跳转链接进入主内容，再按顺序浏览导航。

## 需求与验收条件

| 编号 | 需求 | 可执行验收条件 |
| --- | --- | --- |
| SHELL-01 | 品牌与语义结构 | 首页显示 WorkDev Tools、中文定位、免费免登录与本地处理说明；存在 header、带名称的 nav、唯一 main、footer，主内容恰有一个 h1 |
| SHELL-02 | 页内导航 | 品牌返回页首；“办公工具”“开发者工具”“隐私说明”分别跳转到真实且唯一的锚点；键盘可触发，目标标题不被页头遮挡，无空链接 |
| SHELL-03 | 分类目录 | 展示办公、开发者两个分区；每张卡片显示名称、简介、分类和状态；初始文本统计归办公，JSON 与 URL 归开发者，均标注“规划中”且不可启动；卡片从统一元数据渲染 |
| SHELL-04 | 响应式 | 在 375×812、768×1024、1440×900 CSS 像素下内容不重叠、无页面横向滚动，导航可见；200% 浏览器缩放仍可阅读和操作；长标题可换行 |
| SHELL-05 | 可访问性 | Tab 首先可到达“跳转到主内容”，激活后焦点进入 main；链接焦点可见，顺序符合阅读顺序；不以颜色单独表达状态；正文对比度至少 4.5:1，大字至少 3:1 |
| SHELL-06 | 首页 SEO | index.html 使用 lang="zh-CN"、标题“WorkDev Tools - 办公与开发者在线工具”和非空中文描述；标题与主要文案一致；保留 viewport；不填造域名、canonical 或结构化评分 |
| SHELL-07 | 隐私与页脚 | 页脚展示品牌；隐私分区说明“本阶段工具规划为浏览器本地处理，基础布局不采集工具输入”，不作覆盖未来所有工具的绝对承诺；无虚假备案、联系方式或不可达链接 |
| SHELL-08 | 性能与稳定性 | 使用生产构建本地预览检查，无运行时控制台错误；无外部字体、广告、分析及工具数据请求；记录首页自有 JS+CSS gzip 体积；执行 Lighthouse Performance 测量并保存报告，90 分以上为初步目标，未达标记录原因和优化建议，不将目标当作已达成或硬性通过门槛 |
| SHELL-09 | 空目录与内容伸缩 | 将某分类数据临时置空时显示“暂无工具，敬请期待”；长简介正常换行，不遮挡其他内容；验收后还原测试数据 |
| SHELL-10 | 工程验证 | npm run type-check 与 npm run build 均退出码为 0；保存各项人工验收结果、浏览器版本、操作系统、视口及性能证据；核心布局和导航覆盖 Chrome、Edge、Firefox、Safari 最新稳定主版本及前一个主版本，未验证项不算通过；不要求不存在的测试脚本 |
