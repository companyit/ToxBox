# 052设计

关联[规格](spec.md)。复用既有浏览器Blob与对象URL机制，下载控制在CsvJsonPage，不修改纯转换算法。

用独立hasResult标记转换成功状态，不能以output是否非空判定下载资格。从direction派生文件名和按钮名称，点击时选择对应MIME；只有成功结果才保留资格，invalidate同步清除。

点击创建Blob/对象URL及临时隐藏下载链接并触发原生下载，finally移除临时链接；缓存一个URL，重复点击复用。URL保留至下一次invalidate，避免触发后立即回收造成下载竞态；无定时器或后台任务。首次失败或链接触发失败时回收，给出固定消息，结果不清除，可重试。既有pagehide/卸载调用invalidate，统一释放内存。下载提示只表示向浏览器发起请求，实际保存由浏览器和系统处理。

验证：组件模拟对象URL/点击，覆盖禁用、空结果、延迟创建、重复复用、逐项失效回收、失败重试/隐私和原复制流程。浏览器在两引擎/三宽度接收真实下载，检查建议文件名及实际字节，覆盖中文、引号、换行、前导零、大整数、空CSV、JSON对象和二维模式及键盘/IME。执行类型、preview构建、组件/单元、静态检查与相关浏览器回归，保留本次源/产物摘要。Firefox若无法启动记录缺口，不宣称通过。无新增架构决定待确认。
