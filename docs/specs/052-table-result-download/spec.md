# 052 CSV/JSON转换结果下载

日期：2026-11-16。负责人在“转换结果下载、本地处理、无新增依赖”建议后回复“可以，把高优先级的来下载”；按下载方向实施，不把其他高优先候选自动纳入。关联019/042/043/044，043排除下载的旧范围由本规格对本项扩展。

## 目标及验收

让用户将已经转换的结果直接保存为文件，避免大文本复制。

| 编号 | 可执行验收条件 |
| --- | --- |
| TDL-01 | CSV/JSON页结果区增加有明确类型的下载按钮；转换成功前、错误后、IME期间禁用；不自动转换或覆盖输入。默认模式、对象模式、JSON转CSV均可用 |
| TDL-02 | JSON固定文件名converted.json、MIME application/json;charset=utf-8；CSV为converted.csv、text/csv;charset=utf-8。UTF-8无额外BOM，解码正文与结果框完全一致，不添加末尾换行、不改写公式文字或数值词元。文件名不含用户内容 |
| TDL-03 | 转换成功但结果为空也可下载：JSON转CSV的[]保存零字节CSV，只有CSV表头的对象模式保存[]；未输入或失败不能下载 |
| TDL-04 | 按用户点击才创建本地Blob及对象URL，同一结果重复点击复用URL；编辑、方向/选项切换、重新转换、清空、pagehide和卸载回收URL，旧结果不可下载；不写存储或URL，不发送内容 |
| TDL-05 | 创建或触发下载失败给出固定中文提示，保留输入与结果，允许重试或复制；不回显浏览器异常，不宣称文件已经保存。控件键盘可用、44px目标，375/768/1440无横向溢出 |
| TDL-06 | 保持既有输入/输出/行列预算、复制和示例保护；无新工具、路由、依赖、服务或持久化，22工具/30HTML/22指南与索引/广告范围不变 |

## 排除

本轮不添加文件导入、JSON差异搜索/定位、自定义文件名、CSV分隔符、BOM切换、ZIP、批量文件、自动下载或文件系统写入API；不更新正式dist或部署，不恢复文件翻译。
