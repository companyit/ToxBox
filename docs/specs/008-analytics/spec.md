# 008 页面访问分析规格（本轮授权实现）

日期：2026-11-02。来源：负责人提供 GA4 代码并要求增加数据分析。需求已提出，具体范围及架构决策待确认；本文不代表功能完成。

## 目标和范围

使用 Google Analytics 4（衡量 ID：`G-FT0EKJ0B5K`）了解页面访问分布，为后续优化提供依据。首期只统计页面访问，不统计工具输入、结果、复制内容或按钮事件。

| 需求 | 可执行验收条件 |
| --- | --- |
| ANA-01 | 仅正式环境启用；开发、preview、自动化测试及构建时 SSR 不加载 Google 脚本、不发送分析请求 |
| ANA-02 | 首次访问和 Vue Router 成功切换页面各发送一次 page_view；重复导航不重复发送；禁用默认及后台增强型历史导航页面采集以避免重复 |
| ANA-03 | page_location 只使用固定站点 origin 与已知页面路径；不发送查询参数、hash、原始 referrer、工具内容或任意未知路径；404 使用固定脱敏路径与标题 |
| ANA-04 | 同步更新首页及隐私页，说明 Google 分析请求、访问数据处理与可能的标识符存储；保留工具输入本地处理原则 |
| ANA-05 | 脚本加载失败或被拦截时，导航与工具功能正常；脚本只初始化一次；SSG 与 CSR 均可工作 |
