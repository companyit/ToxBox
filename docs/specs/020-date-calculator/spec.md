# 020 日期差与日期加减

日期：2026-11-07。状态：已获本轮实现授权，实施及验证进展见任务与验证报告。关联 P1-18。019 已完成本地实现后，负责人要求继续推进；本轮按产品需求中的日期计算候选准备可审阅范围，不将该要求自动视为新模块细节获批。

## 目标与范围

拟路径 `/office/date-calculator/`，提供两个主动计算模式：两个日期相差多少个日历日、一个日期加减整数天后是哪一天。仅处理日期，不处理时分秒、设备时区或夏令时，不把结果称为实际经过的 24 小时时长。使用公历的闰年规则，日期范围固定为 `0001-01-01`～`9999-12-31`。

保持 Vue 3、TypeScript、现有路由及 SSG，无新增依赖、上传、后端、持久化、系统日历或定位。默认输入为空，不自动读取当前日期或设备时区。

## 需求与可执行验收

| 编号 | 范围与验收条件 |
| --- | --- |
| DATE-01 | 默认“日期差”，输入开始和结束日期，主动点击计算才产生结果。结果定义为结束日期减开始日期的有符号日历天数，不增加首尾天数、不自动取绝对值。`2024-02-28` 到 `2024-03-01` 得 `2 天`，反向为 `-2 天`，相同日期为 `0 天`；说明负值代表结束日期早于开始日期 |
| DATE-02 | 可切换“日期加减”，输入基准日期及整数天数；正数向后、负数向前，0 保持当天。`2024-02-28` 加 1 得 `2024-02-29`，加 2 得 `2024-03-01`；`2024-03-01` 加 -1 得 `2024-02-29`。只计算天，不提供月份/年份偏移的月末策略 |
| DATE-03 | 日期严格为 10 个 ASCII 字符 `YYYY-MM-DD`，年份 0001～9999，月份/天必须是真实公历日期；不 trim、不宽松解析。拒绝 `2024-2-9`、多余空白、日期时间、0000 年、`2023-02-29`、`1900-02-29` 和 `2024-04-31`；接受 `2000-02-29`。不依赖设备语言日期格式或 Date.parse 的宽松修复 |
| DATE-04 | 天数只接受 `0` 或无前导零的十进制整数，可有一个前置负号；拒绝 `-0`、正号、小数、科学计数、内部/首尾空白、空串与非 ASCII 数字。最多 8 个 UTF-16 码元，绝对值最多 3652058；转换前验证文本与范围，不截断。不允许超出日期范围：`0001-01-01` 加 -1、`9999-12-31` 加 1 均提示错误并保留输入 |
| DATE-05 | 两模式按纯日历日计算，与浏览器所在时区无关。`0001-01-01` 到 `9999-12-31` 得 3652058 天，覆盖最小/最大边界、世纪非闰/400 年闰年和跨年；不得出现 JavaScript 0～99 年映射到 1900～1999 的行为，也不按本地夏令时把日期差除以 86400000 |
| DATE-06 | 各日期输入超过 10 码元、天数超过 8 码元，明确报错而不截断；所有输入均空时点击计算提示暂无内容，部分缺失时中文提示补齐对应参数。输入格式/越界错误不回显原内容，错误保留所有参数且清除旧结果。输出只读，日期差固定为带符号整数加“ 天”，日期加减固定为 10 字符 ISO 日期 |
| DATE-07 | 输入/模式变化、重新计算、清空使旧结果及异步复制提示立即失效，不自动计算；换模式保留各模式待编辑参数，不把旧结果转填输入。提供按当前模式的示例，有任何现有参数时先提示清空，不覆盖；清空清除两模式全部参数、恢复日期差并回焦开始日期 |
| DATE-08 | 成功结果（包括 `0 天`）才允许复制，复制完成后提示成功；失败聚焦/选择结果并提示手动复制。版本号阻止编辑、换模式、清空、pagehide、卸载后的迟到复制反馈。输入法组合期间禁用计算/换模式/示例/清空/复制；pagehide 与卸载释放所有参数及结果引用并清理监听 |
| DATE-09 | 参数及结果只在当前页面内存处理，不写网络、URL、日志、分析事件或持久化，不主动读取剪贴板。页面不读取真实日历、位置、当前时间或本地时区。保留既有统计边界、敏感文档隔离与广告关闭策略，不新增第三方脚本或依赖 |
| DATE-10 | 接入首页、办公目录、搜索、相关工具、办公面包屑及分类高亮、独立元信息与原创指南，SSG 只渲染空表单。新页 noindex，既有八页正式索引不扩容；实现后由 12 工具/19 站点页面加 404 精确变为 13 工具/20 站点页面加 404，指南由 12 增至 13，更新精确路径/数量审计 |
| DATE-11 | 日期字段使用可直接编辑的文本输入、可见标签、格式示例、文本键盘，负数天数不强制 numeric 键盘，避免无法输入负号。错误/结果可被读屏感知，键盘可完成全部核心操作；375/768/1440px 无页面级横向溢出，保留可见焦点。浏览器验证至少覆盖双引擎和不同系统时区上下文；真实设备/读屏/剪贴板人工组合未运行时标为未验证 |
