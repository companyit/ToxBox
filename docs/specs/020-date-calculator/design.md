# 020 日期计算设计

日期：2026-11-07。状态：已获本轮实现授权，按本文范围实施。关联：[规格](spec.md)、[任务](tasks.md)。

## 模块与日期口径

新增纯 TypeScript `src/utils/dateCalculator.ts`，使用判别联合请求区分日期差与日期偏移，返回空输入、带格式化结果的成功及固定错误码。模块不访问 DOM、时钟、设备时区、存储、日志或网络。组件负责输入及中文反馈，不把算法放入 App 或复用有额外时分秒/时区语义的时间戳转换入口。

严格解析日期：先检查原始长度及 ASCII `YYYY-MM-DD` 形态，再验证年份、月份及公历闰年对应的月天数。天数先检查原始长度、整数文本和绝对值范围，禁止宽松 parseInt。输入值不 trim、不自动纠正，不通过 Date.parse 接受模糊格式。

日期转换为从 0001-01-01 起计的整数日序。可采用独立整数公历算法：某年前天数为 `365*(year-1) + floor((year-1)/4) - floor((year-1)/100) + floor((year-1)/400)`，加年内前序月天数与 `day-1`。最大日序 3652058，在安全整数内。日期差直接相减，偏移在检查目标日序上下界后再反解日期。反解可对 1～9999 年二分查找年首，再逐月扣除天数；不需要新增日期库、Date 当前时间或 UTC/本地时区转换，也规避 Date 构造器 0～99 年陷阱。

结果格式固定：日期差 `${difference} 天`，偏移为补零的 `YYYY-MM-DD`。不增加首尾天数、不转换为工作日，不展示小时/秒或时区。输出尺寸由已验证日期范围固定约束，无大字符串生成路径。

## 页面状态与隐私

新增 `DateCalculatorPage.vue`，复用 ToolPageLayout 和现有控件视觉，独立维护模式、开始/结束日期、基准日期、偏移天数、错误、输出、复制消息、版本号、输入法及复制挂起状态。日期/天数使用文本输入且不设置 maxlength 截断，算法拒绝超限。日期差初始参数全空，切换模式保留待编辑参数但立即撤销旧结果，不自动使用设备当前日期。

示例按模式提供，任一现有参数非空时拒绝覆盖；清空释放全部参数、恢复日期差并回焦开始日期。可采用 `nextTick` 等待条件渲染后聚焦。输入法组合期间禁止改变模式或触发操作；编辑、换模式、重新计算使旧结果和复制反馈失效。复制只接收已验证输出快照，以版本和卸载状态防止迟到 Promise 回写；失败时选择只读结果供手动复制。

pagehide（包括 bfcache）与卸载清理两模式所有参数和结果，解绑监听。不将输入、结果或解析异常写日志；页面只映射固定错误码，不回显原内容。沿用普通本地文本工具的统计边界，不自动扩充敏感文档组；现有 PDF/TOTP 整页隔离及广告关闭不变，不读取系统日历或剪贴板。
