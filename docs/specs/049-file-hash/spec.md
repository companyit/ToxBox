## 目标与使用场景

新增开发者工具候选路径 `/developer/file-hash/`。用户选择下载文件或待传输文件，在浏览器本地计算摘要，再与提供方给出的预期摘要核对，或复制摘要用于后续检查。与文件对比互补：摘要只判断原始字节是否匹配，不定位变化，不证明文件来源可信或内容无害。

| 编号 | 可执行验收条件 |
| --- | --- |
| HASH-01 | 单文件，默认SHA-256，可选SHA-384/SHA-512；支持任意扩展名和二进制文件，空文件合法。选择后显示本地文件名/实际字节数，不自动计算或联网；主动点击计算后才启动Worker |
| HASH-02 | 首版每份最多20 MiB（20×1024²字节），读取前验证File.size，读取后验证实际ArrayBuffer.byteLength；超限明确拒绝，不截断、不只算文件片段。采用原始字节，不去BOM、不解码UTF-8、不规范化换行或文件名 |
| HASH-03 | 使用浏览器原生Web Crypto digest，结果为固定长度小写十六进制：SHA-256为64、SHA-384为96、SHA-512为128字符，逐字节补足两位。相同字节不同文件名得到同一结果；不同算法不得混用。API/安全上下文不可用时固定中文提示，不降级为自写摘要或远端计算 |
| HASH-04 | 可选预期摘要输入，最多256个UTF-16码元；只允许对应算法长度的十六进制，忽略首尾空白与大小写，拒绝内部空白、分隔符、错误长度/字符。显式点击核对后分别提示一致/不一致；无预期值或无当前成功结果时不报告匹配 |
| HASH-05 | 预期摘要编辑立即撤销旧匹配提示，保留当前摘要供重新核对；重选文件、换算法、重新计算、取消或清空立即撤销旧摘要/核对/复制反馈。每个任务有代次，迟到Worker/复制结果不得覆盖新状态。计算中允许取消，禁止重复计算；取消保留当前文件选择，可重试 |
| HASH-06 | Worker本地读取和计算，合计30秒保护；超时/错误不显示部分结果，固定中文消息不附文件名、摘要或原始异常。终止Worker并作废代次，不将中止反馈等同设备物理擦除；显示真实阶段（读取/计算），不编造进度百分比 |
| HASH-07 | 成功后可复制摘要字符串，不含文件名或路径；剪贴板Promise成功才反馈，失败聚焦并全选只读摘要供手动复制。不读取剪贴板、不自动下载报告。清空恢复默认算法和空预期值并聚焦文件控件；pagehide/卸载清除文件引用/文本/结果、计时器和Worker，同文件可重选 |
| HASH-08 | 独立敏感文档页，不加载GA/广告/其他第三方脚本；应用不将文件名、字节、摘要或预期值写入请求、URL、日志或存储。与既有敏感组整页导航机制接入，048四页广告白名单不扩大；不能只隐藏广告位声称隔离 |
| HASH-09 | 标签、键盘/可见焦点、polite状态播报完整，375/768/1440px无页面横向溢出，200%字号下摘要可换行/选中。实现后才接入开发者目录/搜索/相关工具/指南/路由/SSG空态。新页noindex，正式24页索引不扩大；实际预计22工具（办公14/开发8）、30HTML、22指南，验收后按实更新 |

## 排除项与验收边界

首版不含文本输入哈希、MD5/SHA-1、HMAC、数字签名、病毒检测、文件夹/多文件批量、流式大文件、读取系统路径、云校验/历史存储或上传服务；不引入新依赖、后端或模型。20 MiB是首版保护值，不是性能承诺；若浏览器/设备实测不满足30秒，应记录并审阅调整，不默默降低范围或换服务。

算法覆盖已知摘要与独立实现对照、空字节/Unicode文本原始编码/BOM/换行差异、大小边界、三算法长度补零、预期值校验；组件覆盖计算阶段/取消/超时/换文件换算法/迟到反馈/复制/清空/离页。真实浏览器验证本地File→Worker→Web Crypto、三宽度、无网络/URL/存储内容泄露及与广告页的文档隔离。类型、单元组件、preview、SSG、历史身份核对及三引擎尝试按实际结果记录；Firefox既有profile失败不得用历史通过代签。真实设备、读屏、系统文件选择/剪贴板及发布独立验收。
