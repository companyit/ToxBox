# 010 Base64 编解码设计

关联：[规格](spec.md)、[任务](tasks.md)。状态：2026-11-03 获授权实现，实际验证见文末报告。

## 模块、数据流与异常

独立 `src/utils/base64.ts` 接收文本及方向，返回类型化结果，不接触 DOM、网络或存储。使用浏览器原生 UTF-8 和 Base64 能力，分块处理字节，避免大数组展开导致调用栈错误；静态渲染时不执行转换。视图复用 ToolPageLayout，管理输入、方向、错误、结果和复制状态。

状态为空、编辑、成功、错误；任何编辑均撤销结果和复制反馈。复制异步返回需校验操作版本，避免清空后出现过期成功提示。严格 UTF-8 解码失败使用固定中文错误。

## 接入及验证

复用既有路由机制，增加页面目录、路由组件、工具目录及独立页面；维护静态输出准确路径集合，不用放松断言替代新增页面检查。新增页保持 preview/noindex，不扩大正式索引白名单；同步展示工具数量的文案，保留旧入口。

新增纯函数边界测试、组件交互测试和浏览器关键流程验证；运行现有类型检查、CSR/SSG 构建及相关回归，记录实际命令、结果、浏览器版本和限制。复制成功/失败、编辑失效、清空及离页均需验证；检查请求、URL 与存储无输入和结果泄露。新增页面还需验证直接访问、导航、尾斜杠和静态输出。
