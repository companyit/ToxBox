# 010 Base64 编解码

日期：2026-11-03。状态：2026-11-03 负责人明确授权实现，已完成本地功能；跨浏览器完整矩阵及负责人最终验收尚未全部完成。按 Base64 → 时间戳 → UUID → 工具搜索顺序推进。关联产品需求 P1-09。

## 目标、范围与验收

用户手动编码 UTF-8 文本或解码标准 Base64，拟路径 `/developer/base64/`。

| 编号 | 可执行验收条件 |
| --- | --- |
| B64-01 | 默认标准 Base64、手动单轮转换；`你好` 编码为 `5L2g5aW9`，`hello` 编码为 `aGVsbG8=`；解码可还原原文 |
| B64-02 | 编码拒绝孤立代理项；解码允许 ASCII 空格、制表符和换行，移除后要求标准字母表、完整四字符分组、正确尾部 padding 与零填充位；拒绝 URL-safe 字符、非法 padding 和非 UTF-8 字节；中文提示不回显输入 |
| B64-03 | 原始输入上限 100000 UTF-16 码元，空输入显示无内容；超限不截断；修改输入或转换方向立即清除旧结果，失败保留输入 |
| B64-04 | 提供示例、清空、只读结果及复制；复制成功后才提示成功，失败提示手动复制；清空与离页释放内容引用 |
| B64-05 | 本地处理，输入和结果不进入 URL、日志、分析事件或存储；页面有独立入口和预渲染正文，新页 noindex |

排除：文件、二进制下载、Base64URL、自动格式识别、加密与新增依赖。明确说明 Base64 是编码，不能保护秘密。

## 共同质量要求

键盘完成核心操作，标签、可见焦点、错误及结果状态可被辅助技术感知；375、768、1440 CSS 像素无页面级横向溢出。输入使用文本绑定，不用 innerHTML。复用现有 Vue 3 + TypeScript + Vite、路由及 SSG，不新增依赖、持久化、内容埋点或部署。现有 2FA 文档隔离必须保留。
