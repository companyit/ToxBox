开发者通过统一命令获得算法、组件、SSG 与真实浏览器结果；审阅者可从每个旧用例追溯迁移后的输入、预期和证据；负责人可以分别判断 Dev Done 与 Release Ready。保留全部 154 项既有自动化行为覆盖，新增测试单列，不用重复执行增加覆盖数量。

本轮只新增本目录 spec/design/tasks 并细化 ADR-019，给 006 增加承接说明。所有路径、脚本、依赖、配置和工作流均为实施提案；没有安装、改代码、执行构建/测试、创建 workflow、部署、commit 或 push。AGENTS 中早期“Router 未安装/9 文档”以本轮明确文档授权和实际工程为准，其余约束继续适用。

排除：新业务功能、算法变更、正式 SEO 产物、线上服务、生产部署、生产密钥、统计/广告、真实用户输入采集。测试工具不进入运行时 bundle。不新增覆盖率百分比门槛或 coverage/UI/canvas 包；以后需要须另批。
