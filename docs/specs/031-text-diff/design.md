# 设计

新增纯TS textDiff 模块：长度/行数检查、换行规范化、LCS动态规划与确定性回溯、统计和报告。最多1000×1000比较，Uint16Array存储LCS长度矩阵（上限1000），约2 MiB矩阵；该限额不是所有设备性能承诺，Worker10秒可终止。回溯先判断同一行，再在同分时删除原行；结果行含kind、原/新行号和原文本，不合并成“修改”或猜测移动。

Vue输入、状态与复制流程复用现有工具交互；结果以语义table渲染，类型有中文/符号且不只依赖颜色，主题使用现有accent/error配色，长内容pre-wrap/anywhere换行。报告使用readonly textarea，复制来自当前筛选结果，失败focus+select供手动复制。处理期间输入可编辑（即取消），中文组合输入时禁用主动操作。

新同源Worker只返回结果或白名单错误码。敏感路径、广告排除清单、页头分类、工具/页面/指南和SSG验收清单扩展，采用既有独立文档边界，无新架构决策或依赖。当前目标17工具（办公10/开发7）、25HTML含404、17指南。

验证纯算法例子及小规模穷举最短性/重建，浏览器真实Worker、键盘/剪贴板、清理/超时和隐私；全站类型、SSG及双引擎回归后生成生产dist，部署仍由负责人执行。
