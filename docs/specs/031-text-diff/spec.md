# 031 文本差异对比

负责人本轮要求继续开发其他功能，按已提议的文本差异对比推进首版。无新增依赖，沿用既有Vue/TS、Worker和独立敏感文档方案。

TD-031-01：新增办公工具 /office/text-diff/，首页搜索与办公目录可达，noindex；不改变正式八页索引，页面无第三方统计/广告。
TD-031-02：原文本与新文本分别输入，点击开始对比，逐行标示保留、删除、新增，展示双方行号及新增/删除/保留数量；修改作为删除加新增，不声明字符级差异或移动识别。默认全部结果，可切换仅看变化。
TD-031-03：大小写、空格和制表符均有意义；CRLF/CR统一为LF。空字符串为0行，其余按LF分行，保留末尾空行，因此结尾换行变化会显示为空行新增/删除。空行显示占位提示，实际文本通过插值安全渲染；不使用v-html。
TD-031-04：每侧最多100,000 UTF-16码元、1,000行，超限不截断，保留输入，结果清空；确定性最短逐行增删序列，重复行同分时优先删除原行。支持交换两侧、清空、主动示例（不覆盖已有输入）、复制可读对比报告；报告含变化标记和双方行号，不是Git补丁格式。
TD-031-05：Worker本地处理，最多10秒，允许取消；改输入/交换/新对比立刻终止旧任务、清除旧结果，过期消息不覆盖新任务。仅看变化不修改原始对比结果，复制报告遵循当前筛选。复制失败保留报告供手动选中；离页/pagehide清空输入、结果、报告并终止Worker，不上传、日志/URL/存储不记录内容。

验收：新增/删除/替换/重复行/空白/结尾换行/空字符串结果和统计正确，重建双方文本与LCS最短序列核对；超限/取消/超时/过期消息与复制失败有效；375/768/1440无横向溢出且键盘可用；SSG空状态、脚本隔离与生产dist验证。排除文件上传、字符级着色、JSON结构对比、忽略空白、云保存或外部差异依赖。
