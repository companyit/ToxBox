# 018 PDF 拆分与选页导出实现验证

日期：2026-11-05。负责人在审阅 [018 规格](../specs/018-pdf-split/spec.md)及两种导出模式、保序去重、逐页最多 20 项的确认请求后要求“继续推动”，本轮据此实现 SPLIT-01～10。不包含生产候选、打包、Git 写操作或部署；未覆盖开始时已有其他工作区改动。

## 实际功能与修改范围

入口 `/office/pdf-split/`。选择一份普通 PDF，检查后输入 `1,3-5,8` 一类页码表达式，显示规范化页序和数量，再主动导出。单份模式输出 `selected.pdf`；逐页模式最多 20 页，依实际页序提供 `page-NNNN.pdf` 单页链接，用户逐项点击下载，无自动批量下载或 ZIP。

`5,1-3,2` 实际导出源第 5、1、2、3 页；`3,1` 逐页导出第 3 页和第 1 页。重叠保留首次出现，不按页码排序。空输入不选全篇，另有明确“选择全部页面”按钮。超限和错误保留原页码，不截断或静默缩减。

新增 `src/utils/pdfSelection.ts`（纯选页解析/单文件校验）、`src/utils/pdfSplit.ts`（严格 PDF 检查与两种输出）、`src/workers/pdfSplit.worker.ts`（固定错误/无日志同源任务）、`src/views/pages/PdfSplitPage.vue`（交互、状态、下载）。复用现有 `loadPdf` 和 pdf-lib，未把解析库加入主线程入口，也未改变 PDF 合并算法。

接入页/工具/指南数据、现有路由、办公导航、首页和隐私说明；扩展 `sensitivePages` 与广告准备排除路径，跨普通/敏感文档组整页导航，正式 origin 也不初始化 GA。现为 10 工具、17 站点页面加 404（18 HTML），新页 noindex，八页正式索引白名单及广告关闭状态不变。精确更新 SSG、浏览器运行器和相关数量断言，不降低资源验证或历史身份检查。

新增 `tests/unit/pdfSplit.test.ts`、`tests/components/pdfSplit.test.ts`、`e2e/pdf-split.spec.ts`；扩展既有统计隔离和目录/页面检查。没有修改 package.json、锁文件或安装依赖，沿用现有许可通知。

## 状态与资源边界

源文件非空、20 MiB/500 页保护，复用扩展名/头部/严格解析、加密及 AcroForm 拒绝。页码最多 1000 个 UTF-16 码元、100 片段；拒绝前导零、空片段、逆序、越界、中文逗号及异常数字，先检查端点才展开。逐页数量在去重后计数，最多 20。

检查和导出在 Worker 内完成，导出重新验证文件、模式与页码。30 秒超时或取消直接终止 Worker；输出累计超过 100 MiB 则整批失败。全部字节成功后才统一创建 URL，创建任一链接失败会回滚先前链接，不发布部分结果。修改页码/模式、重选、重导出、取消、清空、pagehide、卸载均使旧任务及 URL 失效，版本号拒绝迟到消息。

输入法组合期间不导出或覆盖页码。清空恢复默认模式并将焦点返回文件选择；读取失败保留 File 可重新检查，导出失败保留文件和表达式。界面只说明导出完成/请求下载，不推断系统已保存。不上传、持久化或将文件相关内容写入 URL、日志或分析。
