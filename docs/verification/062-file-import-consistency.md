# 062 文件读取交互验证

2026-11-23 按 [FIC-01～03](../specs/062-file-import-consistency/spec.md) 完成。NDJSON、JSON 结构对比、文件对比均在按钮旁展示文件类型及容量，并使用一致的读取、取消和超时提示。取消回焦对应文件按钮。读取失败保留原输入，文件对比在新文件成功读取后才替换该侧预览。

- 类型检查、预览构建、461 项单元与组件测试及 21 项静态测试通过。
- 首轮组件和浏览器用例沿用了文件对比替换失败后清空原文件的旧断言。按已批准的保留规则更新断言后，Chromium／WebKit 共 32 项定向用例通过。
- 覆盖错误编码、超限、双侧读取、迟到读取、取消回焦、NDJSON 超时和下载。Firefox、真机系统文件选择及读屏未验收。未部署。
