## 2026-11-26 两个对比工具的键盘焦点

- 新增用例在修复前的 Chromium 预览中确认两个工具在读取成功后均丢失焦点。修复后，成功、编码失败或超时结束时，同侧文件按钮接续取消按钮的焦点。主动移到另一侧文件按钮时焦点留在该处。失败和超时保留上一份输入。
