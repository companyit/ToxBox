# 061 NDJSON 与 JSON 数组互转验证

按已获授权的 [NDJ-01～05](../specs/061-ndjson-converter/spec.md) 完成，入口为 `/developer/ndjson/`。支持逐行 JSON 与 JSON 数组互转，保留数字词元、对象字段及记录顺序。空行跳过，坏行标注原始行号。失败保留原输入，无部分结果。结果显示记录数并可复制，离页清理，页面复用敏感文档隔离。

- 类型检查、预览构建、458 项单元与组件测试、21 项静态测试和 154 项历史身份验证通过。预览审计覆盖 35 份 HTML、140 处页脚及 27 份指南。
- Chromium 和 WebKit 共 24 项定向用例通过，覆盖两向换算、精度、错误行、空结果、复制失败提示及离页释放，并在 375、768、1440 像素遍历 27 个工具页。
- 隔离生产候选 6 项检查通过。两种浏览器验证 35 份页面输出及导航边界，正式索引 24 页、广告白名单四页。[候选验证](evidence/seo-growth/seo-1795270575764/results.json)

Firefox、真机及读屏尚待验收。使用 `npm run preview:local` 查看，未部署。

## 2026-11-22 文件工作流

NDJ-06 已实现。上传控件仅选择本地文件，由浏览器读取 UTF-8，成功后填入可编辑输入。方向决定扩展名和下载文件名，下载使用结果原始 UTF-8 字节。失败或读取过期保留现有草稿。预览构建、类型检查、458 项单元与组件、21 项静态及 22 项 Chromium／WebKit 定向用例通过。两引擎分别检查文件方向、无效 UTF-8、过期读取、真实下载字节及空文件。真机系统文件选择和尚未执行的浏览器组合仍待验收。

## 逐行校验报告（NDJ-07）

处理方式新增「逐行校验 NDJSON」，支持粘贴或导入。报告统计已检查记录，最多列出 50 条固定错误及原始行号。触及全局预算时说明停止位置和未检查范围。报告可复制，编辑或切换模式后撤销。预览构建、类型检查、460 项单元与组件、21 项静态及 10 项 Chromium／WebKit 定向用例通过，覆盖多错校验、预算、导入、结果失效和已有转换下载流程。未部署。

## NDJ-08 校验到转换

完整通过后，报告旁可直接执行 JSON 数组转换。当前输入沿用，成功后焦点移至输出，下载复用现有文件功能。校验报错、达到中止预算或输入变化时无法沿用旧报告。预览构建、类型检查、461 项单元与组件、21 项静态及 12 项 Chromium／WebKit 用例通过，含键盘执行、输入保留及下载字节验证。未部署。

## NDJ-09 数组输出排版

数组转换提供紧凑及两空格缩进，校验直转沿用该排版，下载字节与显示结果一致。缩进计入 200,000 码元上限，超限可改紧凑重试。复用严格 JSON 的原始数字词元和有序对象，共用输出编码器的脱敏行为通过回归。类型检查、预览构建、464 项单元与组件、21 项静态、22 项 Chromium／WebKit 用例通过，覆盖深层容器、预算、两向转换、精度和真实下载。未部署。
