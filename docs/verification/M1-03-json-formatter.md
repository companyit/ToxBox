## 数值策略与兼容性

语法校验与转换分离。转换以最终原生解析树检查 Number.isFinite / Number.isSafeInteger，不安全整数/非有限数拒绝输出；小数舍入、下溢、科学计数表示及负零变化依原生行为，始终显示警告，不承诺无损。重复属性最后值覆盖，不保留原始键顺序/写法；不检测被覆盖数值的精度风险，不使用正则伪装完整数值安全判断。

文档研究 [MDN兼容性数据](https://github.com/mdn/browser-compat-data/blob/main/javascript/builtins/JSON.json)：context.source从Chrome114、Firefox135、Safari18.4起支持，Edge镜像Chromium。本次实际Chrome154.0.8037.98探针返回原文9007199254740993，生产函数不依赖此能力；其他浏览器是文档结论，非实测。无context.source仍执行同一最终值拒绝策略和警告；无polyfill、新依赖或JSON.rawJSON。全部数字无损方案不在批准范围。

## 人工补测及发布遗留

1. 记录浏览器完整版本、系统、输入法；真实中文输入并提交/取消候选，粘贴转义/Emoji/CRLF样本；组合中操作禁用，结束不自动解析。
2. Tab/Shift+Tab遍历缩进与全部按钮，用Enter/Space执行、清空，确认可见焦点与结果失效；验证首页跳转、收起复位及文本统计不变。
3. 复制结果到外部编辑器逐字核对；实际拒绝权限/非安全上下文下手动复制，只读结果全选且原输入不变；复制未完成时编辑/清空/重算/收起无旧提示。
4. 200%浏览器缩放、实际VoiceOver/读屏核对标签和polite通知；测全部错误/禁用/焦点等状态的对比度。手机记录型号、OS、版本、方向和视口，不能以桌面截图代替。
5. Chrome/Edge/Firefox/Safari验收时最新与前一主版本分别留环境/结果；完整核查网络、存储、日志、URL、渲染与异常路径。
6. Mac mini M4与真实手机生产预览，按规格10k/100k各样本各操作连续10次，记录每次纯函数及点击到绘制时延，最大值对照100ms/300ms。未实测不得承诺预算。补正式URL/SEO、预渲染评估与部署前检查，均需后续相应授权。
