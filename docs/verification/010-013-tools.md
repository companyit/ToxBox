## 实现文件与行为

- `src/utils/base64.ts`、`src/views/pages/Base64Page.vue`：标准 Base64 与 UTF-8 文本严格互转，校验 padding、尾位、UTF-8 及孤立代理项；100000 码元限制。
- `src/utils/timestamp.ts`、`src/views/pages/TimestampPage.vue`：显式秒/毫秒、UTC/固定 UTC+08:00、严格日期和安全整数；负数向负无穷取整；64 码元限制。
- `src/utils/uuid.ts`、`src/views/pages/UuidPage.vue`：Web Crypto 随机字节、v4/variant 位设置，1～100 批量生成，能力不足不降级；SSR 不生成结果。
- `src/utils/toolSearch.ts`、`src/views/HomeView.vue`：名称和简介子串过滤、大小写忽略、分类保留、数量播报、无结果与清除焦点；查询限 100 码元，不写 URL 或存储。
- `src/components/tools/LocalToolEditor.vue`：复用输入、版本失效、pagehide 内容释放、中文状态、示例、清空、复制及失败手动复制；不把工具逻辑集中到 App。
- 页面目录、路由、工具目录、App 工作区、主导航、关于及隐私说明同步接入；新增 3 个 noindex 试用工具，合计 7 个工具、12 个站点页面及 404（13 HTML）。既有正式索引白名单不扩大，2FA 独立文档隔离保留。
- 更新 SSG/E2E 精确页面集合、路由/静态断言；新增算法、组件和浏览器测试。历史 154 项迁移身份及原始文件保护保留。
