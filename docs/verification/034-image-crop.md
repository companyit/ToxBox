- `src/views/pages/ImageCropPage.vue`：Pointer Events移动/四角、X/Y/宽高键盘替代、自由/1:1/4:3/16:9、按宽或高只缩小、默认PNG、JPG白底、结果预览与主动下载。无效草稿保留并禁用生成，改动撤销旧结果，文件与任务版本拒绝迟到消息，清空/离页释放URL和文件。
- 接入目录、搜索、指南、路由、办公分类、隐私、敏感独立文档和广告排除。当前20工具（办公13、开发7）、28HTML、20指南；新增页noindex，八页正式索引范围不变。更新的旧测试仅调整精确目录数量/页面集合，既有算法及历史身份保留。
