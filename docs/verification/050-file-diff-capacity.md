## 实际行为和范围

每侧2 MiB、500000个UTF-16码元、5000行，三项均须满足；仍为严格UTF-8，不支持Word/PDF/GBK，不截断。fileText.ts使用文件专用验证，新增fileDiff.ts/fileDiff.worker.ts，不再借用031限额。031文本对比、032工作台源文件和限制未改。

精确LCS采用行ID、两行长度和1bit回溯：5000×5000时位图3125000字节，滚动行20004、行ID40000字节；旧完整长度矩阵为50020002字节。只报告可核对的数组分配，不宣称浏览器总内存下降相同比例。完全相同文本快速返回，重复行仍与旧算法一样相同优先、同分删除优先。

结果当前筛选每页最多200行，保持原行号和全局统计；筛选/重算重置页码。完整报告仅在主动查看/复制时生成，含当前筛选全部结果而非当前页，预算200万码元；失败保留差异，复制失败展开并选中全文，换筛选废弃迟到反馈。文件选择按钮改为中文，原生input隐藏，独立显示已加载文件名/字节/行数，不再出现“已读取”和“No file chosen”冲突；取消选择保留已加载内容，同文件可重选，清空聚焦可见按钮。

本地读取/比较各10秒保护，取消/重选/超时/离页终止Worker并作废迟到结果。无依赖、上传、统计/广告/路由/索引变化；仍21工具、29HTML、21指南、正式24页索引。指南、045当前范围及ADR-042已同步。
