JSON 格式化与校验

校验 JSON，选择 2 或 4 空格格式化或压缩；提供数字精度风险说明和安全拒绝提示。

JSON 语法校验支持对象、数组、字符串、数字、布尔值和 null；校验成功不代表转换可以安全执行。

重复属性名仅保留最后一个值；转换可能改变数字精度和原始写法，请保留原文。格式化不是无损文本编辑。

转换拒绝最终值中的不安全整数及非有限数。有限小数可能舍入或下溢，科学计数法、尾随零和负零可能变化；需要精确数字时，请在原数据中使用字符串。
