## 本轮测量

[可复现脚本](evidence/file-diff-review-2026-11-15/benchmark.mjs)读取当前两份TypeScript源码，用项目现有TypeScript仅转译后加载，未修改算法。Node24.21.0，每组预热1次、记录5次，合成1000行。

- 完全相同、单行替换、全部不同、重复行四组，单次约2.079～9.040 ms。
- 98999码元/侧、长公共字符前缀且行值不同，单次19.936～21.421 ms。
- 相同文件仍建立全矩阵；这说明当前1000行纯算法不算慢，不代表浏览器解码、Worker通信、Vue渲染或手机性能达标。
- 5000/10000行矩阵字节数仅按现有Uint16Array公式推算，不含输入、对象、报告、DOM或浏览器开销，也不是扩大后已通过的证据。

完整样本、逐次耗时与拒绝复现见[结果](evidence/file-diff-review-2026-11-15/benchmark.json)。首次直接用Node strip-only导入参数属性TypeScript失败，后改用项目现有TypeScript转译执行；未安装工具，不把首轮失败说成行为通过。
