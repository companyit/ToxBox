## 实际行为

对象数组自动生成首次出现顺序的字段并集表头；单个对象为一条记录，缺字段/短行补空并提示。二维混合类型数组不添加表头；普通/混合数组及基本根值使用value列。嵌套对象/数组保留为紧凑JSON文本。null写成null文本，缺失字段写空；CSV不保留JSON类型。

数字词元直接保留，实际覆盖9007199254740993、更大整数、高精小数、负零、指数及嵌套数值，不经过Number舍入。兼容模式仅处理开头一个BOM、字符串外行/块注释、末尾逗号，实际处理逐项提示；严格模式仍支持全部数据模型但不接受这些语法扩展。单引号、裸键、缺值、连续逗号、坏数值和未闭合结构不会猜测修复。

JSON Pointer如/data/items显式选择包装数据，不自动丢弃其他字段。无效/不存在路径、无列数据、重复字段（含转义后同名）、字段名换行归一冲突和不合法Unicode均明确报错。错误不回显输入、字段名、私有路径或原始解析异常；失败/编辑/换选项不显示旧结果。JSON映射和语法规则的边界见 [ADR-038](../architecture/decisions.md)，对照来源为 [RFC8259](https://www.rfc-editor.org/rfc/rfc8259) 和 [RFC6901](https://www.rfc-editor.org/rfc/rfc6901)。

## 限制与待验收

本轮只更新本地preview/noindex产物，没有更新正式dist/移交包或部署。20工具、28HTML、20指南及既有24页正式索引政策保持；不改变其他JSON工具的严格规则、统计/广告或上传策略。

CSV不能保留JSON类型或原始字节格式。对象字段缺失与空字符串都会成为CSV空字段，兼容提示会说明补齐；不提供自动展开、任意JS语法修复、Excel方言、文件导入或下载。JSON生成的表头不计数据行数，CSV反向时首行仍是普通记录且计入1000行限制；输出超过输入上限或含表头超行时需拆分后再反向。

真实设备、完整读屏/中文输入法及系统剪贴板粘贴仍需人工签收，见 [20工具人工清单R07补验](local-review-20-tools-2026-11-08.md)。本轮模拟事件和浏览器复制行为不代签这些项目；远端CI/分支保护、真实托管及依赖审计未在本轮重新核验。
