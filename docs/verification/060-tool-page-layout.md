# 060 全站工具页布局验证

已覆盖工具目录中的 25 个独立工具页。共有操作区使用统一的边框及间距，已有独立面板的工具直接使用该面板。指南按步骤、示例、注意事项与问答分区，设置指南与工具操作之间的同页键盘入口。Word 转 PDF 的打印样式移除新增面板装饰，并隐藏导航与说明。

- 预览构建、类型检查、446 项单元与组件测试、21 项静态测试通过。预览审计覆盖 33 份 HTML、132 处页脚和 25 份指南。
- Chromium／WebKit 首轮定向回归 284 项通过、2 项失败。两引擎均发现 320 像素下新增横向留白影响 JSON 格式化按钮换行。调整超窄屏面板后，复验 12 项全部通过。
- 最终复验在 375、768、1440 像素下逐一检查 25 个工具，覆盖布局、首次打开的编辑区、指南跳转和键盘焦点。额外验证 320 像素的旧编辑器布局及 Word 工具打印样式。首轮的其余用例覆盖文本、CSV、JSON、文件对比、图片裁剪、PDF 合并下载及 DOCX 工作流。

本地 Playwright 验证，Firefox、真机及读屏未执行，未部署。

## TPL-05 导航优化

26 个工具页的指南入口与面包屑共享顶部区域，指南、返回与隐私入口有清晰的边框、悬停和键盘焦点。隐私说明与入口独立排列。预览构建、类型检查、21 项静态及 10 项 Chromium／WebKit 用例通过，覆盖 375、768、1440 像素、指南往返跳转、全站无下划线和打印样式。

## 2026-11-26 全站指南与短视口导航

- 27 个工具的指南改为宽屏两列、窄屏单列。适用场景放在步骤标题下方，示例以描述列表标注输入和结果，并保留解释正文。静态产物逐页对照指南原文，确认示例值和适用场景完整。实际查看 CSV/JSON 指南的 320×256 和 1440×900 截图。
- 高度不超过 400 像素时页头随页面滚动。Chromium 与 WebKit 逐页验证 320×256 的指南首节可见、往返焦点和历史返回，同时验证首页分类快捷入口。Chromium 另逐页检查全部 35 页在该视口下的深浅主题，70 个组合均通过键盘跳过导航与横向溢出检查。
- 首页隐私摘要与 048 已批准的正式构建广告接入范围对齐。预览审计覆盖 35 份 HTML、140 处页脚、27 份工具指南，所有预览页的广告加载器计数为零。
- 修复前，定向用例发现示例缺少结构化标签、短视口首节未露出及首页隐私摘要过期。首轮短视口调整后，长场景仍挡住首节标题，因此将场景置于步骤标题之后。首轮全站回归 696 项通过、4 项失败，均因文本统计测试使用了全页描述列表定位器。将其限定到统计结果区，保留原有断言。
- 最终类型检查、预览构建、464 项单元与组件、21 项静态和 154 项历史用例映射检查通过。Chromium 和 WebKit 各通过 350 项全站用例，无失败、跳过或重试。Firefox、真机和读屏本轮未复验，改动已进入本地预览，未部署。
