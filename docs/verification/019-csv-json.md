## 实现与接入

- `src/utils/csvJson.ts`：纯 TypeScript CSV 四状态解析，严格 JSON 二维字符串表格验证，固定错误码、Unicode 与输入/行列限额。保留前导零、空白及字符串类型，支持引号内逗号/多行和双引号转义；统一换行为 LF。序列化前精确估算 JSON 转义/缩进或 CSV 引号长度，通过后才生成结果，再核对输出长度。
- `src/views/pages/CsvJsonPage.vue`：两方向主动转换、原输入保留、记录/列数播报、空输入与成功空结果区分、示例防覆盖、只读结果、复制版本保护、输入法保护、清空回焦与 pagehide/卸载清理。
- 页面/工具/指南数据、路由、首页、隐私说明及共享布局接入 `/office/csv-json/`，总计 12 工具、19 站点页面加 404。新页 noindex，原八页正式索引白名单不变；现有统计、敏感文档组和广告关闭策略不变。
- 主导航补入 csv-json 与此前遗漏的 text-cleanup 办公分类高亮，保留固定名单方式；增加静态及双引擎断言。更新 SSG、E2E、路由、工具数量和 12 份指南的精确审计，不放松资源限制。
- 新增算法、组件、SSG 与浏览器测试：`tests/unit/csvJson.test.ts`、`tests/components/csvJson.test.ts`、`tests/ssg/csvJson.test.ts`、`e2e/csv-json.spec.ts`；更新现有文本整理导航断言及精确数量断言。
