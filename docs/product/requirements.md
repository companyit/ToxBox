## 共同质量要求

在 375、768、1440 CSS 像素宽度下无页面级横向溢出；键盘可完成核心操作；输入有标签，焦点可见，结果和错误可被辅助技术感知。支持验收时 Chrome、Edge、Firefox、Safari 当前最新稳定主版本及前一个主版本（各两个主要版本）；记录版本号、操作系统和结果，无法执行的组合标为未验证，不得视为通过。

首页不使用外部字体、广告、分析脚本或第三方接口。Lighthouse Performance 目标为 90 分以上，作为需实测的初步优化目标，不是已完成承诺或当前硬性通过门槛；基础布局测量方案见 001；各工具须在独立规格定义输入限制及响应目标，避免大输入阻塞界面。

## 排除项及依赖

第一阶段以纯前端实现为主，不包含账号、支付、云存储或云同步、数据库、后端、广告系统、文件上传服务或大文件处理。收藏、历史记录、主题切换、多语言和复杂文件转换暂不纳入。

P1-01 本轮只维护规范，后续基础布局实现须另行授权。P1-02 和 P1-08 的多页面部分遵循已确认的路由方向，但安装和接入仍需后续授权。P1-03～05 的优先级已确定为文本统计 → JSON 格式化与校验 → URL 编解码；详细行为、边界和输入规模仍须分别建立规格、设计和任务，经审阅并获得工具实现授权后开发。规划 Cloudflare Pages 静态部署，尚未批准生产发布。
