# 第一阶段功能需求

状态：M0-03 第一轮人工设计审查已记录（2026-10-10，确认者：项目负责人/用户）。产品范围和技术方向已确认；本轮仅更新规范，不授权基础布局编码、工具实现、依赖安装或发布。项目名称暂定 WorkDev Tools。

## 范围及验收

| 编号 | 功能 | 验收标准 |
| --- | --- | --- |
| P1-01 | 网站基础布局 | 满足 [001 规格](../specs/001-site-shell/spec.md) 的全部验收条件；具备品牌、导航、工具目录与页脚 |
| P1-02 | 工具发现 | 用户可按办公/开发者分类浏览已上线工具；按名称或简介搜索；无结果有提示且可清除条件；仅在真实工具上线后提供可用入口 |
| P1-03 | 文本统计（首批第 1 项） | 本地显示字符数、去空白字符数与非空行数；空输入均为 0；清空后归零；字符按 Unicode 码点计数，CRLF 视为一次换行；具体示例在独立规格确定 |
| P1-04 | JSON 格式化/校验（首批第 2 项） | 合法 JSON 以两空格缩进输出，含对象、数组和原始值；非法 JSON 提示错误并保留输入；不使用 eval；结果仅在成功时可复制 |
| P1-05 | URL 编解码（首批第 3 项） | 提供 URI 组件 encodeURIComponent / decodeURIComponent 及完整 URI encodeURI / decodeURI 两种模式，默认组件模式、手动单轮处理；空输入为无内容状态；中文、空格和保留符有明确示例；非法百分号/UTF-8 编码提示错误、保留输入并清除旧结果；不混用表单加号语义；输入最多100000 UTF-16码元，细则见 [004规格](../specs/004-url-encoder/spec.md) |
| P1-06 | 通用工具操作 | 每个工具具备说明、示例、清空、结果区域；复制成功才提示成功，剪贴板失败提供手动复制提示；输入上限与超限提示由各工具规格确定 |
| P1-07 | 隐私说明 | 明确本地处理范围；工具内容不出现在请求、日志、URL 或持久化存储；刷新不承诺保留输入 |
| P1-08 | SEO 与使用质量 | 首页有中文语言声明、唯一标题、描述和单个主标题；每个工具页面需有可访问地址、独立标题与说明，按已确认的 Vue Router 4 HTML5 History 规划，在后续授权后实现；上线前评估静态预渲染并记录结论；不得宣称 SPA 已解决搜索引擎收录 |

## 共同质量要求

在 375、768、1440 CSS 像素宽度下无页面级横向溢出；键盘可完成核心操作；输入有标签，焦点可见，结果和错误可被辅助技术感知。支持验收时 Chrome、Edge、Firefox、Safari 当前最新稳定主版本及前一个主版本（各两个主要版本）；记录版本号、操作系统和结果，无法执行的组合标为未验证，不得视为通过。

首页不使用外部字体、广告、分析脚本或第三方接口。Lighthouse Performance 目标为 90 分以上，作为需实测的初步优化目标，不是已完成承诺或当前硬性通过门槛；基础布局测量方案见 001；各工具须在独立规格定义输入限制及响应目标，避免大输入阻塞界面。

## 排除项及依赖

第一阶段以纯前端实现为主，不包含账号、支付、云存储或云同步、数据库、后端、广告系统、文件上传服务或大文件处理。收藏、历史记录、主题切换、多语言和复杂文件转换暂不纳入。

P1-01 本轮只维护规范，后续基础布局实现须另行授权。P1-02 和 P1-08 的多页面部分遵循已确认的路由方向，但安装和接入仍需后续授权。P1-03～05 的优先级已确定为文本统计 → JSON 格式化与校验 → URL 编解码；详细行为、边界和输入规模仍须分别建立规格、设计和任务，经审阅并获得工具实现授权后开发。规划 Cloudflare Pages 静态部署，尚未批准生产发布。
