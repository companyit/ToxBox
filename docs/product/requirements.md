# 第一阶段功能需求

状态：建议基线，待审阅；工具清单须人工确认，本文不授权实现。

## 范围及验收

| 编号 | 功能 | 验收标准 |
| --- | --- | --- |
| P1-01 | 网站基础布局 | 满足 [001 规格](../specs/001-site-shell/spec.md) 的全部验收条件；具备品牌、导航、工具目录与页脚 |
| P1-02 | 工具发现 | 用户可按办公/开发者分类浏览已上线工具；按名称或简介搜索；无结果有提示且可清除条件；仅在真实工具上线后提供可用入口 |
| P1-03 | 文本统计（候选） | 本地显示字符数、去空白字符数与非空行数；空输入均为 0；清空后归零；字符按 Unicode 码点计数，CRLF 视为一次换行；具体示例在独立规格确定 |
| P1-04 | JSON 格式化/校验（候选） | 合法 JSON 以两空格缩进输出，含对象、数组和原始值；非法 JSON 提示错误并保留输入；不使用 eval；结果仅在成功时可复制 |
| P1-05 | URL 编解码（候选） | 提供 encodeURIComponent / decodeURIComponent 对应操作；中文、空格和保留符有明确示例；非法百分号编码提示错误且保留输入；不混用整条 URL 与表单编码规则 |
| P1-06 | 通用工具操作 | 每个工具具备说明、示例、清空、结果区域；复制成功才提示成功，剪贴板失败提供手动复制提示；输入上限与超限提示由各工具规格确定 |
| P1-07 | 隐私说明 | 明确本地处理范围；工具内容不出现在请求、日志、URL 或持久化存储；刷新不承诺保留输入 |
| P1-08 | SEO 与使用质量 | 首页有中文语言声明、唯一标题、描述和单个主标题；每个工具页面需有可访问地址、独立标题与说明，路由/渲染决策确认后实现；不得宣称 SPA 已解决搜索引擎收录 |

## 共同质量要求

在 375、768、1440 CSS 像素宽度下无页面级横向溢出；键盘可完成核心操作；输入有标签，焦点可见，结果和错误可被辅助技术感知。支持范围建议为验收时 Chrome、Edge、Safari、Firefox 最新稳定版，具体版本记录于验收报告。

首页不使用外部字体、广告、分析脚本或第三方接口。基础布局性能预算见 001；各工具须在独立规格定义输入限制及响应目标，避免大输入阻塞界面。

## 排除项及依赖

第一阶段不包含账号、支付、云同步、数据库、后端、广告接入、文件上传服务或大文件处理。收藏、历史记录、主题切换、多语言和复杂文件转换暂不纳入。

P1-01 可独立设计；P1-02 和 P1-08 的多页面部分依赖路由决策。P1-03～05 先确认优先级，再分别建立规格、设计和任务，不在 001 内实现算法。未批准的候选功能不得直接进入编码。
