# 项目开发路线图

按验收门槛推进，不承诺未经评估的日期。

| 阶段 | 交付内容 | 进入下一阶段的条件 |
| --- | --- | --- |
| R0 规范基线（当前） | 本轮 9 份中文文档、实际依赖盘点、待确认决策 | 人工审阅产品范围、001 规格与设计，并明确授权实现 |
| R1 网站基础布局 | 按 001 构建品牌、锚点导航、分类目录、响应式及隐私说明 | 001 所有验收通过，类型检查与构建通过，保存人工验证证据 |
| R2 首批工具 | 确认文本统计、JSON、URL 工具优先级；分别完成独立 SDD 文档再实现；加入真实工具入口及搜索 | 每个上线工具满足独立规格；路由方案已确认，多页面直接访问和返回行为通过验证 |
| R3 发布准备 | 确认域名、托管、SEO 渲染及测试方案，完善工具说明、性能和可访问性验证 | 发布清单通过、静态资源和深链接验证通过，获得独立部署授权 |
| R4 后续演进 | 根据反馈评估新增工具、广告、统计或 Python/FastAPI | 每项变更有独立规格与决策；涉及数据离开浏览器须显式说明并获批准 |

R0 不实现网站功能。R1 不安装新依赖；若必须改变此约束，先提交决策请求。R2、R3 的路由、自动化测试及 SEO 基建不可因路线图出现而视为已授权。

每阶段结束记录验收结果、未解决问题和文档变化；发现范围膨胀时先更新产品需求与决策。上线工具数量与商业化日期均待确认。
