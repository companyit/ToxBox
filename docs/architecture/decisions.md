## 变更沿革与备选处理

本轮将原 ADR-003、004、006、007 的建议/待确认状态转为上述已确认方向；ADR-005 从泛化 SSR/预渲染备选收敛为上线前静态预渲染评估；ADR-009 由托管平台待定收敛为 Cloudflare Pages 规划。ADR-011 拆出新增 ADR-012 性能目标，新增 ADR-013 明确授权边界。原 150 KiB 提案不再作为实施前确认项或硬性门槛，避免与已批准的性能目标混淆。

hash 路由、Pinia、立即接入 Playwright、SSR 和后端不是当前方案。首发中文、系统字体、响应式和系统明暗偏好保留在 001 设计中，手动主题切换不在范围内。

日期：2026-10-10。提出者：项目负责人；起草依据：本轮 M1-02 UAT 归档要求。状态：正式批准。批准日期：2026-10-10；批准者：项目负责人；依据本轮《M1-02 阶段确认与 M1-03 规格设计》授权。

采用 [双层质量门禁](../quality/gates.md)：Dev Done 判断功能、自动化、类型、构建、真实浏览器核心交互、阻塞缺陷及遗留记录；Release Ready 进一步验证目标浏览器、正式移动设备、无障碍、隐私安全、性能预算、独立 URL/SEO 和生产部署前检查。理由是开发阶段结束与生产发布具备不同证据要求。备选是沿用单一完整验收门禁；其完整验收要求保留，但无法单独表达开发完成状态。

影响：002 tasks 与验收归档增加两层状态；既有需求与测试预期不变，不将未测追认为通过，不自动关闭 001/002 全验收任务。M1-02 经本轮逐项证据核对确认为 Dev Done；Release Ready 未完成，兼容性待验证。独立路由、依赖、预渲染和发布仍需各自授权。此规则用于后续阶段门禁；Dev Done 用于继续开发阶段，Release Ready 用于判断发布准备，均不自动授权生产发布。本轮仅授权 M1-03 规格设计，不授权实现。

## ADR-016：独立页面与客户端路由迁移（正式批准）

起草及批准日期：2026-10-10；批准者：项目负责人。来源：M1-05B明确实施授权，包含仅vue-router 4.x安装与路由迁移。

批准方案：明确Vue Router 4.x、HTML5 History，根部署、已知路径带尾斜杠并兼容旧无斜杠地址；首页、两分类、三工具、关于、隐私共8页及catch-all 404。保留共享布局与工具纯函数/交互组件，不缓存工具输入；首页移除三个交互实例，保留原分类/隐私锚点与三个工具迁移入口，卡片使用RouterLink进入独立页。静态页面目录统一管理路径/元数据，轻量纯函数加DOM适配维护head，暂不加head库。新页焦点、返回滚动和读屏通知按005设计，不在URL携带用户输入。

理由：消除双实例与入口歧义，获得稳定可链接页面，复用已验证工具语义。备选：首页与独立页双保留会增加状态/测试分叉；直接丢弃旧锚点会损害已有书签；hash路由与既定History/SEO方向不符，均不推荐。正式域名未知不生成生产canonical，404无canonical且noindex。

影响：[005规格](../specs/005-routing-seo/spec.md)、[设计](../specs/005-routing-seo/design.md)、[任务](../specs/005-routing-seo/tasks.md)。本轮批准替代002～004的历史本页集成方式；不更改算法、不追认Release Ready。上述安装、package/锁文件变化及编码已获本轮授权；实际安装4.6.4，其余新依赖未授权。

## ADR-018：原生Vue构建时SSR与自定义SSG（正式批准）

## ADR-020：静态产物、404 Hydration与SEO环境一致性（本轮实施范围批准）

起草日期：2026-10-10；批准日期/批准者：未批准。关联ADR-016、017、018。

建议8个已知路径按尾斜杠映射目录index.html，顶层404.html用同一App的catch-all渲染，不反射未知地址；分类当前状态由已知路由而非路径前缀决定，使不同未知路径可Hydration同一404。Cloudflare命中文件优先，顶层404关闭默认SPA兜底，不加全路径200 rewrite；未知/缺资源/API状态须在获授权的平台环境验证，本地Vite结果不替代HTTP404证据。

构建/客户端共用SeoEnvironment与PageHead；未批域名preview无canonical/sitemap/robots且noindex，正式origin/索引白名单获批后才生成正式产物，缺失/非法正式配置失败，不能复制旧正式文件到preview。不承诺收录，正式发布独立授权。

必要适配提案：Hydration完成前原生fieldset禁用工具表单，首棵树一致；数字显示固定zh-CN，不改工具计算语义；noscript位于Hydration根外。构建并发1、每页30秒/总300秒，证据留存14天/失败trace7天均为待批准参数，非性能实测值。备选静态404不Hydration可降低该页风险，但与统一应用体验分叉；全站SPA回退会产生软404，均不优先。影响见[006规格](../specs/006-ssg-testing/spec.md)，本轮只设计，未授权实施或部署。
